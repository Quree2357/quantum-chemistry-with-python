## 복소수와 복소평면

학교에서 복소수(complex number)를 배울 때에는 보통 '제곱해서 -1이 되는 수를 $i$라고 부른다' 정도로 들으셨을 겁니다. 문제를 복잡하게 만들려고 억지로 만들어낸 거 아니냐고 생각하실 수도 있습니다. 하지만 복소수는 생각보다 현실에 가까이 있습니다.  

임의의 복소수는 $z=a+bi$처럼 쓸 수 있다는 것을 아실 겁니다. 여기서 $a$를 $z$의 실수부(real part), $b$를 $z$의 허수부(imaginary part)라고 부르죠. 만약 실수부를 가로축으로, 허수부를 세로축으로 놓으면 어떻게 될까요? *좌표평면이라는 말이 어렴풋이 기억납니다...* 그러면 이 복소수는 $(a, b)$라는 좌표를 가지는 평면 위의 한 점으로 표시할 수 있겠군요! 이 평면을 **복소평면(complex plane)**이라고 부릅니다. 원점에서 이 점까지 화살표를 그으면 벡터로 볼 수도 있겠네요. 실제로 복소수의 덧셈과 뺄셈은 벡터의 덧셈과 뺄셈과 완전히 똑같이 계산할 수 있습니다.  
 보니 자연스럽게 `j`로 쓰는 관습이 남았습니다.

```python
import numpy as np

z = 3 + 4j

print("z         =", z)
print("실수부     =", z.real)
print("허수부     =", z.imag)
print("켤레복소수  =", np.conj(z))
print("절댓값     =", abs(z))
```

```python
z         = (3+4j)
실수부     = 3.0
허수부     = 4.0
켤레복소수  = (3-4j)
절댓값     = 5.0
```

여기서 **켤레복소수(complex conjugate)**는 원래 복소수의 허수부의 부호만 반대로 바꾼 것입니다. 되게 별것 아닌 것처럼 보이지만 양자역학에서는 ***정말정말 자주*** 등장하게 됩니다.


## 복소수의 극형식

평면 위의 점은 x좌표와 y좌표로 표시할 수 있습니다. 이를 **직교좌표(Cartesian coordinate)**라고 하는데요. 이 점을 표현하는 다른 방법이 있습니다. 바로 **극좌표(polar coordinate)**입니다. 극좌표에서는 원점에서부터 떨어진 거리, 그리고 양의 x축과 이루는 각도, 이 두 가지를 가지고 점을 표현합니다.

$$
z=r(\cos\theta+i\sin\theta)
$$

여기서 $r=\sqrt{a^2+b^2}$은 $z$의 크기라고 부르고 $|z|$라고도 씁니다. 위 코드에서 절댓값이라고 되어 있는 부분과 같은 의미입니다. 그리고 $\theta$는 양의 x축으로부터 잰 각도입니다. 아래의 그림을 보시면 이해가 쉬우실 겁니다.

![복소수의 극형식](/assets/image-5.png)  

그런데 저 괄호 안의 식에는 아주 유명한 이름이 붙어있습니다. 바로, **오일러의 공식**입니다. 세상에서 가장 아름다운 공식이라는 별명도 붙어있죠.

$$
e^{i\theta}=\cos\theta+i\sin\theta
$$

이 공식을 쓰면 복소수를 이렇게 간단히 쓸 수 있게 됩니다.

$$
z=re^{i\theta}
$$

$r$을 1로 고정해 놓고 한 번 각도에 따라 어떻게 변하는지 그려볼까요?

```python
import matplotlib.pyplot as plt

t = np.linspace(0, 2 * np.pi, 400)

fig, ax = plt.subplots(figsize=(5, 5))
ax.plot(np.exp(1j * t).real, np.exp(1j * t).imag, color="navy", lw=2)
ax.axhline(0, color="gray", lw=0.5)
ax.axvline(0, color="gray", lw=0.5)
ax.set_aspect("equal")
ax.set_xlabel("Re")
ax.set_ylabel("Im")
ax.grid(alpha=0.3)
plt.show()
```

## 파동을 복소수로 나타내기

자, 파동을 생각해봅시다. 복소수 얘기하다가 왜 생뚱맞게 파동이냐고요? 일단 한번 생각해봐요. 지금은 1차원 파동만 생각해봅시다.  
특정 시간에서 파동의 모양을 정확히 나타내려면 세 가지 정보가 필요합니다. 하나는 파동이 얼마나 크게 출렁이는지를 나타내는 **진폭(amplitude)**, 그리고 다른 하나는 출렁임이 얼마나 촘촘한지를 나타내는 **파수(wavenumber)**, 그리고 마지막으로 어디서 시작하는지를 나타내는 **위상(phase)**입니다. 파동을 나타낼 때는 보통 삼각함수를 이용합니다.

$$
f(x)=A\cos(kx+\phi)
$$

식으로는 위와 같이 씁니다. 여기서 $A$가 진폭, $k$가 파수, 그리고 $\phi$가 위상입니다.  

그런데 파동을 이렇게 쓰는 방법도 있습니다.

$$
\tilde{f}(x)=Ae^{i(kx+\phi)}
$$

*엥, 갑자기 복소수요? 전혀 다르게 생겼는데요!*  
위에서 얘기한 오일러 공식을 다시 한번 봅시다.

$$
e^{i\theta}=\cos\theta+i\sin\theta
$$

여기서 실수부만 생각한다면 우리는 이것을 얻습니다. ($\text{Re}(z)$는 $z$의 실수부를 뜻합니다.)

$$
\text{Re}(e^{i\theta})=\cos\theta
$$

그러니까 우리는 복소수에서 실수부만 꺼내면 코사인 함수를 얻을 수 있겠군요! 그림으로 한번 볼까요? 복소평면에서 $e^{i\theta}$는 원을 나타낸다고 했습니다. 이 원을 도는 점에서 실수축으로 수직선을 내려서 '그림자'를 만들어볼까요? 그러면 점이 원을 한 바퀴 도는 동안 그림자는 좌우로 왕복 운동을 하겠죠. 그 그림자의 위치를 각도에 대한 함수로 나타낸 것이 바로 코사인 함수입니다.

```python
t = np.linspace(0, 2 * np.pi, 400)
th0 = 1.0  # 관찰할 각도 (rad 단위)

fig, (axL, axR) = plt.subplots(
    1, 2, figsize=(10, 3), gridspec_kw={"width_ratios": [1, 2]}
)

# 왼쪽: 복소평면 위의 점과 그 그림자
axL.plot(np.cos(t), np.sin(t), color="navy", lw=1.5)
axL.plot([0, np.cos(th0)], [0, np.sin(th0)], color="crimson", lw=2)
axL.plot(np.cos(th0), np.sin(th0), "o", color="crimson")
axL.plot([np.cos(th0)] * 2, [np.sin(th0), 0], color="gray", ls=":", lw=1.5)
axL.plot(np.cos(th0), 0, "s", color="darkgreen")
axL.set_aspect("equal")
axL.grid(alpha=0.3)
axL.set_xlabel("Re")
axL.set_ylabel("Im")

# 오른쪽: 그림자의 궤적 = 코사인
axR.plot(t, np.cos(t), color="darkgreen", lw=2)
axR.plot(th0, np.cos(th0), "s", color="darkgreen", ms=8)
axR.set_xlabel("theta")
axR.set_ylabel("cos(theta)")
axR.grid(alpha=0.3)
plt.show()
```

![코사인 함수](/assets/image-7.png)

빨간 점이 원 위를 돌면, 초록 사각형이 그 그림자를 나타냅니다. 오른쪽 그래프의 초록 점이 같은 위치를 나타내죠.


## 그래서 뭣이 중헌디?

파동을 삼각함수 대신 복소수로 나타낼 수 있다는 건 알겠는데, 굳이 왜 그렇게 할까요? 그 이유는 복소수로 나타냈을 때 계산이 훨씬 편해지기 때문입니다. 여러 개의 파동이 겹칠 때에는 각각의 파동을 더하면 됩니다. 이것을 **중첩 원리(superposition principle)**라고도 하는데요. 삼각함수로 나타낸 파동을 더하려면... 삼각함수의 덧셈정리를 이용해야 합니다. 생각만 해도 골치가 아프네요.  

복소수를 이용하면 이야기가 달라집니다! 복소수를 더할 때에는 실수부끼리 더하고 허수부끼리 더한다는 것, 기억하시죠? 그러니까, 복소수로 파동을 나타내면 그냥 더하면 됩니다!

$$
Ae^{i(kx+\phi)} = (Ae^{i\phi})e^{ikx}
$$

지수함수의 성질 덕분에 위상 부분을 이렇게 떼어낼 수 있습니다. 파수가 같은 두 파동을 더할 때 $e^{ikx}$는 공통으로 묶여 나오니, 결국 앞의 $Ae^{i\phi}$끼리만 더하면 되는 것이죠. 삼각함수로는 이렇게 깔끔하게 분리되지 않습니다.  
실제로 확인해볼까요? 진폭이 같고 위상만 어긋난 두 파동을 더해보겠습니다.

```python
x = np.linspace(0, 4 * np.pi, 500)
k = 1.0
A1, phi1 = 1.0, 0.0
A2, phi2 = 1.0, 2 * np.pi / 3

# 방법 1: 실수 코사인끼리 직접 더하기
real_sum = A1 * np.cos(k * x + phi1) + A2 * np.cos(k * x + phi2)

# 방법 2: 복소수로 더한 뒤 마지막에 실수부만 취하기
psi1 = A1 * np.exp(1j * (k * x + phi1))
psi2 = A2 * np.exp(1j * (k * x + phi2))
complex_sum = (psi1 + psi2).real

print("두 방법의 결과가 같은가요?", np.allclose(real_sum, complex_sum))
```

```python
두 방법의 결과가 같은가요? True
```

파동을 복소수로 나타내면 또 하나의 장점이 있습니다. 바로 합성파의 진폭과 위상을 한 번에 알아낼 수 있다는 점입니다.

```python
A1, phi1 = 1.0, 0.0
A2, phi2 = 1.0, 2 * np.pi / 3

c = A1 * np.exp(1j * phi1) + A2 * np.exp(1j * phi2)

print(f"합성파 진폭 = {abs(c):.4f}")
print(f"합성파 위상 = {np.angle(c):.4f} rad")
```

```python
합성파 진폭 = 1.0000
합성파 위상 = 1.0472 rad
```

어라, 진폭이 1인 파동 두 개를 더했는데 합성파의 진폭도 1이 나왔네요? 위상이 어긋난 만큼 서로 상쇄간섭이 일어나서 그렇습니다. 삼각함수로 이 값을 얻으려면 덧셈정리로 계산을 해야 하지만 복소수에서는 덧셈 한 번이면 끝납니다.


## 켤레복소수

마지막으로 이 책에서 가장 자주 쓰게 될 계산 중 하나를 짚고 넘어가겠습니다. 어떤 복소수에 자기 자신의 켤레복소수를 곱해봅시다.

$$
z^*z = (a-bi)(a+bi)=a^2+b^2=|z|^2
$$

그냥 실수가 되었네요. 특히 크기의 제곱값이므로 항상 0 이상인 것도 알 수 있습니다. 사소해 보이지만 굉장히 중요한 성질입니다. 나중에 파동함수 $\psi$를 공부하게 되면, 파동함수 그 자체보다는 이렇게 파동함수에 자기 자신의 켤레복소수를 곱한 $\psi^*\psi=|\psi|^2$에 더 집중하게 될 겁니다. 이렇게 하면 복소수값이 아니라 실숫값으로 편하게 다룰 수 있고, 물리적인 의미를 부여하기도 편합니다.  
앞으로도 켤레복소수의 곱셈을 지겹도록 보게 될 텐데, 전부 이 이유 때문에 붙어 있다고 보면 됩니다.  


## 정리하며

여기까지 복소수는 계산을 편하게 해주는 포장지 같은 것이었습니다. 실수부만 꺼내면 언제든 원래 파동으로 돌아올 수 있었으니까요. 그런데 양자역학에서는 사정이 조금 다릅니다. 파동함수는 실수부를 꺼내서 쓰는 물건이 아니거든요. 관측 확률은 실수로 나타나지만, 파동함수가 가진 상대적인 위상 정보는 간섭과 시간 변화에 중요한 역할을 합니다. 지금은 그런 순간이 온다는 것만 기억해두시면 됩니다.
