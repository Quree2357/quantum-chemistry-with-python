우리는 함수의 대칭, 도형의 대칭 같은 개념을 이미 배웠습니다. 분자의 대칭도 그것과 크게 다르지 않습니다. 접거나 돌리거나 거울에 비췄을 때 같아 보이면 대칭이죠. 이렇게 접거나 돌리거나 하는 것을 **대칭 조작(symmetry operation)**이라고 합니다. 물론 아무렇게나 막 하면 안 되고 적어도 원래 모양과 똑같이 보여야 하죠. 그리고 이 대칭 조작이 이루어지는 기준이 되는 축, 면, 혹은 점을 **대칭 요소(symmetry element)**라고 부릅니다. 이번 절에서는 이것들에 대해서 살펴보도록 하죠.


## 다섯 가지 대칭 조작

분자가 가지는 대칭 조작에는 다섯 가지가 있습니다. 그리고 각각에 대응되는 대칭 요소도 총 다섯 가지죠.  

첫 번째는 **항등 조작(identity operation)**으로, $E$라고 씁니다. 아무것도 안 하는 거죠. 당연한 소리처럼 들리겠지만 나중에 군을 이야기할 때 없어서는 안 되는 중요한 조작입니다. 대응되는 대칭 요소는 분자 그 자체입니다.  

두 번째는 **n중 회전(n-fold rotation)**으로, $C_n$이라고 씁니다. 대칭 요소는 회전축이고요. 여기서 $n$은 회전을 $n$번 했을 때 처음 상태로 돌아오게 되는 숫자로, 분자를 $\frac{360}{n}\degree$만큼 회전시킨다고 생각하면 됩니다. 예를 들면 벤젠 분자는 육각형이니 $C_6$을 주축(principal axis)으로 가지죠. 분자 하나가 여러 개의 회전 조작을 가질 수 있는데 $n$이 가장 큰 것을 주축이라고 부릅니다. 회전 조작은 여러 번 할 수 있기 때문에 $C_n$ 조작을 $m$번 한 경우에는 $C_n^m$이라고 씁니다.   

세 번째는 **반사(reflection)**입니다. $\sigma$라고 쓰는데, 독일어로 거울을 뜻하는 spiegel의 첫 글자에서 따왔습니다. 대칭 요소는 거울면(mirror plane)이라고 부르는데 거울면과 주축이 어떤 관계인지에 따라 추가로 분류할 수 있습니다. 거울면이 주축을 포함하고 있으면 $\sigma_v$라고 쓰고 수직면(vertical plane)이라고 합니다. 만약 거울면이 주축과 수직이면 $\sigma_h$라고 쓰고 수평면(horizontal plane)이라고 하고요. 그리고 가장 재미있는 경우는 수직면이 두 개의 $C_2$ 축 사이를 이등분할 때인데, $\sigma_d$라고 쓰고 이면 평면(dihedral plane)이라고 부릅니다.

네 번째는 **반전(inversion)**입니다. $i$라고 쓰죠. 일반적인 의미의 '점대칭'과 같습니다. 당연히 대칭 요소는 점이고요.  

그리고 마지막은 **n중 회전반사(n-fold rotary-reflection)**입니다. 먼저 $C_n$ 회전을 한 다음에 그 축에 수직인 평면에 대해 반사시키는 거죠. $S_n$이라고 쓰는데, 조작 과정만 보면 이걸 굳이 따로 빼놔야 하나 싶지만 군론에서는 아주 중요한 조작입니다. 얘도 spiegel의 S를 따왔습니다. 왜 헷갈리게 이름에도 안 들어가는 S를 썼담...

$S_1=\sigma$이고 $S_2=i$라서 엄밀히 말하면 $E$, $C_n$, $S_n$ 세 가지만으로 모든 조작을 표현할 수 있긴 하지만 관례적으로는 이렇게 분류하는 게 편해서 이대로 씁니다.


## 대칭 조작과 행렬

자, 그래서 대칭 조작이 뭐가 있는지는 알았는데요. 이제 우리가 궁금한 건 이걸 어떻게 식으로 쓸 것이냐는 거죠. 머릿속으로 돌려보고 뒤집어보고 하는 건 쉬운데 결국에는 숫자로 옮겨야 하니까요. 다행히 우리에게는 아주 강력한 도구가 있습니다. 바로 행렬이죠.  

선형대수학 시간에 2차원 회전을 행렬로 어떻게 썼었는지 기억하시나요? $xy$-평면에서 원점을 기준으로 각도 $\theta$만큼 회전하는 행렬을 다음과 같이 썼었습니다.

$$
C(\theta) = \begin{bmatrix}
\cos \theta & -\sin \theta \\
\sin \theta & \cos \theta
\end{bmatrix}
$$

3차원에서도 똑같은 방법을 쓸 수 있습니다. 예를 들어 $z$축을 중심으로 회전시키는 조작은 이렇게 쓸 수 있죠.

$$
C(\theta) = \begin{bmatrix}
\cos \theta & -\sin \theta & 0\\
\sin \theta & \cos \theta & 0 \\
0 & 0 & 1
\end{bmatrix}
$$

$\theta=\frac{2\pi}{n}$로 놓으면 $C_n$ 행렬이 되겠군요.  

반사는 더 간단합니다. 좌표의 부호만 뒤집으면 되니까요. 마찬가지로 반전과 항등 조작도 간단하게 만들 수 있습니다. 코드로 정리하면 이렇게 됩니다.
```python
import numpy as np


def C(n, axis="z"):
    """z, y, x 축에 대한 360/n 도 회전"""
    th = 2 * np.pi / n
    c, s = np.cos(th), np.sin(th)
    if axis == "z":
        return np.array([[c, -s, 0], [s, c, 0], [0, 0, 1.0]])
    if axis == "y":
        return np.array([[c, 0, s], [0, 1.0, 0], [-s, 0, c]])
    return np.array([[1.0, 0, 0], [0, c, -s], [0, s, c]])


def sigma(plane):
    """xy, xz, yz 평면에 대한 반사"""
    m = np.eye(3)
    m[{"yz": 0, "xz": 1, "xy": 2}[plane]] *= -1
    return m


def S(n, axis="z"):
    """회전반사: 회전한 다음 그 축에 수직인 면에서 반사"""
    perp = {"z": "xy", "y": "xz", "x": "yz"}[axis]
    return sigma(perp) @ C(n, axis)


E = np.eye(3)
i = -np.eye(3)
```

이제 우리는 코드로 대칭 조작 다섯 가지를 모두 할 수 있게 되었습니다! (지금 이 코드에서는 회전 조작은 $x$, $y$, $z$ 축에 대한 것만, 반사 조작은 $xy$, $yz$, $xz$ 평면에 대한 것만 가능하다는 것을 주의하세요.)


## 분자에 대칭 조작 해보기

물 분자에다가 대칭 조작들을 직접 해볼까요? 먼저 분자의 좌표를 정해야 하는데, 대칭 요소들이 최대한 각 좌표축과 좌표평면에 일치하도록 두겠습니다. 산소 원자를 원점에 두고 수소 원자가 $z$축에 대칭이 되도록 $yz$-평면에다가 놓으면 좋겠네요.
```python
r, theta = 0.9572, np.radians(104.52)
water = np.array([
    [0, 0, 0],
    [0,  r * np.sin(theta / 2), -r * np.cos(theta / 2)],
    [0, -r * np.sin(theta / 2), -r * np.cos(theta / 2)],
])
labels = ["O", "H", "H"]


def is_symmetry(op, coords, labels, tol=1e-6):
    moved = coords @ op.T
    used = set()
    for p, l in zip(moved, labels):
        for j, (q, m) in enumerate(zip(coords, labels)):
            if j not in used and l == m and np.allclose(p, q, atol=tol):
                used.add(j)
                break
        else:
            return False
    return True


tests = {
    "E": E,
    "C2(z)": C(2),
    "C3(z)": C(3),
    "σ(xz)": sigma("xz"),
    "σ(yz)": sigma("yz"),
    "σ(xy)": sigma("xy"),
    "i": i,
}

for name, op in tests.items():
    print(f"{name:>5}: {'O' if is_symmetry(op, water, labels) else 'X'}")
```
```
    E: O
C2(z): O
C3(z): X
σ(xz): O
σ(yz): O
σ(xy): X
    i: X
```

물 분자가 가지는 대칭 조작은 4개입니다. 항등 조작 $E$, 180도 회전 조작 $C_2$, 그리고 거울면 두 개죠.  
메테인 분자에도 해볼까요? 탄소 원자를 중심에 두고 수소 원자 4개를 정육면체의 꼭지점에 놓아봅시다. (다르게 둬도 크게 상관은 없지만요.)
```python
methane = np.array(
    [
        [0.0, 0.0, 0.0],  # C
        [1.0, 1.0, 1.0],  # H
        [1.0, -1.0, -1.0],  # H
        [-1.0, 1.0, -1.0],  # H
        [-1.0, -1.0, 1.0],  # H
    ],
)
mlabels = ["C", "H", "H", "H", "H"]

mtests = {
    "E": E,
    "C2(z)": C(2),
    "C4(z)": C(4),
    "S4(z)": S(4),
    "i": i,
}

for name, op in mtests.items():
    print(f"{name:>5}: {'O' if is_symmetry(op, methane, mlabels) else 'X'}")
```
```
    E: O
C2(z): O
C4(z): X
S4(z): O
    i: X
```

메테인 분자는 180도 회전 조작 $C_2$는 되지만 90도 회전 조작 $C_4$는 안 됩니다. 그런데 회전 반사 $S_4$는 됩니다. 회전만으로는 안 되고, 반드시 반사 조작이 함께 들어가야 하는 것이죠. 이것이 $S_n$ 조작을 따로 둔 이유이기도 합니다.  

$S_n$ 조작을 하나도 가지지 않는 분자를 **카이랄(chiral)**하다고 합니다. 거울면이나 반전 중심이 있으면 카이랄하지 않다는 익숙한 규칙이 여기 포함됩니다. 일반화학 시간에 배운 것처럼 '탄소에 서로 다른 치환기 네 개가 붙으면 카이랄이다'라는 명제가 성립하지 않는 경우가 있습니다. 그럴 때 이 대칭 조작으로 분자의 카이랄성을 판단할 수 있습니다.


## 점군과 군

어떤 대칭을 가지는지에 따라서 분자들을 분류할 때는 가능한 대칭 조작들을 모아서 이름을 붙입니다. 예를 들어, 물 분자의 경우에는 위에서 본 것처럼 $\{E, C_2, \sigma_v, \sigma_v'\}$가 되겠죠. 반사 조작에 따옴표를 붙인 이유는 두 거울면이 모두 $\sigma_v$라서 구분하기 위해 붙여놓았습니다. 이렇게 가능한 대칭 조작들을 모아 놓은 집합을 **점군(point group)**이라고 부릅니다. 이름에 '점'이 들어가는 이유는 대칭 조작을 할 때 적어도 한 점은 반드시 고정되기 때문입니다. 결정처럼 전체가 평행이동하는 대칭 조작이 존재할 때는 공간군(space group)을 사용하는데 여기서는 다루지 않겠습니다.  

물 분자의 점군은 $C_{2v}$라는 이름이 붙어있습니다. 어떤 대칭 조작이 가능한지에 따라 여러 이름들이 붙어있는데, 암모니아 분자 같은 경우에는 $C_{3v}$, 벤젠 분자는 $D_{6h}$, 메테인 분자는 $T_d$ 등 엄청나게 많은 종류가 존재합니다. 그래서 일일이 모든 점군을 나열하는 것은 불가능하기도 하고 별로 실용적이지도 않습니다. 그때그때 표를 보고 확인하는 게 더 낫죠.

그런데 '군'은 무엇일까요? 영어로는 group이긴 한데 집합처럼 그냥 단순히 모아만 놨으면 set이라고 써도 되지 않았을까요? 사실 집합의 일종으로 봐도 됩니다. 현대대수학에서 나오는 개념인데 집합 중에서도 특수한 조건을 만족하는 집합을 **군(group)**이라고 부릅니다. 엄밀하게는 집합과 연산, 이 두 개를 묶어서 하나의 군을 이룬다고 말합니다. 그 '특수한 조건'은 다음과 같습니다. 어떤 집합 $A$와 연산 $\circ$이 있다고 해보죠.

1) 집합이 연산에 관하여 닫혀 있다: 집합의 원소를 아무거나 두 개 가져와서 연산을 해도 그 결과가 다시 그 집합의 원소가 되어야 한다는 것입니다.
2) 연산이 결합법칙을 만족한다: 결합법칙은 $(a \circ b) \circ c = a \circ (b \circ c)$였죠. 임의의 원소에 대해서도 이 식이 성립해야 합니다.
3) 항등원이 존재한다: $A$의 어떤 원소 $e$가 있어서 아무 원소나 가져와서 연산을 해도 다시 그 원소가 나와야 하죠. $a \circ e = e \circ a = a$라고 씁니다. 물론 $a$에 따라서 $e$가 달라지면 안 되고요.
4) 역원이 존재한다: 집합의 모든 원소에 대해서 연산을 했을 때 항등원 $e$가 나오는 원소가 존재해야 합니다. $a \circ b = b \circ a = e$가 되는 $b \in A$가 존재해야 하죠. 얘는 $a$에 따라서 당연히 달라질 거고요.

이 네 가지 조건을 모두 만족하는 집합과 연산이 있을 때 $(A, \circ)$를 군이라고 합니다. 그냥 $A$가 군이라고 하기도 하고요. 예를 들어, 정수와 덧셈은 군을 이룹니다. 또, 0을 제외한 유리수와 곱셈도 군을 이루고요. 각 조건을 만족하는지 직접 확인해 보세요!


## 군과 곱셈표

그러면 점군도 위 조건들을 모두 만족하는 집합이라서 '군'이라고 부르는 거겠군요. 군의 연산과 성질을 한 눈에 알아보기 좋은 도구가 바로 곱셈표를 만들어보는 것입니다. 두 연산을 연속으로 하는 것을 곱셈으로 표기해서 그 결과가 어떻게 되는지 살펴보는 것이죠. 위에서 대칭 조작을 행렬로 만들어봤으니 그대로 행렬의 곱셈으로 계산하면 됩니다.
```python
ops = {
    "E": E,
    "C2": C(2),
    "σ_v": sigma("xz"),
    "σ_v'": sigma("yz"),
}


def which(M, table):
    for name, op in table.items():
        if np.allclose(M, op):
            return name
    return "??"


w = 7
print(" " * w + "".join(f"{k:>{w}}" for k in ops))
for a, A in ops.items():
    print(f"{a:>{w}}" + "".join(f"{which(A @ B, ops):>{w}}" for B in ops.values()))
```
```
             E     C2    σ_v   σ_v'
      E      E     C2    σ_v   σ_v'
     C2     C2      E   σ_v'    σ_v
    σ_v    σ_v   σ_v'      E     C2
   σ_v'   σ_v'    σ_v     C2      E
```
이런 식으로 만들어진 표를 **군 곱셈표(group multiplication table)**라고 부릅니다. 그러니까 만약 $C_2$ 조작을 한 후에 $\sigma_v$ 조작을 하면 $\sigma_v'$ 조작을 한번 한 것과 똑같은 결과가 나온다는 뜻이죠.  

물 분자의 점군 곱셈표를 다시 잘 보세요. 대각선을 기준으로 표가 대칭입니다. 그러니까 연산의 순서를 바꿔도 결과가 같다는 거죠. 이런 군을 **가환군(commutative group)**, 혹은 Abelian 군이라고 부릅니다. 당연하게도 모든 군이 가환은 아닙니다. 암모니아 분자의 경우에는 돌리고 뒤집는 것과 뒤집고 돌리는 것이 다른 조작이 되거든요. 이렇게 비가환군을 이루는 점군에서는 특이한 현상이 나타나는데 13.3절에서 이 얘기를 해보겠습니다.

## 이렇게 보나 저렇게 보나

암모니아 분자를 생각해보세요. 거울면이 세 개 있습니다. 각 거울면에 대한 반사 조작은 서로 다른 조작이지만 분자 자체만 보면 어떤 조작을 하든 구별이 안 될 것 같습니다. 심지어 거울면에 이름을 어떻게 붙일지도 우리 마음이죠. 그러니까 동일한 조작을 다른 각도에서 본 거라고 생각해도 되지 않을까요?  

이것을 수학적으로 표현할 수 있습니다. 어떤 조작 $R$과 $S$에 대해서 다음과 같은 관계가 성립한다고 합시다.

$$
R' = S^{-1}RS
$$

그러면 조작 $R$과 $R'$는 켤레(conjugate)라고 합니다. 이 두 조작은 같은 조작을 다른 방향에서 봤을 뿐이라는 거죠. 이렇게 켤레인 조작들을 묶은 것을 **유형(class)**이라고 합니다.  

예를 들어, 암모니아 분자는 6개의 대칭 조작을 가지는데, 이 조작들은 세 가지 유형으로 분류됩니다.

$$
\{ E, \, C_3, \, C_3^2, \, \sigma_a, \, \sigma_b, \, \sigma_c \} \longrightarrow \{ E \}, \, \{ C_3, \, C_3^2 \}, \, \{ \sigma_a, \, \sigma_b, \, \sigma_c \}
$$

[[TIP]]
$S^{-1}RS$라는 꼴이 어딘가 익숙하지 않으신가요? 0.1.4에서 행렬을 대각화할 때 $V^{T}AV$ 꼴을 봤었죠. 생김새가 같은 게 우연이 아닙니다. 13.3절에서 이 둘이 만나면서 지표표라는 물건이 성립하는 이유가 밝혀집니다.
[[/TIP]]


## 다음 이야기
 
분자의 대칭 조작을 행렬로 쓰고, 그 조작들이 군을 이룬다는 것까지 봤습니다. 그런데 방금 우리가 만든 행렬들은 사실 분자 전체가 아니라 공간의 한 점이 어떻게 움직이는지만 말해주고 있습니다. 우리가 정말 알고 싶은 건 오비탈이나 파동 함수가 대칭 조작에 어떻게 반응하는가인데 말이죠.
 
다음 절에서는 이 행렬을 확장합니다. 대상이 바뀌면 행렬도 바뀌는데, 놀랍게도 그렇게 만든 여러 행렬들이 전부 같은 곱셈표를 따르는 것을 보게 될 겁니다.
