# 2.2. Bohr의 가정 해결

1.3절에서 봤던 Bohr 모형을 생각해봅시다. Bohr는 원자 구조를 설명하기 위해 여러 가정을 했고, 그중 하나가 바로 이것이었습니다.  

$$
L = m_evr = n\hbar, \qquad n=1, 2, 3, \ldots
$$

전자의 각운동량이 $\hbar$의 정수배여야 한다는 것이었죠. 그런데 왜 그래야 하는지는 Bohr 자신도 설명하지 못했고, 아무도 몰랐습니다. 이제 그 빚을 갚을 차례입니다.  


## 전자가 파동이라면

de Broglie가 말한 것처럼 전자가 파동이라고 해봅시다. 그리고 전자가 파동의 형태로 원자핵 주위의 궤도를 돌고 있다고 합시다. 한 바퀴를 다 돌아서 제자리로 오면 어떻게 될까요? 만약 위상(phase)이 같다면 보강 간섭을, 반대라면 상쇄 간섭을 일으키겠죠. 조금씩이라도 어긋나게 되면 두 바퀴, 세 바퀴 계속 돌다 보면 결국 완전히 상쇄되어 아무것도 남지 않게 될 겁니다. 이 파동이 계속 유지되려면 한 바퀴를 돈 후에 자기 자신의 위상과 정확히 맞아떨어져야 합니다. 그러려면 궤도의 둘레 길이가 파장의 정수배여야 하죠.

$$
2\pi r = n\lambda, \qquad n=1, 2, 3, \ldots
$$

그림으로 보면 더욱 분명해집니다.
```python
import numpy as np
import matplotlib.pyplot as plt

R, A = 1, 0.15
theta = np.linspace(0, 2 * np.pi, 1000)
theta_over = np.linspace(2 * np.pi, 3 * np.pi, 250)

fig, axes = plt.subplots(1, 2, figsize=(11, 5))

for i, (n, ok) in enumerate([(4, True), (3.5, False)]):
    color = "blue" if ok else "red"
    psi = R + A * np.sin(n * theta)
    psi_over = R + A * np.sin(n * theta_over)

    ax = axes[i]
    ax.plot(R * np.cos(theta), R * np.sin(theta), color="lightgray", lw=1.2, ls="--")
    ax.plot(psi * np.cos(theta), psi * np.sin(theta), color=color, lw=2.2)
    ax.plot(psi_over * np.cos(theta_over), psi_over * np.sin(theta_over), color=color, lw=2.2, ls="--")
    ax.plot([R], [0], "o", color="black", ms=7)
    ax.set_aspect("equal")
    ax.axis("off")
    ax.set_xlim(-1.4, 1.4)
    ax.set_ylim(-1.4, 1.4)
    ax.set_title(f"n = {n}")

plt.show()
```
![de Broglie 양자 조건](/assets/image-27.png)

왼쪽은 $n=4$인 경우입니다. 파동이 궤도를 따라 네 번 출렁이며 돌고, 한 바퀴 뒤에 시작점과 정확히 만납니다. 그리고 계속 같은 모양을 유지하면서 돌죠. 반면에, 오른쪽은 $n=3.5$인 경우입니다. 파동이 한 바퀴를 돌고 나면 그 다음부터는 점선처럼 움직이고, 직전 바퀴의 자기 자신과 위상이 반대가 되어 상쇄시키게 됩니다. 이런 파동은 유지될 수 없습니다.

전자가 파동이라면 아무 궤도나 허용될 수 없다는 뜻입니다.


## Bohr의 가정이 풀리다

앞 절에서 배운 de Broglie의 식을 다시 한 번 살펴봅시다. $\lambda = \frac{h}{mv}$였죠. 여기에 위에서 봤던 전자가 파동이라면 만족해야 하는 조건, $2\pi r = n\lambda$을 넣어봅시다.

$$
\frac{2\pi r}{n} = \frac{h}{mv}
$$
$$
mvr = \frac{nh}{2\pi} = n\hbar
$$

전자의 각운동량 $L=mvr$이 $\hbar$의 정수배여야 한다는 Bohr의 가정이 튀어나왔습니다! 이제 Bohr의 가정이 왜 그래야 했는지를 이해할 수 있겠군요.  

정말 맞는지 확인해봅시다. 수소 원자의 바닥상태에서의 전자 궤도 둘레와 de Broglie 파장을 각각 계산해서 비교해보죠.
```python
from scipy.constants import h, hbar, m_e, e, epsilon_0

a0 = 4 * np.pi * epsilon_0 * hbar**2 / (m_e * e**2)
v1 = e**2 / (4 * np.pi * epsilon_0 * hbar)

circumference = 2 * np.pi * a0
wavelength = h / (m_e * v1)

print(f"궤도 둘레        = {circumference:.4e} m")
print(f"de Broglie 파장 = {wavelength:.4e} m")
print(f"둘레 / 파장      = {circumference / wavelength:.6f}")
```
```
궤도 둘레        = 3.3249e-10 m
de Broglie 파장 = 3.3249e-10 m
둘레 / 파장      = 1.000000
```
정확히 1이 나왔네요! 그러니까 수소 원자의 바닥상태는 궤도 둘레에 파장이 딱 하나 들어가는 상태인 것입니다.  

위쪽 준위에서는 어떨까요? Bohr 모형에서 $n$번째 궤도의 반지름과 이 궤도에서 전자의 속도는 다음과 같이 알려져 있습니다. (자세한 유도 과정은 9장에서 살펴보겠습니다.)

$$
r_n = n^2 a_0, \qquad v_n = \frac{v_1}{n}
$$

```python
for n in range(1, 6):
    r_n = n**2 * a0
    v_n = v1 / n
    ratio = 2 * np.pi * r_n / (h / (m_e * v_n))

    print(f"n = {n}    반지름 = {r_n*1e12:6.1f} pm    둘레 / 파장 = {ratio:.4f}")
```
```
n = 1    반지름 =   52.9 pm    둘레 / 파장 = 1.0000
n = 2    반지름 =  211.7 pm    둘레 / 파장 = 2.0000
n = 3    반지름 =  476.3 pm    둘레 / 파장 = 3.0000
n = 4    반지름 =  846.7 pm    둘레 / 파장 = 4.0000
n = 5    반지름 = 1322.9 pm    둘레 / 파장 = 5.0000
```
이 값들은 Bohr의 가정으로부터 얻은 것이라 같은 결과가 나오는 건 당연합니다. 우리가 여기서 봐야할 것은 양자수 $n$이 곧 궤도에 들어가는 파장의 개수와 같다는 사실입니다.


## 양자화와 경계조건

잠깐만요, 지금 무슨 일이 일어난 거죠? 우리는 파동에 경계조건을 걸었습니다. '파동이 한 바퀴 돌아오면 자기 자신과 같은 위상을 가져야 한다'는 조건이었죠. 그랬더니 아무 파장이나 가능한 것이 아니라 특정한 값만이 허용되었습니다. 이 구조, 어디선가 본 기억이 나지 않으세요?  

0.2.4절에서 미분방정식 $y'' = -k^2 y$를 풀 때 경계조건으로 $y(0)=y(L)=0$으로 뒀던 것을 기억하시나요? 그랬더니 $k$는 아무 값이나 가질 수 없고 $\pi$의 정수배로만 나타날 수 있었죠. 그때 이렇게 말했었습니다.

> $k$는 원래 연속적인 값입니다. 그런데 양 끝을 동시에 묶어놓자 불연속적인 값만 가질 수 있게 되었습니다. 연속적인 세계에서 정수가 튀어나온 겁니다.  

지금 일어난 일이 정확히 이것과 똑같은 상황입니다. 그때는 순수하게 수학적 이야기였지만 이제는 원자 속 전자의 이야기가 되었습니다. 양자화는 신비한 현상이 아니었습니다. 파동이 어딘가에 갇히면 자연스럽게 일어나는 일이었죠.  
Planck가 "에너지는 $h\nu$의 정수배 덩어리로만 전달된다"고 했던 것과 Bohr가 "각운동량은 $\hbar$의 정수배로만 가능하다"고 가정한 것, 두 가정은 서로 무관해 보였지만 같은 뿌리에서 나왔던 것이죠.


## 아직 끝이 아니다

de Broglie의 식은 Bohr가 설명하지 못한 것을 설명했죠. 그리고 물리적으로도 아름다워보였습니다. 하지만 이것도 완벽한 답은 아니었습니다.  
문제는 여전히 전자가 특정한 궤도를 따라 돌고 있다고 가정한다는 것입니다. 그리고 앞 절에서 본 전자 회절 실험을 생각해보면 조금 이상합니다. 전자가 결정을 통과할 때, 전자는 대체 어떻게 간 걸까요? 그리고 더 근본적인 질문은, 대체 무엇이 출렁거린다는 걸까요? 전자가 출렁인다고 생각하면 그래봤자 입자가 진동하는 거지 그렇다고 갑자기 파동이 될 수는 없거든요... 다음 절에서는 더 이상한 현상을 보시게 될 겁니다.
