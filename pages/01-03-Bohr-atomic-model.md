## 수소 원자의 선 스펙트럼

1.1절에서 봤던 흑체 복사 스펙트럼을 떠올려봅시다. 모든 진동수의 빛이 방출되는 연속적이고 부드러운 곡선으로 나타났었죠. 이런 것을 **연속 스펙트럼(continuous spectrum)**이라고 합니다. 햇빛을 프리즘에 통과시키면 나오는 무지개가 대표적이죠.  
그런데 기체를 유리관에 넣고 전압을 걸어서 빛을 내게 한 다음(네온 사인을 생각해보세요.), 그 빛을 프리즘에 통과시키면 전혀 다른 모양의 스펙트럼이 나타납니다. 무지개처럼 연속적인 것이 아니라 특정 진동수의 빛만 나타나는 선 모양의 스펙트럼이 나옵니다. 이걸 (당연히) **선 스펙트럼(line spectrum)**이라고 부르고요.  
더 신기한 것은, 기체를 이루는 원소의 종류에 따라 나타나는 선의 위치가 정해져 있다는 것입니다. 예를 들어, 수소와 헬륨이 나타내는 선 스펙트럼의 위치는 완전히 다릅니다. 실제로 헬륨은 태양 스펙트럼에서 정체불명의 선이 발견되면서 지구에서보다 먼저 발견된 원소입니다. 태양을 뜻하는 그리스어 helios에서 이름을 따왔죠.  

![수소 원자의 선 스펙트럼](/assets/image-24.png)

수소의 선 스펙트럼에서는 가시광선 영역에서 656.3 nm, 486.1 nm, 434.0 nm, 410.2 nm 등등에 해당하는 선이 뚜렷하게 보입니다. 파장이 긴 쪽부터 차례대로 $H_\alpha$, $H_\beta$, $H_\gamma$, $H_\delta$라는 이름이 붙었습니다.  
그런데 대체 왜 원자들은 이렇게 정해진 진동수의 빛만 낼까요? 그리고 왜 하필 저 값들일까요?

## Balmer의 식

1885년 스위스의 수학 선생님이었던 Balmer는 이 숫자들을 들여다보다가 규칙을 찾아냈습니다.

$$
\lambda = B \frac{n^2}{n^2-4}, \qquad n = 3, 4, 5, \ldots
$$

여기서 $B$ = 364.56 nm라는 값입니다. 정말 맞는지 확인해봅시다.
 
```python
import numpy as np

B = 364.56
n = np.arange(3, 8)
lam = B * n**2 / (n**2 - 4)

obs = np.array([656.279, 486.135, 434.0472, 410.1734, 397.0075])

for ni, l, o in zip(n, lam, obs):
    print(
        f"n={ni}   Balmer 공식 {l:7.2f} nm   관측값 {o:7.2f} nm   차이 {abs(l-o):.2f} nm"
    )
```
```
n=3   Balmer 공식  656.21 nm   관측값  656.28 nm   차이 0.07 nm
n=4   Balmer 공식  486.08 nm   관측값  486.13 nm   차이 0.05 nm
n=5   Balmer 공식  434.00 nm   관측값  434.05 nm   차이 0.05 nm
n=6   Balmer 공식  410.13 nm   관측값  410.17 nm   차이 0.04 nm
n=7   Balmer 공식  396.97 nm   관측값  397.01 nm   차이 0.04 nm
```
 
관측값을 매우 잘 재현하고 있습니다! 여기서 관측된 선들을 Balmer 계열이라고 부릅니다.

그 후, 1888년에 스웨덴의 물리학자 Rydberg는 이 식을 더 일반적인 형태로 다시 썼습니다.
 
$$
\frac{1}{\lambda} = R\left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right), \qquad n_2 > n_1
$$
 
여기서 $n_1 = 2$로 두면 Balmer의 식이 됩니다. 그리고 $n_1 = 1$이나 $3$으로 두면 각각 자외선과 적외선 영역에서 나올 수 있는 파장값이 나오는데, 실제로 나중에 전부 발견되었습니다.(발견자들의 이름을 따서 $n_1 = 1$의 경우는 Lyman 계열, $n_1 = 3$의 경우를 Paschen 계열이라고 부릅니다.) 여기서 $R$을 **Rydberg 상수(Rydberg constant)**라고 부릅니다.
 
관측된 파장에서 $R$을 직접 구해볼까요? 위 식을 정리하면 $1/\lambda$가 $\left(1/4 - 1/n^2\right)$에 비례하니, 직선 피팅을 하면 기울기가 곧 $R$입니다.
 
```python
x = 1 / 4 - 1 / n**2
y = 1 / (obs * 1e-9)

slope, intercept = np.polyfit(x, y, 1)
print(f"관측값에서 얻은 R = {slope:.6e} m^-1")
print(f"문헌값         R = 1.097373e+07 m^-1")
```
```
관측값에서 얻은 R = 1.097102e+07 m^-1
문헌값         R = 1.097373e+07 m^-1
```

소수점 셋째자리까지 일치하네요!
 
여기까지가 1890년대의 상황이었습니다. 현상을 설명할 식은 있는데 왜 이렇게 되는지는 아무도 몰랐습니다. 왜 하필 정수의 제곱이 들어가는지, $R$이라는 상수는 어디서 온 숫자인지, 아무도 설명하지 못했죠.
 
 
## 원자는 존재할 수 없다
 
이 무렵 원자의 구조에 대해서도 문제가 있었습니다. 1.2절에서 얘기했듯이 Thomson이 전자를 발견하고 나서 원자는 푸딩에 건포도(전자)가 박혀있는 것처럼 생겼을 것이라는 Thomson 모델이 널리 알려져 있었습니다.
 
그리고 1911년에 Rutherford는 금박에 알파 입자를 쏘는 산란 실험을 통해 원자의 중심에 아주 작고 무거운 핵이 있다는 것을 밝혀냈습니다. 그러면 자연스럽게 아래와 같은 그림이 떠오릅니다. 무거운 핵이 중심에 있고 그 주위를 전자가 돌고 있는 모습이죠. 사실 지금도 원자를 생각하면 이런 이미지를 떠올리시는 분들이 많을 겁니다.

![러더퍼드 원자 모형](/assets/image-22.png)  
[출처: https://commons.wikimedia.org/wiki/File:Rutherford_atomic_planetary_model.svg]
 

그런데 여기에 치명적인 문제가 있었습니다. 고전 전자기학에 따르면 '가속하는 전하는 전자기파를 방출'해야 합니다. 원운동은 속력이 일정하다고 해도 방향이 계속 바뀌니까 가속 운동이죠. 그러니까 원 궤도를 도는 전자는 끊임없이 빛을 내며 에너지를 잃어야 합니다. 에너지를 잃으면 궤도가 작아지고, 결국 핵으로 빨려 들어가야 하죠.
 
이렇게 되는 데에는 얼마나 걸릴까요? 고전 전자기학으로 계산할 수 있습니다.(계산 과정이 궁금하신 분들은 Larmor 공식에 대해 검색해보세요.) 전자 하나가 양성자 주위를 반지름 약 $10^{-10}$ m의 원 궤도로 돈다는 단순한 고전 모형을 생각해봅시다.
 
```python
from scipy.constants import c, e, m_e, epsilon_0

r0 = 1e-10

t_collapse = m_e**2 * c**3 * (4 * np.pi * epsilon_0) ** 2 / (4 * e**4) * (r0**3)

print(f"붕괴 시간 = {t_collapse:.3e} 초")
```
```
붕괴 시간 = 1.050e-10 초
```
 
원자가 붕괴하는 데 약 100억 분의 1초밖에 걸리지 않습니다. 고전물리학이 옳다면 이 세상의 모든 원자는 만들어지자마자 즉시 붕괴해야 합니다. 여러분도, 여러분이 보고 있는 이 책도 존재할 수 없죠. 게다가 궤도가 연속적으로 줄어드는 동안 방출되는 빛의 진동수도 연속적으로 변해야 합니다. 그러면 선 스펙트럼이 아니라 연속 스펙트럼이 나와야 하죠. 관측과 정반대입니다.
 
1.1절과 1.2절에서 본 것이 "고전물리학이 설명하지 못하는 현상"이었다면, 여기서는 한 걸음 더 나아갑니다. 고전물리학이 옳다면 원자 자체가 존재할 수 없습니다!
 
 
## Bohr의 등장
 
1913년, 덴마크의 물리학자 Bohr가 해결책을 내놓습니다. 방법은 단순했습니다. Bohr는 고전 전자기학이 원자 내부의 궤도에서는 그대로 적용되지 않는다고 가정했습니다.
 
Bohr는 세 가지를 가정했습니다.
 
1. 전자는 특정한 궤도에서만 돌 수 있고, 그 궤도에 있는 동안에는 에너지를 흡수하거나 방출하지 않는다. 이런 상태를 **정상상태(stationary state)**라고 부릅니다.

2. 전자가 가질 수 있는 정상상태의 궤도는 각운동량이 $\hbar$의 정수배인 궤도뿐이다. 여기서 $n$을 **양자수(quantum number)**라고 부릅니다.
 
$$
L = m_evr = n\hbar, \qquad n = 1, 2, 3, \ldots
$$
 
3. 빛은 전자가 한 궤도에서 다른 궤도로 건너뛸 때만 나온다. 이때 방출되는 빛의 에너지는 두 궤도의 에너지 차이와 같다. (플랑크의 양자 가설이 또 등장했습니다.)
 
$$
\Delta E = h\nu
$$
 
두 번째 가정으로부터 수소 원자의 가장 작은 궤도의 반지름인 **Bohr 반지름(Bohr radius)**을 계산할 수 있습니다. 약 0.0529 nm이고 $a_0$라고 표기합니다.  

사실 이 가정들에는 근거가 없었습니다. 왜 전자가 정상상태에 있을 때는 빛을 내지 않는지, 왜 하필 각운동량이 양자화되는지 Bohr는 설명하지 못했습니다. 그냥 "이렇게 가정하면 실험과 맞는다"는 것이 유일한 근거였죠. 플랑크가 에너지를 덩어리로 가정했을 때와 똑같은 상황입니다.
 
 
## 근데 이게 왜 됨?

이 가정에서 출발해 계산하면 전자의 에너지 준위가 이렇게 나옵니다. (유도 과정은 8장에서 제대로 다루겠습니다.)
 
$$
E_n = -\frac{m e^4}{8\varepsilon_0^2 h^2}\cdot\frac{1}{n^2}
$$
 
$n^2$이 분모에 있죠. 그러면 두 궤도 사이의 전이에서 나오는 빛은 Bohr의 세 번째 가정에 따르면 다음과 같겠네요.
 
$$
\frac{1}{\lambda} = \frac{m e^4}{8\varepsilon_0^2 h^3 c}\left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right)
$$
 
Rydberg 식과 똑같은 모양이 나왔습니다. 그것도 앞의 상수 덩어리가 통째로 $R$의 자리에 들어앉았죠. 그러니까 Bohr의 모형이 맞다면 이렇게 되어야 합니다.
 
$$
R = \frac{m e^4}{8\varepsilon_0^2 h^3 c}
$$
 
이건 검증할 수 있는 예측입니다. 우변에는 전자의 질량($m_e$), 전자의 전하량($e$), 진공의 유전율($\varepsilon_0$), 플랑크 상수($h$), 그리고 빛의 속도($c$)밖에 없거든요. 전부 다른 실험에서 독립적으로 측정된 상수들입니다.
 
직접 계산해봅시다.
 
```python
from scipy.constants import h

R_bohr = m_e * e**4 / (8 * epsilon_0**2 * h**3 * c)

print(f"Bohr 모형에서 계산한 R = {R_bohr:.6e} m^-1")
print(f"문헌값              R = 1.097373e+07 m^-1")
```
```
Bohr 모형에서 계산한 R = 1.097373e+07 m^-1
문헌값              R = 1.097373e+07 m^-1
```
 
Bohr 모형은 Rydberg 상수의 크기와 기본 상수 사이의 관계를 놀랍도록 정확하게 설명했습니다. 30년 가까이 정체를 모르던 숫자가, 기본 상수 다섯 개의 조합으로 정확히 설명된 것입니다. Balmer가 그저 숫자를 맞춰 얻었던 상수에 물리적인 의미가 생긴 순간이죠.
 
에너지 준위로 그려보면 이렇습니다.
 
```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(5, 5))

for ni in range(1, 8):
    E = -13.606 / ni**2
    ax.hlines(E, 0, 1, lw=2, color="navy")
    ax.text(1.03, E, f"n={ni}", va="center", fontsize=9)

ax.hlines(0, 0, 1, lw=1.5, ls="--", color="gray")

# Balmer 계열: n = 3, 4, 5에서 n = 2로
for ni, col in zip([3, 4, 5], ["crimson", "steelblue", "darkviolet"]):
    xpos = 0.3 + 0.12 * (ni - 3)
    ax.annotate(
        "",
        xy=(xpos, -13.606 / 4),
        xytext=(xpos, -13.606 / ni**2),
        arrowprops=dict(arrowstyle="->", color=col, lw=2),
    )

ax.set_xlim(0, 1.2)
ax.set_ylim(-14.5, 0.5)
ax.set_xticks([])
ax.set_ylabel("energy (eV)")
plt.show()
```
![수소 원자의 에너지 준위](/assets/image-23.png)
 
에너지 준위가 위로 갈수록 촘촘해지고 0에 수렴합니다. $n \to \infty$가 되면 에너지가 0이 되는데, 이건 전자가 원자에서 완전히 떨어져 나간 상태입니다. 그래서 바닥상태에서 여기까지 올리는 데 필요한 에너지 13.6 eV가 곧 수소의 **이온화 에너지(ionization energy)**가 되죠. 그림의 화살표 세 개가 바로 Balmer 계열입니다. 위쪽 준위에서 $n=2$로 떨어질 때 나오는 빛이죠.
 
Bohr 모형은 대성공이었습니다. 1922년에 노벨상도 받았고요. 그런데 곧 한계가 드러났습니다. 자세한 건 다음 절에서 살펴보도록 하죠.
 
 
## 확인 문제
 
1. Rydberg 식에서 Lyman 계열의 $n_2 = 2, 3, 4$일 때의 파장을 계산하고, 이 빛들이 어느 영역(가시광선/자외선/적외선)에 속하는지 판단해보세요. Paschen 계열도 계산해보세요. 라이만 계열과 비교하면 파장이 어떻게 다른가요?
2. 수소의 이온화 에너지는 13.6 eV입니다. 이 에너지를 가진 광자의 파장을 계산해보세요. 가시광선으로 수소를 이온화할 수 있을까요?
3. Balmer 계열에서 $n_2 \to \infty$일 때 파장은 얼마로 수렴할까요? 이것을 계열 한계(series limit)라고 합니다.
