섭동론에서 **섭동(perturbation)**이란 크기가 아주 작은 변화를 뜻합니다. 예를 들면 천체의 운동을 분석할 때 다른 천체의 영향을 받아서 원래의 공전 궤도에서 미세하게 벗어나는 현상 같은 것들이죠. 섭동론은 원래 천문학에서 이렇게 행성들의 운동을 기술하기 위해 쓰였습니다. 프랑스의 수학자 Lagrange와 Laplace가 행성이 태양 주위를 공전하면서 궤도가 '교란된다(perturbed)'라는 개념을 도입하여 섭동론을 정립하였습니다. 그리고 양자역학에서도 비슷하게 원자핵과 전자들이 서로를 교란하는 일들이 일어나기 때문에 섭동론을 들여오게 되었습니다. 그럼 이제 섭동론이 어떻게 적용되는지 확인해볼까요?


## 답 베껴도 돼? 어, 근데 조금은 바꿔라.

우리가 Schrödinger 방정식을 정확히 풀 수 있는 경우는 손에 꼽을 정도입니다. 기껏해야 상자 속 입자, 조화 진동자, 수소 원자 정도였죠. 그런데 만약 우리가 계산하고 싶은 계의 Hamiltonian이 이런 경우들과 완전히 똑같지는 않지만 거의 비슷하다면 어떨까요? 그러면 (정확히 풀 수는 없겠지만) 답도 거의 비슷하게 나오지 않을까요? 이것이 섭동론의 아이디어입니다.  
계산하고 싶은 계의 Hamiltonian 중에서 우리가 정확히 답을 알고 있는 부분과 나머지를 분리해봅시다. 그러니까, '아, 이거만 없으면 풀 수 있을텐데'라고 생각되는 항을 따로 빼는 거죠.

$$
\hat{H} = \hat{H}^{(0)} + \hat{H}^{(1)}
$$

앞으로 뺀 부분은 우리가 정확히 풀 수 있는 비섭동(unperturbed) Hamiltonian입니다. 즉, $\hat{H}^{(0)} \psi_n^{(0)} = E^{(0)} \psi_n^{(0)}$라고 썼을 때 우리가 이 식을 정확히 풀어서 $\psi_n^{(0)}$와 $E^{(0)}$를 구할 수 있습니다. 나머지를 퉁쳐서 $\hat{H}^{(1)}$ 항으로 밀어넣고 이걸 섭동이라고 부릅니다.  

이걸 바로 풀 수는 없으니 약간의 기술을 써야 하는데요, 섭동 항에 매개변수 $\lambda$를 붙여놓는 것입니다. $\lambda=0$이면 섭동이 전혀 없으니 우리가 정확히 풀 수 있는 문제가 되고, $\lambda=1$이면 섭동이 다시 생겨 처음에 우리가 풀고 싶었던 문제가 되죠.

$$
\hat{H} = \hat{H}^{(0)} + \lambda \hat{H}'
$$

이제 Hamiltonian이 $\lambda$에 대한 함수가 되었으니 에너지와 파동 함수도 $\lambda$에 대한 함수로 나타날 것입니다. 일단 얘네들을 Taylor 급수로 전개해봅시다. 앞에 붙는 상수들은 귀찮으니 다 묶어버립시다.

$$
\psi_n = \psi_n^{(0)} + \lambda \psi_n^{(1)} + \lambda^2 \psi_n^{(2)} + \cdots
\\ \, \\
E_n = E_n^{(0)} + \lambda E_n^{(1)} + \lambda^2 E_n^{(2)} + \cdots
$$

그러니까 이렇게 묶인 겁니다.

$$
\psi_n^{(k)} = \frac{1}{k!} \frac{\partial^k}{\partial \lambda^k} \psi_n
\\ \, \\
E_n^{(k)} = \frac{1}{k!} \frac{d^k}{d \lambda^k} E_n
$$

이 항들을 k차 보정 항이라고 부릅니다. 예를 들어, $\psi_n = \psi_n^{(0)} + \lambda \psi_n^{(1)}$에서 끝났다면 1차 보정이 된 거죠.  
이제 이걸 원래 식에 넣고 정리하면 되는데요, 조금 귀찮으니 생략하고 바로 결과로 넘어가겠습니다. 자세한 유도 과정이 궁금한 분들은 McQuarrie 교재의 8장이나 Levine 교재의 9장을 참고하세요.

에너지의 1차 보정 항은 이렇게 됩니다.

$$
E_n^{(1)} = \left\langle \psi_n^{(0)} \middle| \hat{H}' \middle| \psi_n^{(0)} \right\rangle
$$

섭동의 기댓값이네요. 원래 파동 함수를 그대로 쓰고 섭동의 평균을 구하면 됩니다. 간단하네요. 파동 함수는 어떻게 나타날까요?

$$
\psi_n^{(1)} = \sum_{m \neq n} \frac{\left\langle \psi_m^{(0)} \middle| \hat{H}' \middle| \psi_n^{(0)} \right\rangle}{E_n^{(0)} - E_m^{(0)}} \psi_m^{(0)}
$$

와 정말 복잡하네요. 조금 풀어서 보자면 다른 모든 상태들에 대한 합으로 나타나고 있습니다. 분자는 섭동이 상태 $n$과 $m$을 얼마나 섞는지를 나타내고, 분모는 두 상태의 에너지 차이죠.

에너지의 2차 보정 항까지는 봐두면 좋습니다. 파동 함수의 2차 보정은 너무 복잡해지고요.

$$
E_n^{(2)} = \sum_{m \neq n} \frac{\left| \left\langle \psi_m^{(0)} \middle| \hat{H}' \middle| \psi_n^{(0)} \right\rangle \right|^2}{E_n^{(0)} - E_m^{(0)}}
$$

파동 함수의 1차 보정과 거의 비슷한데 분자만 조금 다르네요. 이 식에서 두 가지를 읽을 수 있습니다.
- 바닥 상태의 2차 보정 에너지는 항상 음수입니다. 분자는 절댓값의 제곱이라 항상 양수인데 분모가 항상 음수로 나타나기 때문입니다. $E_0^{(0)}$이 제일 작으니까요.
- 에너지가 가까운 상태일수록 크게 기여합니다. 분모가 작아지거든요.

이런 식으로 접근하는 방식의 섭동론을 Rayleigh-Schrödinger 섭동론이라고 부릅니다. 물론 다른 접근법도 있고요.

[[TIP]]
섭동론은 변분법과 성격이 조금 다릅니다. 변분법에서는 어떤 시험 함수를 써도 항상 참값보다 크다는 보장이 있었기 때문에 낮으면 무조건 좋다는 기준이 성립했습니다. 섭동론에서는 그런 보장은 없습니다. 2차 보정 항까지 계산한 값이 참값보다 높을 수도 있고, 낮을 수도 있죠. 대신에 파동 함수를 미리 정할 필요가 없고 어떤 상태들이 얼마나 섞이는지가 식에 그대로 드러난다는 장점이 있습니다.
[[/TIP]]


## 비조화 진동자의 에너지 보정

6.4절에서 실제 분자의 퍼텐셜은 포물선이 아니라 비대칭 곡선인 것을 봤습니다. 그래서 조화 진동자 근사만으로는 실제 퍼텐셜을 정확히 묘사할 수 없습니다. 섭동론을 사용해 비조화 진동자의 에너지를 계산해보겠습니다. 당연히 출발은 조화 진동자입니다.

$$
V(x) = \frac{1}{2}kx^2 + \frac{1}{6}cx^3 + \frac{1}{24}dx^4
$$

퍼텐셜 곡선을 최소점 근처에서 전개했을 때 조화 진동자의 경우에는 2차 항에서 끊었지만 4차 항까지 고려해봅시다. 그러면 앞의 2차 항이 비섭동 항이고 나머지가 섭동이죠.  
조화 진동자의 해는 우리가 정확히 알고 있습니다. 보정을 계산하기 위해 필요한 것은 $\left\langle \psi_m^{(0)} \middle| \hat{H}' \middle| \psi_n^{(0)} \right\rangle$ 형태의 적분들이죠. 손으로 직접 계산하려면 조금 귀찮은데 다행히 조화 진동자 문제에는 편리한 도구가 하나 있습니다. 바로 6.2절에서 잠깐 언급했던 사다리 연산자입니다.

$$
x = \sqrt{\frac{\hbar}{2m \omega}} \left( \hat{a} + \hat{a}^{\dagger} \right)
$$

$\hat{a}$는 행렬로 썼을 때 대각선에 $\sqrt{1}, \sqrt{2}, \sqrt{3}, \dots$이 늘어서 있는 아주 단순한 모양의 행렬입니다. 그러니 $x$도 행렬로 만들 수 있고, $x^3$이나 $x^4$도 계산할 수 있죠. 원자 단위계로 두고 계산해봅시다.
```python
import numpy as np

N = 60

a = np.diag(np.sqrt(np.arange(1, N)), 1)
X = (a + a.T) / np.sqrt(2)
E0 = np.arange(N) + 0.5

X3 = X @ X @ X
X4 = X3 @ X

print(f"<0|x^3|0> = {X3[0, 0]:.6f}")
print(f"<0|x^4|0> = {X4[0, 0]:.6f}  (이론값 3/4)")
```
```
<0|x^3|0> = 0.000000
<0|x^4|0> = 0.750000  (이론값 3/4)
```
$x^3$의 기댓값이 0입니다. 바닥 상태의 파동 함수가 우함수라서 홀수차항의 기댓값이 0이 되네요. 그러니 에너지의 1차 보정에는 4차 항만 기여합니다.

$$
E_0^{(1)} = \frac{d}{24}\left\langle x^4 \right\rangle = \frac{d}{24}\cdot\frac{3}{4} = \frac{d}{32}
$$

이제 에너지를 계산해봅시다.
```python
def corrections(c, d):
    Hp = c / 6 * X3 + d / 24 * X4

    E1 = Hp[0, 0]
    E2 = sum(Hp[0, m] ** 2 / (E0[0] - E0[m]) for m in range(1, N))
    return E1, E2


c, d = -0.1, 0.1
E1, E2 = corrections(c, d)

print(f"0차 (조화)   : {0.5:.8f}")
print(f"1차 보정     : {E1:+.8f}   (이론값 d/32 = {d/32:.8f})")
print(f"2차 보정     : {E2:+.8f}")
print(f"2차까지 합계 : {0.5 + E1 + E2:.8f}")
```
```
0차 (조화)   : 0.50000000
1차 보정     : +0.00312500   (이론값 d/32 = 0.00312500)
2차 보정     : -0.00042752
2차까지 합계 : 0.50269748
```
1차 보정 항이 위에서 구했던 $\frac{d}{32}$와 똑같이 나오네요. 그리고 2차 보정 항이 음수로 나오는 것도 앞에서 본 것과 일치합니다.


## 근사, 어디까지 되었니?

7.4절에서 만들었던 solver로 정확한 답을 구해서 섭동론으로 구한 에너지가 얼마나 비슷한지 비교해보겠습니다. 이번에도 원자 단위계를 씁니다.
```python
def solve_1d(V, x, mass):
    N = len(x)
    dx = x[1] - x[0]
    D2 = (-2 * np.eye(N) + np.eye(N, k=1) + np.eye(N, k=-1)) / dx**2
    H = -1 / (2 * mass) * D2 + np.diag(V)
    E, _ = np.linalg.eigh(H)

    return E


x = np.linspace(-5, 5, 1000)
V = 0.5 * x**2 + c / 6 * x**3 + d / 24 * x**4
E_exact = solve_1d(V, x, 1.0)[0]

print(f"{'보정 없이'} {0.5:.8f}   오차 {0.5 - E_exact:+.2e}")
print(f"{'1차 보정'} {0.5 + E1:.8f}   오차 {0.5 + E1 - E_exact:+.2e}")
print(f"{'2차 보정'} {0.5 + E1 + E2:.8f}   오차 {0.5 + E1 + E2 - E_exact:+.2e}")
print(f"{'정확한 값'} {E_exact:.8f}")
```
```
보정 없이 0.50000000   오차 -2.72e-03
1차 보정 0.50312500   오차 +4.07e-04
2차 보정 0.50269748   오차 -2.04e-05
정확한 값 0.50271789
```
보정의 차수를 올릴 수록 정확한 에너지 값에 가까워집니다. 차수가 하나 올라갈수록 오차는 거의 10배씩 줄어드네요. 오차의 부호도 1차 보정에서는 위로 갔다가 2차 보정에서는 다시 아래로 갑니다.


## 섭동이 커지면

섭동론은 Hamiltonian이 '살짝' 다르면 해도 '살짝'만 다를 것이라는 전제에서 출발했습니다. 만약에 섭동이 크면 어떻게 될까요? $d$의 크기를 증가시키면서 확인해봅시다.
```python
import matplotlib.pyplot as plt

ds = np.linspace(0, 2, 11)
e1, e2, ex = [], [], []

for d in ds:
    E1, E2 = corrections(0, d)
    e1.append(0.5 + E1)
    e2.append(0.5 + E1 + E2)
    V = 0.5 * x**2 + d / 24 * x**4
    ex.append(solve_1d(V, x, 1.0)[0])

fig, ax = plt.subplots(figsize=(7, 4))
ax.axhline(0.5, ls="--", lw=2, color="gray", label="0th order")
ax.plot(ds, e1, "o-", lw=2, ms=4, color="darkorange", label="1st order")
ax.plot(ds, e2, "s-", lw=2, ms=4, color="crimson", label="2nd order")
ax.plot(ds, ex, lw=3, color="black", label="exact")
ax.set_xlabel("d (quartic strength)")
ax.set_ylabel("E (a.u.)")
ax.legend(fontsize=9)
ax.grid(alpha=0.3)
plt.show()

for d in [0.1, 0.5, 1.0, 2.0]:
    E1, E2 = corrections(0, d)
    V = 0.5 * x**2 + d / 24 * x**4
    exv = solve_1d(V, x, 1.0)[0]
    print(f"d = {d:4.2f}: 1차 {0.5 + E1:.5f}, 2차 {0.5 + E1 + E2:.5f}, 정확 {exv:.5f}")
```
![큰 섭동에서의 보정](/assets/image-87.png)
```
d = 0.10: 1차 0.50313, 2차 0.50308, 정확 0.50308
d = 0.50: 1차 0.51562, 2차 0.51449, 정확 0.51464
d = 1.00: 1차 0.53125, 2차 0.52669, 정확 0.52773
d = 2.00: 1차 0.56250, 2차 0.54427, 정확 0.55079
```
$d$가 작을 때는 잘 맞다가 1보다 커지면 점점 안 맞기 시작합니다. 섭동이 너무 크면 급수가 잘 수렴하지 않아서 더 높은 차수의 항까지 고려해야 합니다. Taylor 급수의 수렴이랑 비슷한 느낌이죠. 이것이 섭동론의 한계입니다.

[[TIP]]
지금까지 본 경우는 모두 축퇴가 없는 경우였습니다. 축퇴가 있으면 에너지가 같은 상태가 존재하니 보정 식에서 분모가 0이 되어 발산해버리거든요. 그런데 사실 축퇴는 흔한 일이죠. 당장 상자 속 입자만 해도 3차원에서는 축퇴가 생겼습니다. 이런 경우는 어떻게 다뤄야 할까요? 다행히 해결책이 있습니다. 11.5절에서 다뤄보겠습니다.
