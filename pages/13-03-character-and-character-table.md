앞 절에서 대칭 조작의 행렬 표현과 기약 표현에 대해서 살펴봤습니다. 기약 표현은 더 쪼갤 수 없지만 우리는 뭔가 좀 더 쉽게 만들고 싶었죠. 조각 하나를 숫자 하나로 부를 수 있게 하고 싶었던 겁니다. 이번 절에서는 어떻게 그게 가능한지, 그리고 이것으로 무엇을 할 수 있는지 알아보겠습니다.


## 조각 하나에 숫자 하나

앞 절의 확인 문제에서 대칭 조작의 표현 행렬들의 대각합을 계산해보셨나요? 암모니아 분자의 경우에는 $E$는 4, $C_3$는 1, $\sigma_a$는 2였습니다. 표현 행렬의 대각합을 그 조작의 **지표(character)**라고 부르고 $\chi(R)$이라고 씁니다.

$$
\chi(R) = \text{tr}(D(R))
$$

잠깐만요, 대각합을 조작의 지표로 쓴다고요? 기저를 바꾸면 행렬이 달라지는데 대각합도 달라지는 거 아닌가요?  
여기서 대각합의 중요한 성질이 등장합니다. 선형대수학에서 행렬 $D$의 기저를 바꾼다는 것은 어떤 행렬 $T$에 대해서 $T^{-1}DT$를 계산하는 것과 같습니다. 그리고 대각합은 행렬의 곱셈의 순서를 바꿔도 변하지 않죠: $\text{tr}(\mathbf{AB})=\text{tr}(\mathbf{BA})$. 그러니 다음과 같은 관계가 성립하죠.

$$
\text{tr}(T^{-1}DT) = \text{tr}(DT T^{-1}) = \text{tr}(D)
$$

그래서 기저를 아무리 바꿔도 행렬의 대각합, 즉 지표는 변하지 않습니다. 직접 확인해볼 수 있습니다. 임의의 두 행렬 $D$와 $T$에 대해서 계산해보죠.
```python
import numpy as np

D = np.array([[1, 0, -6, 0], [0, 2, -9, 0], [5, 0, 3, 7], [-1, 5, 0, 4]])

T = np.array([[1, 2, 3, 4], [np.sqrt(2), -3, np.pi, 9], [-1, -3, -5, -8], [np.sin(42), np.cos(24), 2.718, 99]])

print("기존 행렬의 대각합:", np.trace(D))
print("기저 변환 후 대각합:", np.trace(np.linalg.inv(T) @ D @ T))
```
```
기존 행렬의 대각합: 10
기저 변환 후 대각합: 10.000000000000007
```
정확히 일치합니다. 아무렇게나 막 만든(물론 역행렬이 존재해야 합니다!) 행렬인데도 성립하죠.

13.1에서 대칭 조작을 유형으로 나눴던 것을 기억해보세요. 두 조작이 같은 유형에 속한다는 것은 켤레 관계, 즉 $S^{-1}RS$ 형태로 이어져 있다는 뜻이었습니다. 따라서 대각합의 성질을 이용하면 같은 유형에 속하는 조작들은 같은 지표를 가진다는 결론을 얻습니다. 그러면 우리는 지표만 가지고 다니면 되겠군요! 암모니아 분자의 경우에는 세 가지 유형을 가지니 숫자 세 개, $(4,\,1,\,2)$만 있으면 됩니다.


## 지표로 만든 표!

이렇게 중요한 지표들을 모으고 모아서 표로 정리한 것이 바로 **지표표(character table)**입니다. 기약 표현들의 각 유형별로 모아놓죠. 암모니아 분자의 점군인 $C_{3v}$에는 유형이 세 가지 있으니 지표표에는 열이 3개 있게 됩니다. 행에는 앞에서 말했던 대칭 종이 들어갑니다. 일단 전체 표를 먼저 볼까요?

| $C_{3v}$ | $E$ | $2C_3$ | $3\sigma_v$ | 선형 함수, 회전 | 이차 함수 |
| - | - | - | - | - | - |
| $A_1$ | +1 | +1 | +1 | $z$ | $x^2+y^2$, $z^2$ |
| $A_2$ | +1 | +1 | -1 | $R_z$ | - |
| $E$ | +2 | -1 | 0 | $(x,\,y)$, $(R_x,\,R_y)$ | $(x^2-y^2,\,xy)$, $(xz,\,yz)$ |

각 유형별로 조작이 몇 개인지를 앞에 숫자로 써 넣었습니다. 회전 조작은 $C_3$와 $C_3^2$ 두 개라서 앞에 2를 붙였죠. 그리고 각 기약 표현들이 대칭 조작에 대해 갖는 지표를 써두었습니다.

[[TIP]]
$E$가 첫 번째 행에도 나오고 첫 번째 열에도 나오는데 둘은 서로 다른 의미입니다. 맨 윗줄의 $E$는 항등 조작의 $E$이고, 왼쪽에 있는 $E$는 기약 표현이 2차원인 경우에 쓰는 이름입니다. 둘 다 표준 표기라 어쩔 수 없는데 위치로 구분하시면 됩니다.
[[/TIP]]

*엥, 4는 어디 갔어요?* 자, 천천히 설명드릴게요. 지표표에 적혀 있는 것은 기약 표현의 지표입니다. 우리가 계산했던 $E$의 대각합은 4×4 행렬에 대한 것이었으니 당연히 다른 값을 가집니다. 지표표를 만드려면 기약 표현으로 다 쪼개놓은 다음에 대각합을 계산해야 합니다. 이렇게 말이죠.
```python
def C(n, axis="z"):
    th = 2 * np.pi / n
    c, s = np.cos(th), np.sin(th)
    if axis == "z":
        return np.array([[c, -s, 0], [s, c, 0], [0, 0, 1.0]])
    if axis == "y":
        return np.array([[c, 0, s], [0, 1.0, 0], [-s, 0, c]])
    return np.array([[1.0, 0, 0], [0, c, -s], [0, s, c]])


def sigma_v(d):
    th = np.radians(d)
    return np.array([[np.cos(2 * th), np.sin(2 * th), 0], [np.sin(2 * th), -np.cos(2 * th), 0], [0, 0, 1.0]])


def orbital_rep(op, coords, labels):
    """s 오비탈 기저에 대한 표현 행렬"""
    n = len(coords)
    M = np.zeros((n, n))
    moved = coords @ op.T
    for i, (p, l) in enumerate(zip(moved, labels)):
        for j, (q, m) in enumerate(zip(coords, labels)):
            if l == m and np.allclose(p, q, atol=1e-6):
                M[j, i] = 1
                break
    return M


r, z = 0.9375, -0.3810
ammonia = np.array(
    [
        [0, 0, 0],
        [r, 0, z],
        [r * np.cos(2 * np.pi / 3), r * np.sin(2 * np.pi / 3), z],
        [r * np.cos(4 * np.pi / 3), r * np.sin(4 * np.pi / 3), z],
    ]
)
labels = ["N", "H", "H", "H"]

ops = {
    "E": np.eye(3),
    "C3": C(3),
    "C3^2": C(3) @ C(3),
    "σ_a": sigma_v(0),
    "σ_b": sigma_v(120),
    "σ_c": sigma_v(240),
}
orb_reps = {k: orbital_rep(v, ammonia, labels) for k, v in ops.items()}

new_basis = [
    ("sN", np.array([1, 0, 0, 0])),
    ("sA + sB + sC", np.array([0, 1 / np.sqrt(3), 1 / np.sqrt(3), 1 / np.sqrt(3)])),
    ("2sA - sB - sC", np.array([0, 2 / np.sqrt(6), -1 / np.sqrt(6), -1 / np.sqrt(6)])),
    ("sB - sC", np.array([0, 0, 1 / np.sqrt(2), -1 / np.sqrt(2)])),
]

new_basis_names = [b[0] for b in new_basis]
T = np.column_stack([b[1] for b in new_basis])

blocks = {"s_N": slice(0, 1), "sA + sB + sC": slice(1, 2), "2x2": slice(2, 4)}

print(" " * 12 + "".join(f"{k:>7}" for k in ops))
for name, sl in blocks.items():
    row = [round(np.trace((T.T @ D @ T)[sl, sl])) for D in orb_reps.values()]
    print(f"{name:>12}" + "".join(f"{v:>7d}" for v in row))
print(f"{'total':>12}" + "".join(f"{round(np.trace(D)):>7d}" for D in orb_reps.values()))
```
```
                  E     C3   C3^2    σ_a    σ_b    σ_c
         s_N      1      1      1      1      1      1
sA + sB + sC      1      1      1      1      1      1
         2x2      2     -1     -1      0      0      0
       total      4      1      1      2      2      2
```
같은 유형의 조작별로 보면 $s_N$ 조각과 $s_A+s_B+s_C$ 조각은 둘 다 (1, 1, 1)이고, 2×2 조각은 (2, -1, 0)입니다. 각각 $A_1$ 행과 $E$ 행의 값과 같죠.  그리고 조각들의 대각합을 모두 더하면 우리가 처음에 계산했던 (4, 1, 2)가 나옵니다. 블록 대각 행렬로 쪼갰으니 조각들의 대각합을 다 더하면 전체 행렬의 대각합과 같겠죠. 그래서 이 경우에는 $2A_1+E$라고도 표기합니다.  

지표표에서 또 재미있는 성질 중 하나는 모든 기약 표현의 차원의 제곱을 더하면 군의 원소의 개수와 같다는 것입니다. 군의 원소의 개수를 위수(order)라고 부르고, $h$라고 쓰는데요. 예를 들어 $C_{3v}$에서는 조각 3개가 각각 1, 1, 2차원으로 쪼개지니 $1^2+1^2+2^2=6$과 대칭 조작의 개수 6이 같죠.


## 대칭 종의 이름들

$A_1$이니 $E$이니 이런 이름들은 어떻게 붙는 걸까요? 이 규칙은 12장에서 이름이 잠깐 나왔던 미국의 화학자 Mulliken이 만들었습니다. 기약 표현이 1차원이면 $A$ 또는 $B$, 2차원이면 $E$, 그리고 3차원이면 $T$를 씁니다. $A$와 $B$를 구분하는 기준은 주축 회전에 대한 지표입니다. 회전 조작에 대해 지표가 +1이면 $A$, -1이면 $B$라고 붙이죠. 그리고 만약 반전 조작에 대해 지표가 +1이면 아래 첨자 $g$를 붙이고, -1이면 $u$를 붙입니다. 오비탈에서 붙였던 것과 같은 의미입니다. 부호가 바뀌냐 안 바뀌냐의 뜻이죠.  

지표표의 오른쪽에 있는 숫자가 아닌 것들은 그 대칭 종에 속하는 함수들의 예입니다. 예를 들어 $z$가 $A_1$ 행에 있다는 것은 $z$라는 함수가 모든 대칭 조작에 대해 부호가 바뀌지 않는다는 뜻입니다. 회전축과 거울면 모두 $z$축을 포함하고 있으니 어떤 조작을 해도 그대로죠. $(x,\,y)$가 괄호로 묶여서 $E$ 행에 있는 것도 의미가 있습니다. 둘이 따로 떼어낼 수 없고 섞인다는 뜻입니다. $C_3$ 조작을 하면 위치가 바뀌죠.  

이 열들이 나중에 유용하게 쓰입니다. 만약 $p_x$ 오비탈이 어떤 대칭 종에 속하는지 알고 싶으면 $x$가 있는 행을 보면 되죠. 이런 식으로 선택 규칙을 유도할 수 있는데요. 다음 절에서 더 자세히 살펴보겠습니다.


## 축약 공식

위에서 $2A_1+E$와 같은 식을 봤는데요, 이걸 지표표에서부터 바로 계산하는 방법이 있습니다. 이 식은 다시 말하면, 전체 표현이 어떤 기약 표현들로 분해될 수 있는지를 나타내는 것입니다. 이 과정을 축약(reduction)이라고 부르고 다음과 같은 공식을 씁니다.

$$
a_i = \frac{1}{h} \sum_R \chi(R) \chi_i(R)
$$

$a_i$는 기약 표현 $i$가 몇 번 나타나는지를 나타냅니다. $h$는 군의 위수이고, $\chi(R)$은 우리가 가진 표현의 지표, $\chi_i(R)$은 기약 표현 $i$의 지표입니다. 모든 조작에 대해서 합하게 되는데, 같은 유형은 지표가 같으니 유형마다 계산해서 합하면 되겠죠. (이 공식이 왜 성립하는지는 증명하지 않겠습니다. 궁금하신 분들은 대직교 정리라는 것을 찾아보세요.)

위에서 살펴본 암모니아 분자에 대해 이 공식을 써봅시다.
```python
c3v = {"A1": [1, 1, 1], "A2": [1, 1, -1], "E": [2, -1, 0]}  # 지표표
sizes = [1, 2, 3]  # 각 유형에 속하는 조작의 개수
h = sum(sizes)  # 군의 위수


def reduce(chi, table, sizes):
    return {name: round(sum(g * a * b for g, a, b in zip(sizes, chi, row)) / sum(sizes)) for name, row in table.items()}


chi_nh3 = [4, 1, 2]
print("암모니아 분자의 s 오비탈 표현의 지표:", chi_nh3)
print()

for name, row in c3v.items():
    terms = " + ".join(f"{g} * {a} * {b}" for g, a, b in zip(sizes, chi_nh3, row))
    n = sum(g * a * b for g, a, b in zip(sizes, chi_nh3, row)) / h
    print(f"n({name}) = (1/{h})[{terms}] = {n:.0f}")
print()
print("축약 결과:", reduce(chi_nh3, c3v, sizes))
```
```
암모니아 분자의 s 오비탈 표현의 지표: [4, 1, 2]

n(A1) = (1/6)[1 * 4 * 1 + 2 * 1 * 1 + 3 * 2 * 1] = 2
n(A2) = (1/6)[1 * 4 * 1 + 2 * 1 * 1 + 3 * 2 * -1] = 0
n(E) = (1/6)[1 * 4 * 2 + 2 * 1 * -1 + 3 * 2 * 0] = 1

축약 결과: {'A1': 2, 'A2': 0, 'E': 1}
```
위에서 봤던 것처럼 $2A_1+E$가 나왔네요! 그런데 이번에는 행렬을 직접 만들어서 계산한 것이 아니라 지표표만 보고 계산한 겁니다. 이것이 바로 지표표의 힘입니다.


## 물 분자의 진동 모드

새로운 문제를 풀어봅시다. 6장에서 이원자 분자의 진동에 대해 다뤘었죠. 원자가 세 개 이상 되면 진동이 일어나는 방식이 복잡해집니다. $N$개의 원자로 이루어진 분자의 자유도는 $3N$인데, 12.1절에서 말한 것처럼 분자가 통째로 움직이는 병진 운동과 회전 운동을 제외하고 $3N-6$(선형 분자의 경우에는 $3N-5$)이 진동 모드에 대한 전체 자유도입니다.  

물 분자의 경우에는 진동 모드가 3개네요. 각 모드가 어떤 대칭 종인지 알아봅시다. 먼저 지표표를 살펴봐야겠죠? 물 분자는 $C_{2v}$ 점군이니 다음과 같은 지표표를 가집니다.  

| $C_{2v}$ | $E$ | $C_2$ | $\sigma_v(xz)$ | $\sigma_v(yz)$ | 선형 함수, 회전 | 이차 함수 |
| - | - | - | - | - | - | - |
| $A_1$ | +1 | +1 | +1 | +1 | $z$ | $x^2$, $y^2$, $z^2$ |
| $A_2$ | +1 | +1 | -1 | -1 | $R_z$ | $xy$ |
| $B_1$ | +1 | -1 | +1 | -1 | $x$, $R_y$ | $xz$ |
| $B_2$ | +1 | -1 | -1 | +1 | $y$, $R_x$ | $yz$ |

$C_{2v}$는 가환군이라 기약 표현이 전부 1차원이어서 앞에 붙는 숫자가 없습니다. 조작도 4개, 유형도 4개죠.  

이제 분자의 표현 지표 $\chi(R)$이 필요한데, 직교 좌표 9개를 기저로 하는 9×9 행렬을 다 만들어서 계산할 필요는 없습니다. 우리는 어차피 대각합만 필요하니까요. 대각선 성분에는 제자리에 남아있는 원자만 기여합니다. 그러니까 사실상 다음과 같은 계산을 하면 되는 거죠.  

$$
\chi(R) = \text{(제자리에 남은 원자 수)} \times \text{tr}(R)
$$

```python
def sigma(plane):
    m = np.eye(3)
    m[{"yz": 0, "xz": 1, "xy": 2}[plane]] *= -1
    return m


r, theta = 0.9572, np.radians(104.52)
water = np.array(
    [
        [0, 0, 0],
        [0, r * np.sin(theta / 2), -r * np.cos(theta / 2)],
        [0, -r * np.sin(theta / 2), -r * np.cos(theta / 2)],
    ]
)
labels = ["O", "H", "H"]

ops_water = {"E": np.eye(3), "C2(z)": C(2), "σ(xz)": sigma("xz"), "σ(yz)": sigma("yz")}

chi_3n = []
print(" " * 8 + f"{"제자리 원자":>8}{"tr(R)":>8}{"χ":>8}")
for k, op in ops_water.items():
    n_fixed = sum(np.allclose(p, q, atol=1e-6) for p, q in zip(water @ op.T, water))
    chi = n_fixed * np.trace(op)
    chi_3n.append(round(chi))
    print(f"{k:>8}{n_fixed:>12}{np.trace(op):>8.0f}{chi:>8.0f}")

print()
print("χ(3N) =", chi_3n)
```
```
          제자리 원자   tr(R)       χ
       E           3       3       9
   C2(z)           1      -1      -1
   σ(xz)           1       1       1
   σ(yz)           3       1       3

χ(3N) = [9, -1, 1, 3]
```
다른 교재에서는 순서가 바뀌어 있는 경우가 있는데, 처음에 분자를 놓을 때 방향을 다르게 두어서 그렇습니다. 숫자 조합만 맞으면 되니 너무 신경쓰지 마세요.  

이제 지표표를 이용해서 축약을 해봅시다.
```python
c2v = {"A1": [1, 1, 1, 1], "A2": [1, 1, -1, -1], "B1": [1, -1, 1, -1], "B2": [1, -1, -1, 1]}
sizes_water = [1, 1, 1, 1]

print("축약 결과:", reduce(chi_3n, c2v, sizes_water))
```
```
축약 결과: {'A1': 3, 'A2': 1, 'B1': 2, 'B2': 3}
```
따라서, 물 분자의 기약 표현에 대한 축약 표현은 $3A_1+A_2+2B_1+3B_2$가 됩니다.  

그런데 이건 가능한 모든 운동에 대한 표현입니다! 여기서 병진 운동과 회전 운동 6개를 빼줘야 합니다. 어떤 게 병진 운동에 해당하고 어떤 게 회전 운동에 해당하는 걸까요? 이것은 지표표의 오른쪽을 보면 알 수 있습니다.

병진 운동은 $x$, $y$, $z$가 어디 적혀 있는지 보면 됩니다. 각각 $B_1$, $B_2$, $A_1$에 있네요. 그러니 $A_1+B_1+B_2$를 빼주면 됩니다.  
회전 운동은 $R_x$, $R_y$, $R_z$를 보면 되고, 각각 $B_2$, $B_1$, $A_2$에 있으니 $A_2+B_1+B_2$를 빼주면 되겠군요.

따라서 남는 것은 $2A_1+B_2$입니다. $A_1$에 해당하는 모드는 대칭 신축과 굽힙입니다. $B_2$에 해당하는 모드는 비대칭 신축이고요. ([링크](https://www.chem.purdue.edu/jmol/vibs/h2o.html)에 가시면 물 분자의 진동 운동에 대한 애니메이션을 보실 수 있습니다. 다른 분자들에 대한 애니메이션도 있으니 참고하세요.)


## 대칭성과 축퇴

3.2절에서 정사각형 막의 진동을 다룰 때 대칭성이 축퇴를 만든다고 했었던 것, 기억나시나요? 7.1절의 고리 위의 입자에서도 그랬고요. 그 때 나중에 분자의 대칭성과 군론을 배우면서 다시 얘기하겠다고 했습니다. 지금이 이 이야기를 할 딱 좋은 타이밍이군요.

그 답은 2차원 이상의 기약 표현에 있습니다. 2차원 이상의 기약 표현에 속한다는 것은 함수 여러 개가 짝지어 하나의 대칭 종을 이룬다는 뜻입니다. 대칭 조작을 하면 함수들이 섞이는 것이죠. 그런데 Hamiltonian은 모든 대칭 조작에 대해 변하지 않습니다. 에너지가 변하지 않으니까요. 따라서, 섞이는 함수들은 같은 에너지를 가질 수밖에 없습니다. 이것이 축퇴로 나타나는 것이죠.

정사각형 막의 진동이 바로 이 경우에 해당합니다. 정사각형의 대칭 조작을 생각해보세요. 정사각형은 $C_{4v}$ 점군에 속하죠. 그런데 이 점군에도 2차원 기약 표현 $E$가 존재합니다. 직사각형은 $C_{2v}$ 점군이라 2차원 기약 표현이 없어서 축퇴가 깨지는 것이고요.

그리고 또 13.2절에서 2차원 이상의 기약 표현은 비가환군에서만 나타난다고 했었죠. 그러니까 정리하면 비가환군은 2차원 이상의 기약 표현을 가지니 축퇴가 나타난다고 할 수 있습니다. 물의 진동 모드에는 축퇴 준위가 없고, 암모니아의 진동 모드에는 축퇴 준위가 존재하는 거죠.
