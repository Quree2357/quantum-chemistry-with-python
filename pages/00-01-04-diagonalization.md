# 0.1.4. 대각화와 에르미트 행렬

앞 절의 마지막 부분에서 던졌던 질문을 기억하시나요? 행렬의 고유벡터를 계산했더니 두 고유벡터가 직교했었죠.
잘 보면 행렬 $A$는 **대칭행렬(symmetric matrix)**이었습니다! 대각선을 중심으로 해서 양쪽이 같은 값을 가지고 있죠. 이것이 우연일까요?

## 고유벡터와 대각화

사실 이것은 우연이 아닙니다. 대칭행렬의 고유벡터는 항상 직교하거든요. 자세한 증명은 선형대수학 교재에서 많이 다루니 생략하도록 하고, 저희는 이 결과만을 사용하겠습니다.  
이걸 사용해서 무엇을 할 수 있을까요? 일단 이런 계산을 한 번 해봅시다. 

```python
import numpy as np

A = np.array([[2.0, 1.0],
              [1.0, 2.0]])

w, V = np.linalg.eigh(A)

print("v1 . v1 =", round(np.dot(V[:, 0], V[:, 0]), 10))
print("v1 . v2 =", round(np.dot(V[:, 0], V[:, 1]), 10))
print("\nV^T V =\n", np.round(V.T @ V, 10))
```
```
v1 . v1 = 1.0
v1 . v2 = 0.0

V^T V =
 [[1. 0.]
 [0. 1.]]
```

NumPy에서 .T 메서드는 주어진 행렬의 **전치 행렬(transpose matrix)**를 반환시켜 줍니다. 그러니까, 행렬의 행과 열을 바꿔주는 거죠.  
고유벡터들로 이루어진 행렬을 자기 자신의 전치 행렬과 곱했더니 **단위 행렬(unit matrix)**이 나왔습니다. 이것은 행렬 $V$를 이루는 벡터들이 정규직교기저를 이룬다는 말과 동치입니다. 행렬의 곱셈을 생각해보면 당연한 말입니다.  
그런데 기저는 하나가 아니라고 했던 것 기억나시나요? `eigh` 함수는 왜 하필 이 기저를 만들어 준 걸까요?

0.1.2에서 같은 벡터라도 기저에 따라 숫자가 달라진다고 했었습니다. 다른 자를 쓰면 측정값이 달라지는 거죠. 그렇다면 자연스럽게 이런 생각이 듭니다.  
*어떤 자를 써야 가장 편하게 쓸 수 있을까?*  
만약 행렬 $A$를 가지고 문제를 풀고 있다면, 답은 바로 $A$의 고유벡터로 만든 기저입니다. 이 기저로 봤을 때의 행렬 $A$는 엄청 계산이 편해지도록 바뀌거든요. 한번 볼까요?

```python
D = V.T @ A @ V
print("V^T A V = \n", np.round(D, 10))
```
```
V^T A V = 
 [[ 1.  0.]
 [-0.  3.]]
```

$ V^{T}AV$라는 곱을 계산했더니 대각선에 고유값이 나열되어 있고 나머지 성분은 모두 0인 **대각행렬(diagonal matrix)**이 되었습니다!  
이렇게 만드는 것을 **대각화(diagonalization)**라고 하는데요. 대각행렬이 다루기 편한 이유는 곱셈을 할 때 다른 성분을 신경쓰지 않고 대각성분만 신경쓰면 되기 때문입니다.  

$$
V^{T}AV =
\begin{pmatrix}
\lambda_1 & 0 \\
0 & \lambda_2
\end{pmatrix}
$$

모든 행렬이 대각화가 가능하지는 않습니다. 하지만 대각화가 가능한 행렬을 다룬다면 문제를 매우 쉽게 바꿀 수 있다는 큰 장점이 있습니다.  
이 아이디어는 앞으로 이 책 전체에서 계속 반복될 것입니다. 이렇게 대각화를 통해 계산량을 줄이면 양자화학 계산에서 매우 유리하거든요.


## 에르미트 행렬

앞 절에서 언급했던 **에르미트 행렬(Hermitian matrix)**이 드디어 등장합니다. 에르미트 행렬의 특징은 켤레를 취했을 때 자기 자신의 전치 행렬이 된다는 점입니다. 식으로 쓰면 $A^T = A^*$ 라고 쓸 수 있겠군요. 여기서 식을 한 번 더 꼬아서 $A^T*=A$라고도 쓸 수 있는데요, 이렇게 전치 행렬에 켤레를 씌우는 것을 켤레 전치(conjugate transpose)라고 하며, $A^\dagger$로 표현합니다. 에르미트 행렬은 실수 행렬에서의 대칭행렬에 해당하는 개념이라고 볼 수 있습니다.  

```python
H = np.array([[2.0, 1.0 - 1.0j], 
              [1.0 + 1.0j, 3.0]])

print("H =\n", H)
print("H와 H의 켤레 전치는 동일한가요?", np.allclose(H, H.conj().T))
```
```
H =
 [[2.+0.j 1.-1.j]
 [1.+1.j 3.+0.j]]
H와 H의 켤레 전치는 동일한가요? True
```

이 에르미트 행렬의 고유값을 계산해봅시다.

```python
w2, V2 = np.linalg.eigh(H)

print("고유값:", w2)
print("v1 . v2 =", np.round(np.vdot(V2[:, 0], V2[:, 1]), 10))
```
```
고유값: [1. 4.]
v1 . v2 = 0j
```

분명히 복소수 성분을 가진 행렬인데 고유값은 실수로 나왔습니다. 그리고 고유벡터끼리도 여전히 직교합니다.  
네, 에르미트 행렬의 고유값은 항상 실수입니다. 이 성질 때문에 양자역학에서는 에르미트 행렬이 지겹도록 나옵니다. 실험으로 측정되는 물리량(에너지, 위치, 운동량 등)들은 모두 실수여야 하니까요. 만약 에너지를 계산했는데 $3+2i$ J처럼 나오면 안 되겠죠. 이 이야기는 6장에서 더 자세히 해보도록 하겠습니다.


## 양자역학에서 고유값 문제가 중요한 이유

자, 그런데 고유값 문제가 도대체 왜 그렇게 중요할까요? 소개문에서도 말했듯이, 양자역학에서 가장 중요한 문제는 슈뢰딩거 방정식을 푸는 것입니다. 뒤에서 더 자세히 얘기하겠지만 우선 식 자체는 이렇게 생겼습니다.

$$
\hat{H}\psi=E\psi
$$
