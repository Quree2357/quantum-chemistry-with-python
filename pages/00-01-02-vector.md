## 벡터와 내적

벡터의 **내적(inner product)**을 어떻게 계산했는지 기억하시나요? 같은 성분끼리 곱해서 더하는 것이었죠.

$$
\mathbf{u}\cdot\mathbf{v} = u_1v_1 + u_2v_2 + u_3v_3
$$

```python
import numpy as np

u = np.array([1, 2, 3])
v = np.array([4, 5, 6])

print("u . v =", np.dot(u, v))
print("직접 계산:", u[0] * v[0] + u[1] * v[1] + u[2] * v[2])
```
```
u . v = 32
직접 계산: 32
```

그런데 내적을 이해하는 방법에는 두 가지가 있습니다. 한 가지는 위에서 봤던 같은 성분끼리 곱하는 것입니다. 다른 하나는 아래와 같습니다.

$$
\mathbf{u}\cdot\mathbf{v} = |\mathbf{u}||\mathbf{v}|\cos\theta
$$

여기서 $\theta$는 두 벡터가 이루는 각도입니다. 즉 내적은 두 벡터가 얼마나 같은 방향을 보고 있는지를 알려주는 값입니다. 같은 방향이면 양수, 직각이면 0, 반대 방향이면 음수가 되죠.

이 두 방법이 같은 값을 준다는 게 사실 꽤 신기한 일입니다. 성분끼리 곱해서 더했을 뿐인데 두 벡터가 이루는 각도를 알 수 있으니까요. 어쨌든 이 덕분에 내적 하나로 여러 가지를 구할 수 있게 됩니다.

먼저 자기 자신과의 내적은 크기의 제곱이 됩니다. 자기 자신과는 각도가 0이니 $\cos\theta = 1$이겠죠.

$$
\mathbf{u}\cdot\mathbf{u} = |\mathbf{u}|^2
$$

```python
print("|u|          =", np.linalg.norm(u))
print("sqrt(u . u)  =", np.sqrt(np.dot(u, u)))
```
```
|u|          = 3.7416573867739413
sqrt(u . u)  = 3.7416573867739413
```

그리고 각도도 내적을 통해 구할 수 있습니다.

```python
cos_theta = np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))
print(f"u와 v 사이의 각도 = {np.degrees(np.arccos(cos_theta)):.2f}도")
```
```
u와 v 사이의 각도 = 12.93도
```

특히 내적이 0일 때, 두 벡터가 **직교(orthogonal)**한다고 합니다. 앞으로 지겹게 보게 될 단어니 눈에 익혀두세요.


## 복소수 벡터의 내적

여기서 앞 절의 이야기가 돌아옵니다. 파동함수가 복소수 값을 가진다고 했으니, 우리가 다룰 벡터도 성분이 복소수일 수 있겠죠. 그런데 성분이 복소수가 되면 내적의 정의를 조금 손봐야 합니다.

왜 그런지 직접 확인해봅시다. 복소 성분을 가진 벡터에 아무 생각 없이 원래 방식대로 자기 자신과의 내적을 취해보겠습니다.

```python
v = np.array([1 + 2j, 3 - 1j])

print("켤레 없이 계산 :", np.sum(v * v))
```
```
켤레 없이 계산 : (5-2j)
```

*엥?* 크기의 제곱을 구했는데 복소수가 나왔습니다. 벡터의 길이가 $5-2i$라는 건 말이 안 되죠. 길이는 실수여야 하고, 음수가 되어도 곤란합니다.  
해결책은 앞에서 이미 봤습니다. 한쪽에 켤레복소수를 씌우면 됩니다. 일반적으로는 첫 번째 인자에 켤레를 씌웁니다. 그리고 내적은 점곱 대신 다음과 같이 표기하는 경우가 많습니다.

$$
\langle \mathbf{u}, \mathbf{v} \rangle = \sum_i u_i^{*}v_i
$$

```python
print("켤레 씌워서    :", np.sum(np.conj(v) * v))
print("np.vdot(v, v)  :", np.vdot(v, v))
print("|v|^2          :", np.linalg.norm(v) ** 2)
```
```
켤레 씌워서    : (15+0j)
np.vdot(v, v)  : (15+0j)
|v|^2          : 15.000000000000002
```

허수부가 깨끗하게 사라지고 0 이상의 실수인 15가 나왔습니다. 앞에서 $z^*z=|z|^2$이 항상 0 이상의 실수라고 했던 것, 그게 벡터로 확장된 것뿐입니다.

[[TIP]]
`np.dot`은 켤레를 씌우지 않습니다. 복소 벡터의 내적을 구할 때는 **`np.vdot`**을 쓰세요. 첫 번째 인자에 자동으로 켤레를 씌워줍니다. 실수 벡터에서는 둘이 같은 결과를 주기 때문에, 나중에 복소수가 등장했을 때 틀리기 쉬운 부분입니다.
[[/TIP]]

참고로 마지막 줄의 `15.000000000000002`처럼 소수점 끝이 지저분한 것은 부동소수점 계산의 한계 때문입니다. Python 프로그래밍을 하다보면 지겹게 만나는 문제죠. 나중에 0.2.1에서 다시 제대로 다루겠습니다.


## 기저와 정규직교기저

**기저(basis)**가 무엇이었는지 기억하시나요? 어떤 집합을 이루는 벡터들이 모두 **선형독립(linearly independent)**이고 이 벡터들의 **선형결합(linear combination)**으로 주어진 공간의 벡터를 모두 표현할 수 있다면 그 집합을 주어진 공간의 기저라고 불렀습니다.

특히, 기저 중에서도 다음 두 조건을 만족하는 것을 **정규직교기저(orthonormal basis)**라고 부릅니다.

- 각 기저 벡터의 크기가 1이다 (**정규**, normalized)
- 서로 다른 기저 벡터끼리는 직교한다 (**직교**, orthogonal)

수식으로는 이렇게 씁니다. 여기서 $\mathbf{e}_i$는 하나의 기저 벡터를 나타냅니다.

$$
\langle \mathbf{e}_i, \mathbf{e}_j \rangle = \delta_{ij}
$$

$\delta_{ij}$는 **Kronecker 델타**라는 기호로, $i = j$이면 1, $i \neq j$이면 0의 값을 가집니다. 그러니까 같은 기저끼리 내적을 하면 1이고, 다른 경우에는 모두 0이라는 뜻입니다. 이 기호는 앞으로 자주 만나게 될 겁니다.

중요한 건 **기저가 하나뿐이 아니라는 점**입니다. 가로/세로 축을 통째로 30도 돌려놓아도 여전히 훌륭한 정규직교기저입니다. 확인해볼까요?

```python
th = np.pi / 6  # 30도

e1 = np.array([np.cos(th), np.sin(th)])
e2 = np.array([-np.sin(th), np.cos(th)])

print("e1 . e1 =", round(np.dot(e1, e1), 12))
print("e2 . e2 =", round(np.dot(e2, e2), 12))
print("e1 . e2 =", round(np.dot(e1, e2), 12))
```
```
e1 . e1 = 1.0
e2 . e2 = 1.0
e1 . e2 = 0.0
```

크기는 각각 1이고 서로 직교하네요. 조건을 완벽히 만족합니다.


## 계수는 곧 내적이다

여기가 이 절의 핵심입니다.

어떤 벡터 $\mathbf{v}$를 정규직교기저로 펼쳐 쓴다고 해봅시다. 다시 말해, 정규직교기저를 이루는 벡터들($\mathbf{e}_i$)의 선형결합으로 표현한다고 해봅시다.

$$
\mathbf{v} = c_1\mathbf{e}_1 + c_2\mathbf{e}_2 + \cdots
$$

이때 계수 $c_i$는 어떻게 구할까요? 연립방정식을 풀어야 할 것 같지만, 정규직교기저에서는 놀랍도록 간단합니다. **양변에 $\mathbf{e}_i$를 내적하면** 됩니다. 서로 다른 기저끼리는 직교이기 때문에 나머지 항은 전부 0으로 사라지고 $c_i$만 살아남거든요.

$$
c_i = \langle \mathbf{e}_i, \mathbf{v} \rangle
$$

$$
\mathbf{v} = \sum_i \langle \mathbf{e}_i, \mathbf{v} \rangle \mathbf{e}_i
$$

말로 풀면 이렇습니다. 어떤 벡터가 특정 기저 방향으로 얼마나 있는지 알고 싶으면, 그 기저와 내적하면 된다. 아까 내적이 "얼마나 같은 방향을 보는지"를 알려준다고 했던 것과 비슷한 이야기죠. 다만, 복소 벡터에서는 내적이 복소수가 될 수 있으므로, 단순한 각도보다는 두 벡터의 ‘겹침 정도'로 이해하는 편이 좋습니다.

아까 만든 30도 돌린 기저로 $\mathbf{v}=(3, 4)$를 펼쳐보겠습니다.

```python
v = np.array([3.0, 4.0])

c1 = np.dot(e1, v)
c2 = np.dot(e2, v)
print(f"c1 = {c1:.4f}")
print(f"c2 = {c2:.4f}")

# 계수로 다시 조립해서 원래 벡터가 나오는지 확인
v_rec = c1 * e1 + c2 * e2
print("복원된 v =", np.round(v_rec, 10))
print("원래 v와 같은가요?", np.allclose(v, v_rec))
```
```
c1 = 4.5981
c2 = 1.9641
복원된 v = [3. 4.]
원래 v와 같은가요? True
```

내적 두 번으로 계수를 구했고, 그 계수로 원래 벡터를 정확히 복원했습니다. 연립방정식은 한 번도 풀지 않았습니다.

같은 벡터가 기저에 따라 $(3, 4)$가 되기도 하고 $(4.5981, 1.9641)$이 되기도 한다는 점을 눈여겨봐 주세요. 벡터 자체는 그대로인데 우리가 어떤 자로 재느냐에 따라 숫자가 달라지는 것입니다. 여기서는 같은 공간 안에서 기저만 회전했습니다. 실제 양자화학에서는 기저를 어떻게 선택하느냐가 계산의 양과 시간뿐 아니라 예측 정확도에도 영향을 줍니다.
