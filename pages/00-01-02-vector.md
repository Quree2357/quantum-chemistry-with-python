## 내적의 두 얼굴

벡터의 내적(inner product)은 성분끼리 곱해서 더하는 것이었죠.

$$
\mathbf{a}\cdot\mathbf{b} = a_1b_1 + a_2b_2 + a_3b_3
$$

```python
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

print("a . b =", np.dot(a, b))
print("직접 계산:", 1*4 + 2*5 + 3*6)
```
```
a . b = 32
직접 계산: 32
```

그런데 내적에는 **계산법**과 **의미**라는 두 얼굴이 있습니다. 위의 식은 계산법이고, 의미 쪽은 이렇습니다.

$$
\mathbf{a}\cdot\mathbf{b} = |\mathbf{a}||\mathbf{b}|\cos\theta
$$

여기서 $\theta$는 두 벡터가 이루는 각도입니다. 즉 내적은 **두 벡터가 얼마나 같은 방향을 보고 있는지**를 알려주는 값입니다. 완전히 같은 방향이면 최대, 직각이면 0, 반대 방향이면 음수가 되죠.

이 두 얼굴이 같은 것이라는 게 사실 꽤 신기한 일입니다. 성분을 곱해서 더했을 뿐인데 각도가 튀어나오니까요. 어쨌든 이 덕분에 내적 하나로 여러 가지를 할 수 있게 됩니다.

먼저 **자기 자신과의 내적**은 크기의 제곱이 됩니다. 자기 자신과는 각도가 0이니 $\cos\theta = 1$이겠죠.

$$
\mathbf{a}\cdot\mathbf{a} = |\mathbf{a}|^2
$$

```python
print("|a|          =", np.linalg.norm(a))
print("sqrt(a . a)  =", np.sqrt(np.dot(a, a)))
```
```
|a|          = 3.7416573867739413
sqrt(a . a)  = 3.7416573867739413
```

그리고 **각도**도 내적을 뒤집으면 구할 수 있습니다.

```python
cos_theta = np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))
print(f"a와 b 사이의 각도 = {np.degrees(np.arccos(cos_theta)):.2f}도")
```
```
a와 b 사이의 각도 = 12.93도
```

특히 **내적이 0이면 두 벡터는 직교(orthogonal)한다**고 합니다. 앞으로 지겹게 보게 될 단어니 눈에 익혀두세요.


## 복소수 벡터에서는 켤레를 씌웁니다

여기서 0.1.1의 이야기가 돌아옵니다. 파동함수가 복소수 값을 가진다고 했으니, 우리가 다룰 벡터도 성분이 복소수일 수 있겠죠. 그런데 성분이 복소수가 되면 내적 정의를 조금 손봐야 합니다.

왜 그런지 직접 확인해봅시다. 복소 성분을 가진 벡터에 아무 생각 없이 원래 방식대로 자기 자신과의 내적을 취해보겠습니다.

```python
v = np.array([1+2j, 3-1j])

print("켤레 없이 계산 :", np.sum(v * v))
```
```
켤레 없이 계산 : (5-2j)
```

*어라?* 크기의 제곱을 구했는데 복소수가 나왔습니다. 벡터의 길이가 $5-2i$라는 건 말이 안 되죠. 길이는 실수여야 하고, 음수가 되어도 곤란합니다.

해결책은 0.1.1에서 이미 봤습니다. **한쪽에 켤레복소수를 씌우면** 됩니다.

$$
\mathbf{u}\cdot\mathbf{v} = \sum_i u_i^{*}v_i
$$

```python
print("켤레 씌워서    :", np.sum(np.conj(v) * v))
print("np.vdot(v, v)  :", np.vdot(v, v))
print("|v|^2          :", np.linalg.norm(v)**2)
```
```
켤레 씌워서    : (15+0j)
np.vdot(v, v)  : (15+0j)
|v|^2          : 15.000000000000002
```

허수부가 깨끗하게 사라지고 양수인 실수가 남았습니다. 0.1.1에서 $z^*z=|z|^2$이 항상 0 이상의 실수라고 했던 것, 그게 벡터로 확장된 것뿐입니다.

> **NumPy 팁**
> `np.dot`은 켤레를 씌우지 않습니다. 복소 벡터의 내적을 구할 때는 **`np.vdot`**을 쓰세요. 첫 번째 인자에 자동으로 켤레를 씌워줍니다. 실수 벡터에서는 둘이 같은 결과를 주기 때문에, 나중에 복소수가 등장했을 때 조용히 틀리기 쉬운 부분입니다.

참고로 마지막 줄의 `15.000000000000002`처럼 소수점 끝이 지저분한 것은 부동소수점 계산의 한계 때문입니다. 앞으로도 종종 보게 될 텐데, 0.2.1에서 제대로 다루겠습니다.


## 기저: 세상을 재는 자

이제 **기저(basis)** 이야기를 해봅시다. 우리가 $(3, 4)$라는 좌표를 쓸 때, 사실 여기에는 숨은 약속이 있습니다. "가로 방향으로 3만큼, 세로 방향으로 4만큼"이라는 약속이죠. 이 '가로 방향'과 '세로 방향'에 해당하는 벡터들이 바로 기저입니다.

기저 중에서도 다음 두 조건을 만족하는 것을 **정규직교기저(orthonormal basis)**라고 부릅니다.

- 각 기저 벡터의 크기가 1이다 (**정규**, normalized)
- 서로 다른 기저 벡터끼리는 직교한다 (**직교**, orthogonal)

수식으로는 이렇게 한 줄로 씁니다.

$$
\mathbf{e}_i \cdot \mathbf{e}_j = \delta_{ij}
$$

$\delta_{ij}$는 **크로네커 델타(Kronecker delta)**로, $i=j$이면 1, 아니면 0인 기호입니다. 앞으로 자주 만나게 됩니다.

중요한 건 **기저가 하나뿐이 아니라는 점**입니다. 가로/세로 축을 통째로 30도 돌려놓아도 여전히 훌륭한 정규직교기저입니다. 확인해볼까요?

```python
th = np.pi / 6   # 30도

e1 = np.array([ np.cos(th), np.sin(th)])
e2 = np.array([-np.sin(th), np.cos(th)])

print("e1 . e1 =", round(np.dot(e1, e1), 12))
print("e2 . e2 =", round(np.dot(e2, e2), 12))
print("e1 . e2 =", round(np.dot(e1, e2), 12))
```
```
e1 . e1 = 1.0
e2 . e2 = 1.0
e1 . e2 = 0.0
```

크기는 각각 1이고 서로 직교하네요. 조건을 완벽히 만족합니다.


## 계수는 곧 내적입니다

여기가 이 절의 핵심입니다.

어떤 벡터 $\mathbf{v}$를 정규직교기저로 펼쳐 쓴다고 해봅시다.

$$
\mathbf{v} = c_1\mathbf{e}_1 + c_2\mathbf{e}_2 + \cdots
$$

이때 계수 $c_i$는 어떻게 구할까요? 연립방정식을 풀어야 할 것 같지만, 정규직교기저에서는 놀랍도록 간단합니다. **양변에 $\mathbf{e}_i$를 내적하면** 됩니다. 기저끼리 직교하니 나머지 항은 전부 0으로 사라지고 $c_i$만 살아남거든요.

$$
c_i = \mathbf{e}_i \cdot \mathbf{v}
$$

$$
\mathbf{v} = \sum_i (\mathbf{e}_i \cdot \mathbf{v})\,\mathbf{e}_i
$$

말로 풀면 이렇습니다. **어떤 벡터가 특정 기저 방향으로 얼마나 있는지 알고 싶으면, 그 기저와 내적하면 된다.** 아까 내적이 "얼마나 같은 방향을 보는지"를 알려준다고 했던 것과 정확히 통하는 이야기죠.

아까 만든 30도 기저로 $\mathbf{v}=(3,4)$를 펼쳐보겠습니다.

```python
v = np.array([3.0, 4.0])

c1 = np.dot(e1, v)
c2 = np.dot(e2, v)
print(f"c1 = {c1:.4f}")
print(f"c2 = {c2:.4f}")

# 계수로 다시 조립해서 원래 벡터가 나오는지 확인
v_rec = c1*e1 + c2*e2
print("복원된 v =", np.round(v_rec, 10))
print("원래 v와 같은가요?", np.allclose(v, v_rec))
```
```
c1 = 4.5981
c2 = 1.9641
복원된 v = [3. 4.]
원래 v와 같은가요? True
```

내적 두 번으로 계수를 구했고, 그 계수로 원래 벡터를 정확히 복원했습니다. 연립방정식은 한 번도 풀지 않았습니다.

같은 벡터가 기저에 따라 $(3, 4)$가 되기도 하고 $(4.5981, 1.9641)$이 되기도 한다는 점을 눈여겨봐 주세요. **벡터 자체는 그대로인데 우리가 어떤 자로 재느냐에 따라 숫자가 달라지는 것**입니다. 나중에 20장에서 SCF 계산을 할 때, 같은 계산을 어떤 기저에서 하느냐에 따라 난이도가 완전히 달라지는 장면을 보게 될 겁니다.

마지막으로 재미있는 성질 하나만 더 봅시다. 계수들을 제곱해서 더하면 어떻게 될까요?

```python
print(f"c1^2 + c2^2 = {c1**2 + c2**2:.6f}")
print(f"|v|^2       = {np.dot(v, v):.6f}")
```
```
c1^2 + c2^2 = 25.000000
|v|^2       = 25.000000
```

정확히 벡터 크기의 제곱과 같습니다. 기저를 어떻게 잡든 이 값은 변하지 않습니다. 벡터를 여러 방향으로 쪼갰지만 **전체 양은 보존된다**는 뜻이죠.

이 성질이 나중에 아주 중요해집니다. 6장에서 파동함수를 여러 상태로 펼치게 될 텐데, 그때 각 계수의 제곱이 **그 상태가 측정될 확률**이 됩니다. 그리고 방금 본 성질 덕분에 그 확률들을 전부 더하면 정확히 1이 되죠. 확률의 합이 1이라는 당연한 사실이, 사실은 여기 있는 이 성질이었던 겁니다.
