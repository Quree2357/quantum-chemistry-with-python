## 미분방정식

우리가 아는 보통의 방정식은 이렇게 생겼습니다.

$$
x^2 - 5x + 6 = 0
$$

여기서 미지수는 숫자 $x$이고, 풀면 $x = 2, 3$이라는 숫자가 나옵니다.

그런데 이런 형태의 방정식도 있습니다.

$$
\frac{d^2}{dx^2}y - 5 \frac{d}{dx}y + 6y = 0
$$

여기서는 미지수가 함수 $y(x)$입니다. 이렇게 미지의 함수와 그 도함수가 함께 들어 있는 방정식을 **미분방정식(differential equation)**이라고 합니다.  

자연과학에서 미분방정식이 이렇게 자주 나오는 이유는 간단합니다. 자연법칙 대부분이 "변화율"에 관한 것이기 때문입니다. Newton의 $F=ma$에서 가속도는 위치를 두 번 미분한 것이고, 전기장과 자기장은 서로의 변화율에 따라 움직이고, 이런 식이니까요.


## ODE와 PDE

미분방정식을 분류하는 기준 중 하나는 어떤 변수에 대해 미분한 것이냐는 것입니다.

또 하나의 기준인 **계(order)**는 방정식에 나오는 가장 높은 차수의 미분입니다. 예를 들어, $y' + 2y = 0$은 1계, $y'' - 4y = 0$은 2계죠.

독립변수의 개수로 나누기도 합니다. 독립변수가 하나뿐이면 **상미분방정식(ODE, ordinary differential equation)**, 둘 이상이면 **편미분방정식(PDE, partial differential equation)**이라고 부릅니다.

$$
\frac{d^2y}{dx^2} + y = 0 \quad \text{(ODE)}
\qquad\qquad
\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0 \quad \text{(PDE)}
$$

PDE에서 $\partial$ 기호를 쓰는 이유는, 변수가 여러 개일 때 "다른 변수는 고정하고 이 변수로만 미분한다"는 뜻을 나타내기 위해서입니다. **편미분(partial differentiation)**이라고 부르죠.  
예상하셨겠지만, PDE는 ODE에 비해 훨씬 어렵습니다. 3장에서 변수분리법이라는 기술로 PDE를 여러 개의 ODE로 쪼개서 푸는 것을 보게 될 텐데, 그게 통하는 경우가 오히려 드물다는 것도 알게 되실 겁니다.


## 선형과 비선형

미지 함수 $y$와 그 도함수들이 1차로만 나타나면 그 방정식을 **선형(linear)**이라고 합니다.

$$
y'' + 3y' + 2y = e^x \quad \text{(선형)}
\qquad
y'' + y^2 = 0 \quad \text{(비선형)}
\qquad
y' + \sin y = 0 \quad \text{(비선형)}
$$

$y^2$이나 $\sin y$처럼 미지 함수가 1차가 아닌 형태로 들어가면 비선형입니다. ($x$나 $e^x$ 같은 항은 아무리 복잡해도 상관없습니다. 미지 함수 $y$에 대한 항이 아니니까요.)

이 구분이 결정적으로 중요합니다. 선형 미분방정식은 풀 수 있는 방법이 많지만, 비선형은 대부분 해석적으로 풀 수 없습니다. 다행히 Schrödinger 방정식은 선형입니다.

다만 완전히 안심하기는 이릅니다. 전자가 여러 개인 분자를 다룰 때 쓰는 Hartree-Fock 방법은 근사 과정에서 비선형 문제가 되어버리거든요. 방정식의 계수가 그 방정식의 해에 의존하는 구조라서, 답을 알아야 방정식을 세울 수 있고 방정식을 세워야 답을 알 수 있는 상황이 됩니다. 그래서 어림값에서 출발해 답이 안정될 때까지 반복 계산을 돌리게 되는데, 그것이 SCF라는 이름으로 불리는 절차입니다. 지금 이 얘기는 잊어버리셔도 됩니다!


## 제차와 비제차

선형 미분방정식은 이렇게 쓸 수 있습니다.

$$
a_n(x)y^{(n)} + \cdots + a_1(x)y' + a_0(x)y = g(x)
$$

좌변에는 미지 함수가 들어간 항들만 모아놓고, 우변 $g(x)$에는 미지 함수와 무관한 항을 몰아넣은 형태입니다. 이때

- $g(x) = 0$이면 **제차(homogeneous)**
- $g(x) \neq 0$이면 **비제차(nonhomogeneous)**

라고 부릅니다.  

제차 방정식에는 아주 좋은 성질이 있습니다. $y_1$과 $y_2$가 둘 다 해라면, 이들의 선형 결합도 해가 됩니다.

$$
y = c_1 y_1 + c_2 y_2
$$

이것을 **중첩원리(superposition principle)**라고 부릅니다. 이게 왜 대단한 일일까요? 잠깐 생각해보세요. 어떤 방법을 썼던 간에 일단 방정식을 만족하는 해들을 구하고 나면 자동으로 그 해들의 선형 결합이라는 해를 공짜로 얻게 되니까요.

양자역학에서 "전자가 여러 상태에 동시에 존재한다"는 그 유명한 중첩이, 사실은 여기서 나옵니다. 선형성 덕분에 양자상태들의 선형결합도 새로운 상태가 될 수 있습니다. 양자역학의 중첩원리는 이러한 선형 구조와 측정에 관한 물리적 해석이 결합된 것입니다. 그리고 0.1절에서 배운 선형대수가 양자역학에 그대로 통하는 이유도 이것입니다. 해들이 벡터 공간을 이루니까요.


## 상수계수 2계 제차 선형 ODE

그래서 미분방정식은 어떻게 푸는 건가요? 가장 쉬운 형태부터 살펴봅시다. 제일 쉬운 건 1계 제차 선형 ODE겠지만 그건 그냥 적분하면 풀리니까 패스하고요. 2계 제차 선형 ODE부터 봅시다. 계수는 모두 상수로 두고요.

$$
ay'' + by' + cy = 0
$$

푸는 방법은 놀랍도록 단순합니다. 일단 $y = e^{r x}$라고 찍어보는 것입니다.

왜 하필 지수함수일까요? 미분해도 모양이 안 바뀌는 유일한 함수이기 때문입니다. $y = e^{rx}$면 $y' = re^{rx}$, $y'' = r^2e^{rx}$이니 전부 $e^{rx}$의 상수배죠. 대입하면 다음과 같이 됩니다.

$$
(ar^2 + br + c)e^{rx} = 0
$$

$e^{r x}$은 절대 0이 될 수 없으니 이 식이 성립하려면 괄호 안이 0이어야 합니다.

$$
ar^2 + br + c = 0
$$

미분방정식이 이차방정식으로 바뀌었습니다! 이 식을 **특성방정식(characteristic equation)**이라고 부릅니다. 이 방법은 2계뿐만이 아니라 더 높은 n계 제차 선형 ODE에서도 사용할 수 있습니다. 그러면 특성방정식이 n차 다항식으로 나오겠죠.

0.1.3에서 고유값을 구할 때 나왔던 특성방정식 $\det(A - \lambda I) = 0$과 이름이 같죠. 우연이 아닙니다. 둘 다 "연산자를 상수로 바꿔주는 값을 찾는" 문제거든요.

이차방정식이니 근의 형태가 세 가지 경우로 나뉩니다.

### 1) 서로 다른 두 실근

판별식이 양수일 때입니다. 근이 $r_1, r_2$라면 해는 다음과 같이 쓸 수 있습니다.

$$
y = C_1e^{r_1x} + C_2e^{r_2x}
$$

예를 들어 $y'' - 3y' + 2y = 0$의 특성방정식은 $r^2 - 3r + 2 = 0$이고 근은 $r = 1, 2$입니다. 따라서 $y = C_1e^x + C_2e^{2x}$가 됩니다.

### 2) 켤레복소근

판별식이 음수일 때입니다. 근이 $r_1 = \alpha + i\beta$와 $r_2 = \alpha - i\beta$라면 형식적으로는

$$
y = C_1e^{(\alpha + i\beta)x} + C_2e^{(\alpha - i\beta)x}
$$

인데, 여기서 0.1.1의 Euler의 공식이 등장합니다. $e^{i\beta x} = \cos\beta x + i\sin\beta x$를 쓰면 이렇게 정리됩니다.

$$
y = e^{\alpha x}\left(C_1\cos\beta x + C_2\sin\beta x\right)
$$

삼각함수가 되었네요! 즉, 켤레복소근이 나오면 해에 진동하는 항이 나타난다는 뜻입니다.

우리에게 가장 중요한 경우가 바로 이겁니다. 우선 가장 간단한 형태를 보죠. $\alpha=0$이고 $\beta=k$라고 해봅시다. 이 경우의 해는 다음과 같습니다.

$$
y = C_1\cos kx + C_2\sin kx
$$

0.1.5에서 기저로 썼던 사인 함수들이 어디서 왔는지 이제 설명이 되네요. SymPy를 사용해서 다시 확인해봅시다.

```python
import sympy as sp

x = sp.symbols("x")
y = sp.Function("y")
k = sp.symbols("k", positive=True)

ode = sp.Eq(y(x).diff(x, 2), -(k**2) * y(x))
print(sp.dsolve(ode, y(x)))
```
```
Eq(y(x), C1*sin(k*x) + C2*cos(k*x))
```

### 3) 중근

판별식이 0일 때입니다. 근이 $r$ 하나뿐이죠. 그런데 문제가 있습니다. 2계 방정식이니 해가 두 개 필요한데 근은 하나뿐입니다.

$y_1 = e^{rx}$ 말고 두 번째 해는 어디서 찾을까요? 답은 조금 뜬금없게 들리는데, 바로 $y_2 = xe^{rx}$입니다.

$$
y = (C_1 + C_2x)e^{rx}
$$

정말 해가 맞는지 확인해봅시다. $y'' - 4y' + 4y = 0$은 특성방정식이 $(r-2)^2 = 0$이라 $r = 2$가 중근입니다.

```python
expr = x * sp.exp(2 * x)
print(sp.simplify(sp.diff(expr, x, 2) - 4 * sp.diff(expr, x) + 4 * expr))
```
```
0
```

정말 0이 나오네요. $xe^{2x}$도 해가 맞습니다.

세 경우를 그림으로 비교하면 성격이 확연히 다릅니다.

```python
import numpy as np
import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 3, figsize=(13, 3.8))
xx = np.linspace(0, 3, 400)

for c1, c2 in [(1, 0), (0, 1), (1, -0.5)]:
    axes[0].plot(xx, c1 * np.exp(xx) + c2 * np.exp(2 * xx), lw=1.8)
axes[0].set_title("distinct real roots")
axes[0].set_ylim(0, 30)

for c1, c2 in [(1, 0), (0, 1), (1, -1)]:
    axes[1].plot(xx, (c1 + c2 * xx) * np.exp(2 * xx), lw=1.8)
axes[1].set_title("repeated root")
axes[1].set_ylim(-30, 30)

xo = np.linspace(0, 4 * np.pi, 500)
for c1, c2 in [(1, 0), (0, 1), (1, 1)]:
    axes[2].plot(xo, c1 * np.cos(2 * xo) + c2 * np.sin(2 * xo), lw=1.8)
axes[2].set_title("complex conjugate roots")

for ax in axes:
    ax.set_xlabel("x")
    ax.grid(alpha=0.3)
    ax.axhline(0, color="black", lw=0.6)
plt.show()
```

## Wronskian: 두 해가 정말 다른 해인가

앞에서 계속 "2계 방정식은 해가 두 개 필요하다"고 했습니다. 그런데 아무 해나 두 개 있으면 되는 게 아닙니다. 서로 선형 독립인 해가 두 개여야 합니다.

$e^x$와 $3e^x$는 둘 다 해일 수는 있지만 사실상 같은 해죠. 상수배일 뿐이니까요. 이런 걸 가지고 $C_1e^x + C_2(3e^x) = (C_1+3C_2)e^x$를 만들어봐야 결국 $e^x$의 상수배 하나입니다.

두 함수가 선형 독립인지 판정하는 도구가 바로 **Wronskian**입니다.

$$
W(y_1, y_2) = \begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix} = y_1y_2' - y_2y_1'
$$

행렬식 모양이죠. 여기서 $W \neq 0$이면 두 해는 선형 독립입니다.

0.1.4에서 행렬식이 나왔던 것과 같은 논리입니다. 행렬식이 0이면 열벡터들이 종속이라는 그 이야기죠. 여기서는 열이 함수로 바뀐 것뿐입니다.

```python
X = sp.symbols("X")


def wronskian(f, g):
    return sp.simplify(f * sp.diff(g, X) - g * sp.diff(f, X))


print("e^x, e^2x   :", wronskian(sp.exp(X), sp.exp(2 * X)))
print("e^2x, x e^2x:", wronskian(sp.exp(2 * X), X * sp.exp(2 * X)))
print("sin, cos    :", wronskian(sp.sin(X), sp.cos(X)))
print("e^x, 3e^x   :", wronskian(sp.exp(X), 3 * sp.exp(X)))
```
```
e^x, e^2x   : exp(3*X)
e^2x, x e^2x: exp(4*X)
sin, cos    : -1
e^x, 3e^x   : 0
```

앞의 셋은 0이 아니니 선형 독립이고, 마지막 $e^x$와 $3e^x$는 0이 나왔으니 선형 종속입니다. 예상대로죠.

그리고 두 번째 줄을 보세요. $e^{2x}$와 $xe^{2x}$의 Wronskian이 $e^{4x} \neq 0$입니다. 중근일 때 $xe^{rx}$를 두 번째 해로 쓰는 것이 정당하다는 말이 이겁니다. 아까는 그냥 "확인해보니 해가 맞더라"였는데, 이제는 그것이 첫 번째 해와 독립인 진짜 두 번째 해라는 것까지 확인한 셈입니다.

[[TIP]]
$n$계 선형 미분방정식의 일반해는 $n$개의 독립인 해의 선형결합으로 이루어집니다. 어디서 많이 본 구조 아닌가요? 0.1.2에서 $n$차원 벡터공간의 기저가 $n$개의 독립인 벡터로 이루어진다고 했던 그것입니다. 실제로 제차 선형 미분방정식의 해집합은 벡터공간을 이루고, 독립인 해들이 그 기저 역할을 합니다. 함수가 벡터라는 이야기가 여기서도 반복되는 거죠.
[[/TIP]]


## 초기값 문제와 경계값 문제

미분방정식의 해가 하나가 아니라고 했던 것 기억하시나요? $y'' + k^2y = 0$의 일반해는 $C_1\cos kx + C_2\sin kx$였고, $C_1$과 $C_2$가 아무 값이나 될 수 있으니 해가 무한히 많습니다. 특정한 해 하나를 고르려면 조건을 줘야 하죠. 그런데 조건을 주는 방식에는 여러 가지가 있습니다.  

**초기값 문제(IVP, initial value problem)**는 한 지점에서 함숫값과 도함수값을 함께 주는 방식입니다. 보통은 $x=0$에서의 값을 줍니다.  

$$
y(0) = 0, \qquad y'(0) = 1
$$

물체를 던질 때 초기 위치와 초기 속도를 주는 상황과 같습니다. 이 경우 해는 항상 존재하고 유일합니다.

반면에, **경계값 문제(BVP, boundary value problem)**는 구간의 양 끝에서 함숫값을 주는 방식입니다.

$$
y(0) = 0, \qquad y(L) = 0
$$

출발점과 도착점을 지정하는 것이죠. 0.2.3에서 만든 행렬에 박혀 있던 조건이 정확히 이것이었습니다.

*조건을 두 개 주는 건 똑같은데, 그거나 그거나 아냐?*

엄청나게 다릅니다. 직접 보여드리죠.


## 내일의 값을 향해 쏴라

예를 들어, $y'' = -k^2y$를 $y(0) = 0$, $y'(0) = 1$에서 출발시켜 $x = L$까지 계산해봅시다. 이건 초기값 문제이므로 해가 반드시 하나 나옵니다. SciPy에 전용 함수 `solve_ivp`가 있습니다.

```python
from scipy.integrate import solve_ivp

L = 1.0


def shoot(k, n=400):
    def f(x, y):
        return [y[1], -(k**2) * y[0]]

    s = solve_ivp(f, [0, L], [0.0, 1.0], t_eval=np.linspace(0, L, n), rtol=1e-12, atol=1e-14)
    return s.t, s.y[0]


for k in [1.0, 2.0, 3.0, np.pi, 4.0, 5.0, 6.0, 2 * np.pi, 7.0]:
    print(f"k = {k:6.4f}   y(L) = {shoot(k)[1][-1]:+.6f}")
```

여기서 질문을 바꿔봅시다. 만약 우리가 원하는 것이 경계값 문제, 즉 $y(L) = 0$까지 만족하는 해라면요? 위 표에서 그런 $k$가 보이시나요?

### 무슨 일이 일어난 걸까요

$k$는 원래 연속적인 값입니다. 1.5도 되고 5.73도 되고 아무 값이나 될 수 있죠. 방정식 자체도, 해도, 전부 연속적입니다. 그런데 양 끝을 동시에 묶어놓자 $k$가 불연속적인 값만 가질 수 있게 되었습니다.

$$
k = \frac{n\pi}{L}, \qquad n = 1, 2, 3, \ldots
$$

연속적인 세계에서 정수가 튀어나온 겁니다. 어디서도 정수 조건을 가정하지 않았는데 말이죠. 그저 "출발점과 도착점에서 모두 0이어야 한다"고 요구했을 뿐입니다.

이것이 초기값 문제와 경계값 문제의 결정적 차이입니다.

| | 초기값 문제 | 경계값 문제 |
|---|---|---|
| 조건을 주는 곳 | 한 점 | 양 끝 |
| 해의 존재 | 항상 유일하게 존재 | 없을 수도, 무한히 많을 수도 |
| 매개변수 | 아무 값이나 가능 | **특정한 값만 허용** |
| 푸는 법 | `solve_ivp` | 고유값 문제로 변환 |

마지막 줄이 중요합니다. 경계값 문제는 방금 본 것처럼 $k$를 하나씩 넣어보며 찾을 수도 있지만(이 방법을 **슈팅법(shooting method)**이라고 부릅니다), 훨씬 나은 길이 있습니다. 0.2.3에서 만든 그 행렬이죠.

$$
y'' = -k^2 y
\quad\Longrightarrow\quad
-D_2\,\mathbf{y} = k^2\mathbf{y}
$$

허용되는 $k$값들은 곧 행렬의 고유값과 연관됩니다. 슈팅법처럼 하나씩 찾아 헤맬 필요 없이, `np.linalg.eigh` 한 번이면 허용되는 값 전부가 한꺼번에 쏟아져 나옵니다.

정말 그런지 확인해봅시다.

```python
def second_derivative_matrix(N, h):
    return (np.eye(N, k=1) - 2 * np.eye(N) + np.eye(N, k=-1)) / h**2


N = 2000
h = L / (N + 1)

eigvals = np.linalg.eigvalsh(-second_derivative_matrix(N, h))

print("행렬에서 얻은 k          :", np.round(np.sqrt(eigvals[:4]), 5))
print("이론값 n*pi/L (n=1...4) :", [round(n * np.pi / L, 5) for n in range(1, 5)])
```
```
행렬에서 얻은 k          : [ 3.14159  6.28318  9.42477 12.56635]
이론값 n*pi/L (n=1...4) : [3.14159, 6.28319, 9.42478, 12.56637]
```

정확히 일치합니다. 슈팅법으로 하나씩 찾아냈던 값들이 고유값 계산 한 번에 전부 나왔습니다.

[[TIP]]
지금은 순수하게 수학 이야기로만 했습니다. $y$가 무엇이고 $k$가 무엇인지는 정하지 않았죠. 4장에서 이 $y$를 파동함수로, $k$를 에너지와 연결된 양으로 해석하게 될 텐데, 그때 에너지가 불연속적이 되는 이유가 바로 여기서 본 구조입니다. 물리적인 신비가 아니라 경계값 문제의 수학적 성질인 것이죠.
[[/TIP]]


모든 미분방정식을 특성방정식으로 풀 수 있다면 얼마나 좋을까요? 하지만 그럴 수는 없습니다... 그래서 우리는 0.2.3의 길을 택합니다. 미분을 행렬로 바꾸고, 미분방정식을 고유값 문제로 바꾸고, 컴퓨터에게 넘기는 것이죠. 이것이 계산화학이라는 분야가 존재하는 이유이고, 여러분이 0장을 견뎌낸 이유이기도 합니다.


## 정리하며

정말 긴 여정이었습니다. 지금까지의 내용을 정리해봅시다.

0.1절에서 우리는 선형대수를 다시 세웠습니다. 벡터와 내적에서 시작해 행렬과 고유값을 지나, 마지막에 **함수도 벡터**라는 것을 확인했죠.

0.2절에서는 미적분을 컴퓨터의 언어로 옮겼습니다. 미분은 차분이 되고 적분은 덧셈이 되었으며, 무엇보다 **미분 연산자가 행렬**이 되었습니다.

이제 0.1.5에서 만들다 만 대응표를 완성할 수 있습니다.

| 유한차원 (선형대수) | 무한차원 (양자역학) |
|---|---|
| 벡터 $\mathbf{v}$ | 함수 $f(x)$, 파동함수 $\psi(x)$ |
| 성분 $v_i$ | 함숫값 $f(x)$ |
| 내적 $\sum_i u_i^*v_i$ | $\int f^*g\,dx$ |
| 직교(내적이 0) | 직교(내적 적분이 0) |
| 정규직교기저 $\mathbf{e}_i$ | 정규직교 함수계 $e_n(x)$ |
| 전개 계수 $c_i = \langle \mathbf{e}_i,\mathbf{v} \rangle$ | $c_n = \langle e_n , f \rangle$ |
| 행렬 $A$ | 연산자 $\hat{A}$ |
| 대칭·에르미트 행렬 | 에르미트 연산자 |
| 고유벡터·고유값 | 고유함수·고유값 |

이제 진짜 양자화학을 시작할 준비가 되었습니다. 1장에서 뵙겠습니다.
