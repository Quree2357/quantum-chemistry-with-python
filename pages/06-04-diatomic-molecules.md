6.1절에서 수소 분자의 퍼텐셜 에너지 곡선이 어떻게 생겼었는지 기억하시나요? 우리는 최소점에만 관심이 있어서 포물선으로 근사해도 괜찮다고 했었죠. 그런데 6.3절에서 계산값과 실측값이 다르다는 것을 봤습니다. 힘 상수 값도 안 맞고 적외선 분광 스펙트럼에서 피크가 한 개만 나타나는 것도 아니죠. 좀 더 퍼텐셜 곡선을 잘 묘사할 수 있는 근사가 필요합니다.


## Morse 퍼텐셜

1929년 Morse라는 물리학자는 이원자 분자의 퍼텐셜 에너지 곡선을 잘 근사할 수 있는 모델을 발표합니다. 사실 6.1절에서 수소 분자의 퍼텐셜 에너지를 그릴 때 썼던 게 바로 이 모델이었습니다.

$$
V(x) = D_e\left(1 - e^{-ax}\right)^2, \qquad a=\sqrt{\frac{k}{2 D_e}}
$$

여기서 $x = r - r_e$는 평형 위치로부터의 변위이고, $D_e$는 퍼텐셜 우물의 깊이, 즉 해리 에너지(정확히는 실제 해리 에너지보다 큰 값이지만 편의상 이렇게 부르겠습니다.)이며, $a$는 폭을 정하는 매개변수로 힘 상수 $k$와 연관되어 있습니다.

이 함수의 성질을 봅시다.

- $x = 0$이면 $V = 0$ (최소점)
- $x \to \infty$이면 $e^{-ax} \to 0$이므로 $V \to D_e$ (결합이 끊어짐)
- $x \to -\infty$이면 $e^{-ax}$가 폭발하므로 $V \to \infty$ (핵끼리 밀어냄)

실제 퍼텐셜의 모양을 제대로 흉내 냅니다. 그리고 최소점 근처에서 전개하면 포물선이 나오죠.

$$
V \approx D_e a^2 x^2 = \frac{1}{2} \underbrace{(2 D_e a^2)}_{k} x^2
$$

HCl 분자로 계산해봅시다. 실측값은 $D_e = 37244$ cm⁻¹, $\omega_e = 2990.95$ cm⁻¹입니다.

```python
import numpy as np
from scipy.constants import hbar, u, e, c, h

De, we = 37244.0, 2990.95  # cm^-1, HCl 실측값
mu = 1.008 * 34.969 / (1.008 + 34.969) * u

a = (
    2 * np.pi * c * 100 * we * np.sqrt(mu / (2 * De * 100 * h * c))
)
k = 2 * De * 100 * h * c * a**2

print(f"D_e = {De * 100 * h * c/e:.4f} eV")
print(f"a   = {a:.4e} 1/m")
print(f"k   = {k:.1f} N/m   (6.3절에서 구한 값 516.4)")
```
```
D_e = 4.6177 eV
a   = 1.8682e+10 1/m
k   = 516.4 N/m   (6.3절에서 구한 값 516.4)
```

같은 값이 나옵니다. Morse 퍼텐셜의 곡률이 곧 힘 상수니까요.


## 코드로 풀어보기

4.4절의 코드에서 퍼텐셜만 갈아끼우면 됩니다.

```python
def solve(N, xmin, xmax, potential):
    x = np.linspace(xmin, xmax, N + 2)[1:-1]
    dx = x[1] - x[0]
    D2 = (-2 * np.eye(N) + np.eye(N, k=1) + np.eye(N, k=-1)) / dx**2
    E, psi = np.linalg.eigh(-(hbar**2) / (2 * mu) * D2 + np.diag(potential(x)))
    return x, E, psi


V_morse = lambda x: De * 100 * h * c * (1 - np.exp(-a * x)) ** 2
V_harmonic = lambda x: 0.5 * k * x**2

x, E_m, psi_m = solve(3000, -0.6e-10, 3.5e-10, V_morse)
_, E_h, psi_h = solve(3000, -0.6e-10, 3.5e-10, V_harmonic)

print(f"{'v':>3} {'Morse':>10} {'조화':>8} {'간격(M)':>9} {'간격(H)':>9}")
for v in range(8):
    gap_m = (E_m[v + 1] - E_m[v]) / (100 * h * c)
    gap_h = (E_h[v + 1] - E_h[v]) / (100 * h * c)
    print(
        f"{v:3d} {E_m[v]/ (100 * h * c):10.1f} {E_h[v]/ (100 * h * c):10.1f} {gap_m:10.1f} {gap_h:10.1f}"
    )
```

## 배진동이 나타나는 이유

아직 의문점이 하나 더 있습니다. 실제 적외선 분광 스펙트럼에서는 피크가 여러 개 나타난다는 것이요. 6.3절에서 선택 규칙은 $\Delta v = \pm 1$이라고 했습니다. 그런데 사실 이 규칙에는 전제가 있습니다. 퍼텐셜이 정확히 조화라는 것, 그리고 쌍극자 모멘트가 변위에 정확히 비례한다는 것이죠.

그런데 실제 퍼텐셜은 비조화이고, 쌍극자 모멘트도 변위에 선형적으로 비례하는 게 아닙니다. 그래서 $\Delta v = \pm 2, \pm 3$인 전이도 약하게 일어날 수 있습니다. 이런 전이를 **배진동(overtone)**이라고 부릅니다.  

직접 계산해봅시다.

```python
transitions = [(0, 1, "fundamental"), (0, 2, "1st overtone"), (0, 3, "2nd overtone")]

print(f"{'전이':>13} {'Morse 계산':>11} {'HCl 실측':>8}")
observed = {1: 2885.3, 2: 5665.0, 3: 8339.0}
for vi, vf, name in transitions:
    calc = (E_m[vf] - E_m[vi]) / (100 * h * c)
    print(f"{name:>14} {calc:12.1f} {observed[vf]:10.1f}")
```
```
           전이    Morse 계산   HCl 실측
   fundamental       2870.8     2885.3
  1st overtone       5621.5     5665.0
  2nd overtone       8252.0     8339.0
```

여기서 눈여겨볼 것이 있습니다. 배진동이 기본 진동의 정확히 2배, 3배로 나타나지 않습니다.

$$
2 \times 2885.3 = 5770.6 \quad\text{vs}\quad \text{실측 } 5665.0
$$

100 cm⁻¹쯤 낮죠. 조화 진동자라면 정확히 2배여야 하는데 말이죠. 바로 비조화성의 직접적인 증거입니다. 그리고 이 관계를 이용하면 스펙트럼에서 거꾸로 $\omega_e$와 $\omega_ex_e$를 구할 수 있습니다. 실제로 분광학자들이 하는 일이 이겁니다. 기본 진동과 배진동의 위치를 측정해서 두 상수를 뽑아내죠. 그리고 6.3절에서 우리가 쓴 $\omega_e$가 바로 그렇게 얻은 값입니다.

[[TIP]]
배진동은 기본 진동보다 훨씬 약합니다. 보통 1/10에서 1/100 수준이죠. 그래서 일반적인 IR 스펙트럼에서는 잘 안 보이고, 근적외선(NIR) 영역에서 주로 관측됩니다.  
그런데 이 약한 흡수가 실용적으로 중요한 곳이 있습니다. 근적외선 분광법(NIR spectroscopy)은 배진동을 이용하는데, 흡수가 약하다는 것이 오히려 장점이 됩니다. 빛이 시료 깊숙이 들어갈 수 있으니까요. 곡물의 수분 함량이나 의약품 정제의 성분을 비파괴로 분석할 때 쓰입니다.
[[/TIP]]


## 계산화학의 스케일링 팩터

23장에서 계산화학으로 진동수를 구하게 될 텐데, 그때 컴퓨터가 하는 일은 이렇습니다. 퍼텐셜 곡면의 2차 미분을 계산해서 힘 상수를 얻고, 거기서 진동수를 뽑아내죠. 6.1절에서 본 $k = V''(r_e)$ 그대로입니다.

그런데 이 방식은 조화 근사입니다. 최소점에서의 곡률만 보니까요. 그러니 계산 결과는 $\omega_e$에 해당하고, 실제 관측되는 $\nu_0$보다 높게 나옵니다.

그래서 계산화학에서는 계산된 진동수에 **스케일링 팩터(scaling factor)**를 곱합니다. 방법과 기저함수에 따라 0.95에서 0.98 사이의 값을 쓰죠. 이 인자에는 두 가지가 섞여 있습니다.

- 비조화성 — 계산은 $\omega_e$를 주는데 관측은 $\nu_0$
- 계산 방법 자체의 오차 — 힘 상수를 정확히 못 구하기 때문에 생기는 오차

경험적으로 정한 값이라 물리적으로 깔끔하지는 않습니다. 하지만 실무에서는 이걸 곱해야 실험과 맞으니 다들 씁니다.
