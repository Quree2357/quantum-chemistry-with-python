우리가 필요로 하는 Hamiltonian 행렬 요소의 적분값이 0인지 아닌지 대칭 종들의 지표만 알면 바로 계산할 수 있었습니다. 전체 계산량을 생각해보면 0이 많이 나올수록 더 좋겠죠. 그런데 0이 많이 나오려면 오비탈들을 적절하게 잘 묶어야 합니다. 어떻게 하면 가장 최적의 조합을 찾을 수 있을까요?  


## 어떻게 섞어야 잘 섞었다고 소문이 날까

13.2절에서 암모니아 분자의 $s$ 오비탈들을 섞어서 만든 기저를 대칭 적응 기저라고 불렀습니다.

$$
(s_A + s_B + s_C, \, 2s_A - s_B - s_C, \, s_B - s_C)
$$

이 기저들 하나하나를 **대칭 적응 선형 결합(symmetry-adapted linear combination, SALC)**이라고 부릅니다. 오비탈들의 선형 결합으로 이루어져 있으니까요. SALC는 분자 오비탈을 구성할 때뿐만 아니라 배위 결합 화합물에서 중심 원자와 리간드 사이의 오비탈을 섞을 때에도 많이 사용되는 방식입니다.  

그럼 이 SALC를 어떻게 만들까요? 이 때 사용하는 개념이 바로 **사영 연산자(projection operator)**라는 것입니다. 이 공식을 쓰면 자연스럽게 대칭 적응 기저를 만들 수 있습니다.

$$
\hat{P}^{(i)} = \frac{d_i}{h} \sum_R \chi_i(R) \hat{R}
$$

사영 연산자는 각 기약 표현 $i$에 대해 정의됩니다. $d_i$는 기약 표현 $i$의 차원이고 13.3절의 축약 공식 때 본 것처럼 $h$와 $\chi_i(R)$은 각각 군의 위수와 기약 표현 $i$의 지표입니다. 마지막에 $\hat{R}$은 대칭 조작이죠.

사영 연산자를 사용해서 SALC를 만드는 법은 간단합니다. 일단 오비탈을 아무거나 하나 고른 다음($\phi_i$라고 합시다), 각 대칭 조작에 대해 그 오비탈이 어디로 가는지 보고, 그 결과에 지표를 곱한 것을 전부 더하면 되는 거죠. 이렇게 하면 $\hat{P}^{(i)}\phi_i$를 얻는데, 처음에 선택한 오비탈에서 기약 표현 $i$에 속하는 성분만 남게 됩니다. 아무것도 없으면 0이 나올 거고요.

이 식이 성립하는 이유는 단순하게 얘기하면 지표를 곱해서 더할 때 기약 표현 $i$와 맞지 않는 부분이 부호가 엇갈리면서 서로 상쇄되기 때문입니다. 정확한 증명은 대직교 정리를 이용해야 하는데, 마찬가지로 증명은 생략하고 바로 실전 문제로 들어가보겠습니다.


## 물 분자의 경우: 1차원 기약 표현

물 분자는 $C_{2v}$ 점군이었죠. $z$축에 분자의 $C_2$ 회전축을 두고 $yz$ 평면에 분자 평면을 맞춰봅시다. 그리고 수소의 $s$ 오비탈 두 개를 각각 $\phi_1$과 $\phi_2$라고 해보죠.

$C_{2v}$의 지표표를 다시 봅시다.

| $C_{2v}$ | $E$ | $C_2$ | $\sigma_v(xz)$ | $\sigma_v(yz)$ |
| - | - | - | - | - |
| $A_1$ | +1 | +1 | +1 | +1 |
| $A_2$ | +1 | +1 | -1 | -1 |
| $B_1$ | +1 | -1 | +1 | -1 |
| $B_2$ | +1 | -1 | -1 | +1 |

각 대칭 조작에 의해서 오비탈이 어디로 가는지 보면 다음과 같습니다.

| 조작 | $\phi_1$ | $\phi_2$ |
| - | - | - |
| $E$ | $\phi_1$ | $\phi_2$ |
| $C_2$ | $\phi_2$ | $\phi_1$ |
| $\sigma_v(xz)$ | $\phi_2$ | $\phi_1$ |
| $\sigma_v(yz)$ | $\phi_1$ | $\phi_2$ |

이제 사영 연산자를 사용하면 되죠. 일단 $\phi_1$에 대해서 계산해봅시다.

$A_1$ : $\frac{1}{4} (\phi_1 + \phi_2 + \phi_2 + \phi_1) = \frac{1}{2}(\phi_1 + \phi_2)$  
$A_2$ : $\frac{1}{4} (\phi_1 + \phi_2 - \phi_2 - \phi_1) = 0 $    
$B_1$ : $\frac{1}{4} (\phi_1 - \phi_2 + \phi_2 - \phi_1) = 0 $  
$B_2$ : $\frac{1}{4} (\phi_1 - \phi_2 - \phi_2 + \phi_1) = \frac{1}{2}(\phi_1 - \phi_2)$  

앞에서 봤던 대로 합과 차가 나왔습니다. 대칭 종도 13.4절의 표에 쓴 것과 일치하죠.  

코드로도 확인해봅시다. 13.2절에서 만든 `orbital_rep`으로 표현 행렬을 만들면 대칭 조작을 행렬곱으로 할 수 있습니다.
```python
import numpy as np


def C(n, axis="z"):
    th = 2 * np.pi / n
    c, s = np.cos(th), np.sin(th)
    if axis == "z":
        return np.array([[c, -s, 0], [s, c, 0], [0, 0, 1.0]])
    if axis == "y":
        return np.array([[c, 0, s], [0, 1.0, 0], [-s, 0, c]])
    return np.array([[1.0, 0, 0], [0, c, -s], [0, s, c]])


def sigma(plane):
    m = np.eye(3)
    m[{"yz": 0, "xz": 1, "xy": 2}[plane]] *= -1
    return m


def sigma_v(d):
    th = np.radians(d)
    return np.array([[np.cos(2 * th), np.sin(2 * th), 0], [np.sin(2 * th), -np.cos(2 * th), 0], [0, 0, 1.0]])


def orbital_rep(op, coords, labels):
    n = len(coords)
    M = np.zeros((n, n))
    moved = coords @ op.T
    for i, (p, l) in enumerate(zip(moved, labels)):
        for j, (q, m) in enumerate(zip(coords, labels)):
            if l == m and np.allclose(p, q, atol=1e-6):
                M[j, i] = 1
                break
    return M


def project(reps, chars, vec):
    """사영 연산자: sum(chi_i(R) * R) * d_i / h"""
    P = sum(c * D for c, D in zip(chars, reps)) * chars[0] / len(reps)
    return P @ vec


def combo(v, names):
    """계수 벡터를 보기 좋게 쓴다"""
    v = np.where(np.abs(v) < 1e-10, 0, v)
    if not v.any():
        return "0"
    terms = []
    for c, n in zip(np.round(v, 3), names):
        if c == 0:
            continue
        sign = "+" if c > 0 else "-"
        coef = "" if abs(c) == 1 else f"{abs(c):g}"
        terms.append(f"{sign} {coef}{n}")
    return " ".join(terms).removeprefix("+ ")


r, theta = 0.9572, np.radians(104.52)
water = np.array(
    [
        [0, 0, 0],
        [0, r * np.sin(theta / 2), -r * np.cos(theta / 2)],
        [0, -r * np.sin(theta / 2), -r * np.cos(theta / 2)],
    ]
)
water_names = ["s_O", "s_H1", "s_H2"]
water_reps = [orbital_rep(op, water, ["O", "H", "H"]) for op in [np.eye(3), C(2), sigma("xz"), sigma("yz")]]

c2v = {"A1": [1, 1, 1, 1], "A2": [1, 1, -1, -1], "B1": [1, -1, 1, -1], "B2": [1, -1, -1, 1]}

phi_1 = np.array([0, 1, 0])
for name, chars in c2v.items():
    print(f"{name}: {combo(project(water_reps, chars, phi_1), water_names)}")
```
```
A1: 0.5s_H1 + 0.5s_H2
A2: 0
B1: 0
B2: 0.5s_H1 - 0.5s_H2
```

손으로 계산한 것과 같은 결과를 얻습니다.


## 암모니아 분자의 경우: 2차원 기약 표현

물 분자의 경우에는 모든 기약 표현이 1차원이었습니다. 그렇다면 암모니아 분자처럼 2차원 기약 표현을 갖는 경우에는 어떨까요? 위 코드에 직접 적용해서 확인해봅시다.
```python
r2, z = 0.9375, -0.3810
ammonia = np.array(
    [
        [0, 0, 0],
        [r2, 0, z],
        [r2 * np.cos(2 * np.pi / 3), r2 * np.sin(2 * np.pi / 3), z],
        [r2 * np.cos(4 * np.pi / 3), r2 * np.sin(4 * np.pi / 3), z],
    ]
)

nh3_names = ["s_N", "s_A", "s_B", "s_C"]
nh3_reps = [
    orbital_rep(op, ammonia, ["N", "H", "H", "H"])
    for op in [np.eye(3), C(3), C(3) @ C(3), sigma_v(0), sigma_v(120), sigma_v(240)]
]

c3v = {"A1": [1, 1, 1, 1, 1, 1], "A2": [1, 1, 1, -1, -1, -1], "E": [2, -1, -1, 0, 0, 0]}

s_A = np.array([0, 1, 0, 0])
for name, chars in c3v.items():
    print(f"{name}: {combo(project(nh3_reps, chars, s_A), nh3_names)}")
```
```
A1: 0.333s_A + 0.333s_B + 0.333s_C
A2: 0
E: 0.667s_A - 0.333s_B - 0.333s_C
```

앞에 붙은 계수는 어차피 최종적으로 정규화를 할 거라서 비율만 보면 됩니다. $A_1$에서 $s_A+s_B+s_C$가 나오고, $E$에서는 $2s_A-s_B-s_C$가 나왔네요. 13.2절에서 봤던 형태들입니다.  

그런데 $E$는 2차원이니까 기저가 하나 더 나와야 하는데요. 어떻게 해야 하죠? 그 답은 Gram-Schmidt 직교화(orthogonalization)에 있습니다. 선형대수학 시간에 어렴풋이 배운 기억이 나시나요? 임의의 선형 독립인 벡터들을 서로 직교하는 벡터들로 만드는 과정이었습니다. 아이디어는 간단했죠. 직교하지 않는 성분을 빼버리는 거였습니다.

$$
\mathbf{v}'_2 = \mathbf{v}_2 - \frac{\langle \mathbf{v}_2, \, \mathbf{v}_1 \rangle}{\langle \mathbf{v}_1, \, \mathbf{v}_1 \rangle} \mathbf{v}_1
$$

일단 다른 오비탈 하나를 더 잡아서 사영 연산자를 적용합니다. $s_B$를 잡아보죠.
```python
first_basis = project(nh3_reps, chars, s_A)
second_basis = project(nh3_reps, c3v["E"], np.array([0, 0, 1, 0]))
print(combo(second_basis, nh3_names))
print(round(first_basis @ second_basis, 4))
```
```
- 0.333s_A + 0.667s_B - 0.333s_C
-0.3333
```
$2s_B - s_A - s_C$를 얻었는데, 처음에 얻은 것과 내적이 0이 아니죠. 이를 이용해서 직교화를 해주면 됩니다.

```python
second_basis = second_basis - (second_basis @ first_basis) / (first_basis @ first_basis) * first_basis
print(combo(second_basis, nh3_names))
```
```
0.5s_B - 0.5s_C
```
$s_B-s_C$가 나왔습니다. 이제 13.2절에서 봤던 암모니아의 대칭 적응 기저가 모두 모였네요. 이제 우리는 일일이 모든 조합을 검토해보지 않아도 자동으로 대칭 적응 기저를 만드는 도구를 얻었습니다.


## 벤젠의 경우...

이제 벤젠의 경우를 살펴봅시다. 이번에 우리가 살펴볼 것은 벤젠 분자의 $\pi$ 결합입니다. 벤젠의 완전한 분자 오비탈을 구성하는 데에는 각 수소의 $1s$ 오비탈과 각 탄소의 $1s$, $2s$, 그리고 $p_x, \, p_y, \, p_z$ 오비탈이 모두 필요합니다. 하지만 $\pi$ 결합에만 집중한다면 우리는 탄소의 $p_z$ 오비탈만 보면 됩니다. 분자 평면에 대한 대칭성 때문에 다른 오비탈들은 섞일 수 없거든요.

분자 평면을 $xy$ 평면에 두고 $C_6$ 회전축을 $z$축으로 놓겠습니다. 벤젠의 점군은 $D_{6h}$라서 대칭 조작이 24개나 되지만 우리에게 필요한 것은 $z$축 회전과 $z$축을 포함하는 거울면 $\sigma_v$, $\sigma_d$뿐입니다. 이 조작들은 $p_z$ 오비탈의 자리만 바꾸기 때문에 조작 후에도 오비탈의 부호가 바뀌지 않습니다.

이 조작들에 대한 지표표는 다음과 같습니다.

| $D_{6h}$ | E | $2C_6$ | $2C_3$ | $C_2$ | $3\sigma_v$ | $3\sigma_d$ |
| - | - | - | - | - | - | - |
| $A_1$ | +1 | +1 | +1 | +1 | +1 | +1 |
| $A_2$ | +1 | +1 | +1 | +1 | -1 | -1 |
| $B_1$ | +1 | -1 | +1 | -1 | +1 | -1 |
| $B_2$ | +1 | -1 | +1 | -1 | -1 | +1 |
| $E_1$ | +2 | +1 | -1 | -2 | 0 | 0 |
| $E_2$ | +2 | -1 | -1 | +2 | 0 | 0 |

먼저 축약 공식을 써서 어떤 기약 표현들이 나오는지부터 봅시다.
