## 도플갱어끼리 만나면 소멸되는 이유

0.1.5에서 함수 $x(L-x)$를 사인 함수들로 전개했을 때를 생각해보세요. 계수에 대해 얘기하면서 대칭성이 계수를 미리 결정한다는 말을 했었습니다. 그때 일어난 일은 함수 $x(L-x)$는 구간 정가운데를 기준으로 우함수였고, 짝수 번째 사인 함수가 기함수였기 때문에 벌어진 것이었습니다. 우함수와 기함수를 곱하면 기함수인데 이걸 대칭 구간에서 적분하면 0이 되죠.  

조금 더 일반적으로 생각해봅시다. 적분이라는 것은 어떤 공간 전체에 대해서 함숫값들을 모두 더하는 것입니다. 그러니 좌표축이 바뀌거나 돌아가도 같은 값이 나와야 하겠죠. 그런데 만약 어떤 함수 $f$가 대칭 조작 $R$에 대해서 부호가 바뀐다면 어떻게 될까요?

$$
\int f \,d\tau = \int (Rf) \,d\tau = \int (-f) \,d\tau = - \int f \,d\tau 
$$

부호가 바뀌어도 값이 그대로려면 0이어야 하겠죠. 대칭 조작에 대해 부호가 바뀌는 함수는 적분했을 때 0이 나오는 겁니다. 이 논리를 반대로 적용해보면 적분이 0이 아닌 함수는 모든 대칭 조작에 대해 변하지 않는 부분이 있어야 하는 거죠. 모든 대칭 조작에 대해 변하지 않는 대칭 종은 지표가 전부 +1인 $A_1$뿐입니다. 그래서 이걸 **완전 대칭 표현(totally symmetric representation)**이라고 부릅니다.

도플갱어들은 서로 부호가 반대라서 만나면 상쇄되어 0이 되는 걸까요...?


## 직접곱과 대칭성

그런데 사실 우리가 계산해야 하는 적분은 하나의 함수가 아니라 여러 개가 곱해진 형태입니다. 이걸 일일이 다 전개하지 않고 대칭 종을 판별하는 방법은 없을까요?  

예상하셨다시피, 답은 지표를 그냥 곱하기만 하면 된다는 것입니다. 우함수와 기함수를 곱하면 기함수가 되는 것처럼 어떤 대칭 조작 $R$에 대해 함수 $f$는 부호를 바꾸고 함수 $g$는 그대로라면 함수 $fg$는 같은 대칭 조작에 대해 부호가 바뀌겠죠. 이렇게 두 표현의 지표를 조작마다 곱해서 얻은 표현을 **직접곱(direct product)**이라고 부르고 $\Gamma_1 \otimes \Gamma_2$와 같이 씁니다.

$$
\chi_{\Gamma_1 \otimes \Gamma_2} (R) = \chi_{\Gamma_1} (R) \times \chi_{\Gamma_2} (R)
$$

곱한 게 기약 표현이 아니라면 축약 공식을 써서 다시 쪼개면 되죠. 직접 구현해봅시다.
```python
import numpy as np

c2v = {
    "A1": [1, 1, 1, 1],
    "A2": [1, 1, -1, -1],
    "B1": [1, -1, 1, -1],
    "B2": [1, -1, -1, 1],
}
c2v_sizes = [1, 1, 1, 1]
c3v = {
    "A1": [1, 1, 1],
    "A2": [1, 1, -1],
    "E": [2, -1, 0],
}
c3v_sizes = [1, 2, 3]


def reduce(chi, table, sizes):
    return {
        name: round(sum(g * a * b for g, a, b in zip(sizes, chi, row)) / sum(sizes))
        for name, row in table.items()
    }


def direct_product(table, *names):
    chi = np.ones(len(next(iter(table.values()))), dtype=int)
    for name in names:
        chi = chi * np.array(table[name])
    return [int(v) for v in chi]


for pair in [("B1", "B1"), ("B1", "B2"), ("A1", "B2")]:
    chi = direct_product(c2v, *pair)
    print(
        f"C2v  {pair[0]:>2} x {pair[1]:<2}: 지표 {chi} -> {reduce(chi, c2v, c2v_sizes)}"
    )

print()
for pair in [("E", "E"), ("A1", "E")]:
    chi = direct_product(c3v, *pair)
    print(
        f"C3v  {pair[0]:>2} x {pair[1]:<2}: 지표 {chi} -> {reduce(chi, c3v, c3v_sizes)}"
    )
```
```
C2v  B1 x B1: 지표 [1, 1, 1, 1] -> {'A1': 1, 'A2': 0, 'B1': 0, 'B2': 0}
C2v  B1 x B2: 지표 [1, 1, -1, -1] -> {'A1': 0, 'A2': 1, 'B1': 0, 'B2': 0}
C2v  A1 x B2: 지표 [1, -1, -1, 1] -> {'A1': 0, 'A2': 0, 'B1': 0, 'B2': 1}

C3v   E x E : 지표 [4, 1, 0] -> {'A1': 1, 'A2': 1, 'E': 1}
C3v  A1 x E : 지표 [2, -1, 0] -> {'A1': 0, 'A2': 0, 'E': 1}
```
이 결과를 다시 풀어쓰면, 예를 들어 $C_{3v}$에서 $E \otimes E = A_1+A_2+E$이라는 뜻입니다. 이 얘기를 선형대수학의 관점에서 잠깐 봅시다.  

$C_{3v}$의 지표표를 떠올려보면, $E$에 해당하는 함수는 $(x, y)$였습니다. 이 말은 $(x, y)$가 $E$를 span한다는 뜻입니다. 선형대수학에서 기저가 벡터공간을 span한다고 표현하는 건 많이 들어보셨을 겁니다. 같은 의미로 보시면 됩니다. 정확히는 $(x, y)$라는 기저가 span하는 벡터공간이 대칭 조작에 대해 불변이고, 그 공간 위의 표현이 $E$라는 의미입니다.  
그리고, $E \otimes E$는 $(x, y) \otimes (x, y)$에 의해 span될 겁니다. 같은 쌍을 두 번 쓰면 $xy = yx$라서 조각이 하나 사라지니, 서로 다른 두 쌍 $(x, y)$와 $(x', y')$를 곱해봅시다. 풀어쓰면 $(xx', xy', yx', yy')$이 되죠. 이걸 적절하게 조합하면 $xx' + yy'$, $(xx' - yy', xy' + yx')$, $xy' - yx'$가 되고, 각각 $A_1$, $E$, $A_2$에 해당합니다. 가운데 둘은 짝을 지어 $E$ 하나를 이룹니다.  

그러므로, 이 공간은 $A_1+A_2+E$에 의해 span이 되고, 결국 $E \otimes E$와 같은 공간이 되는 거죠.

[[TIP]]
지표표에는 $A_2$ 행에 $R_z$만 적혀있습니다. $z$축에 대한 각운동량은 $L_z = x p_y - y p_x$인데, 운동량 $(p_x, p_y)$도 위치와 같은 $E$에 속하니 이게 바로 $xy' - yx'$ 꼴이거든요. 그러니 사실 같은 겁니다.   
그리고 또 한 가지 재미있는 것은 같은 대칭 종끼리 곱할 때만 $A_1$이 나오는 것도 눈여겨볼 만합니다.
[[/TIP]]


## 오비탈이 섞이냐 안 섞이냐

자, 이제 우리가 정말로 궁금했던 부분으로 돌아가봅시다. 우리가 계산해야 하는 적분은 Hamiltonian 행렬 요소였죠.

$$
H_{ij} = \int \phi_i \hat{H} \phi_j \,d\tau
$$

여기서 핵심은 Hamiltonian이 완전 대칭이라는 것입니다. 분자에 대칭 조작을 가해도 에너지는 그대로일테니까요. 그러니 $\hat{H}$는 대칭 종 $A_1$에 속하고, 적분 안의 함수는 $\Gamma_i \otimes A_1 \otimes \Gamma_j = \Gamma_i \otimes \Gamma_j$가 됩니다. 따라서, 우리는 두 오비탈이 서로 다른 대칭 종에 속하면 행렬 요소가 0이고, 같은 대칭 종일 때만 0이 아니라는 것을 알 수 있습니다.

물 분자의 경우로 직접 확인해봅시다. 기저를 다음과 같이 잡아보죠: 수소 원자의 $1s$ 오비탈 2개와 산소 원자의 $1s$ 오비탈 1개, $2s$ 오비탈 1개, $2p$ 오비탈 3개, 총 7차원. 수소의 오비탈은 암모니아 분자 때와 마찬가지로 합과 차로 묶어서 쓰겠습니다.  

제대로 하려면 오비탈들의 실제 파동 함수를 넣어야 하겠지만 지금 우리가 관심 있는 것은 적분값이 0이 되는지 아닌지만 보고 싶은 거라 함수의 대칭성은 유지하면서 근사시킨 Gauss 함수를 대신 넣겠습니다.  

물 분자의 Hamiltonian은 12.2절에서 수소 분자 이온에 대해 만들었던 것과 같은 형태를 씁니다. 다만 이번에는 원자핵이 세 개죠. 실제 물 분자에는 전자가 10개나 있고 전자끼리의 상호작용이 매우 많지만 여기서는 전자 하나에 대한 것만 보겠습니다. 전자 간의 반발까지 제대로 다루는 방법은 17장에서 보게 될 겁니다.

$$
\hat{H} = -\frac{1}{2}\nabla^2 - \frac{8}{r_O} - \frac{1}{r_{H_1}} - \frac{1}{r_{H_2}}
$$

핵 사이의 반발 항도 뺐습니다. 어차피 상수니까요.  

먼저 각 기저(오비탈)들의 대칭 종에 대해 살펴봅시다. 대칭 조작에 대해 어떻게 변하는지를 보면 되죠.

| 오비탈 | 대칭 종 |
| - | - |
| $1s_O$, $2s_O$ | $A_1$ |
| $2p_{z, O}$ | $A_1$ |
| $2p_{x, O}$ | $B_1$ |
| $2p_{y, O}$ | $B_2$ |
| $1s_{H_1} + 1s_{H_2}$ | $A_1$ |
| $1s_{H_1} - 1s_{H_2}$ | $B_2$ |

이제 적분값을 계산해볼 수 있습니다.
```python
r, theta = 0.9572 * 1.8897, np.radians(104.52)  # 원자 단위계
O = np.array([0, 0, 0])
H1 = np.array([0, r * np.sin(theta / 2), -r * np.cos(theta / 2)])
H2 = np.array([0, -r * np.sin(theta / 2), -r * np.cos(theta / 2)])

# 원점에 대해 대칭인 3차원 격자
g = np.linspace(-5, 5, 100)
dV = (g[1] - g[0]) ** 3
X, Y, Z = np.meshgrid(g, g, g, indexing="ij")


def gauss(a, c):
    return np.exp(-a * ((X - c[0]) ** 2 + (Y - c[1]) ** 2 + (Z - c[2]) ** 2))


def dist(c):
    return np.sqrt((X - c[0]) ** 2 + (Y - c[1]) ** 2 + (Z - c[2]) ** 2 + 0.01)


V = -8 / dist(O) - 1 / dist(H1) - 1 / dist(H2)
h = g[1] - g[0]


def laplacian(f):
    return sum(np.gradient(np.gradient(f, h, axis=k), h, axis=k) for k in range(3))


def apply_H(f):
    return -0.5 * laplacian(f) + V * f


orbitals = {
    "O 1s": gauss(7.0, O),
    "O 2s": gauss(0.9, O) - 0.3 * gauss(7.0, O),
    "O 2pz": Z * gauss(0.9, O),
    "H+": gauss(0.5, H1) + gauss(0.5, H2),
    "O 2px": X * gauss(0.9, O),
    "O 2py": Y * gauss(0.9, O),
    "H-": gauss(0.5, H1) - gauss(0.5, H2),
}
species = ["A1", "A1", "A1", "A1", "B1", "B2", "B2"]

names = list(orbitals)
F = [orbitals[k] for k in names]
norm = np.sqrt([np.sum(f * f) * dV for f in F])
HF = [apply_H(f) for f in F]
M = np.array([[np.sum(a * Hb) * dV for Hb in HF] for a in F]) / np.outer(norm, norm)

print(" " * 11 + "".join(f"{n:>7}" for n in names))
for name, sp, row in zip(names, species, M):
    marks = "".join(f"{'x' if abs(v) > 1e-6 else '.':>7}" for v in row)
    print(f"{name:>6} ({sp}){marks}")

upper = np.triu_indices(len(F))
print()
print("계산해야 할 행렬 요소:", len(upper[0]), "개")
print("0의 갯수:", np.sum(np.abs(M[upper]) < 1e-6), "개")
```

```
  O 2s (A1)      x      x      x      x      .      .      .
 O 2pz (A1)      x      x      x      x      .      .      .
    H+ (A1)      x      x      x      x      .      .      .

    H- (B2)      .      .      .      .      .      x      x

```
행렬 성분에 `x`는 0이 아닌 값이 뭔가가 있다는 것이고, `.`은 0이라는 뜻입니다. 대칭 종이 같은 것끼리 모아놨더니 행렬이 블록 3개로 갈라진 블록 대각 행렬이 됐습니다. $4A_1+B_1+2B_2$라고 쓸 수 있겠네요. 우리는 이제 물 분자의 영년 방정식을 풀 때 7×7 대신 4×4, 1×1, 2×2 세 개로 나눠서 풀면 됩니다.  

또, 물 분자의 분자 오비탈은 전부 대칭 종이 같은 오비탈들끼리만 섞여서 만들어진다는 뜻이기도 합니다. $2p_x$ 오비탈은 섞이지 않고 그대로 분자 오비탈이 되는 거고요. 14장에서 이 결과를 다시 쓰게 됩니다.

[[TIP]]
Hamiltonian 대신 운동 에너지 항만 넣거나 겹침 적분 $S_{ij}$만 계산해보면 0이 16개가 나옵니다. 산소 위에 함께 놓인 $2s$와 $2p_z$ 같은 쌍이 추가로 0이 되거든요. 이 두 연산자는 분자의 대칭뿐 아니라 산소 원자 하나의 대칭까지 가지고 있어서 그렇습니다. 수소 원자핵이 끌어당기는 퍼텐셜이 들어가야 비로소 산소 원자의 대칭이 깨지고 분자의 대칭만 남죠. 대칭 종이 다르면 반드시 0이지만, 0이라고 대칭 종이 다른 것은 아닙니다.
[[/TIP]]


## 분광학의 선택 규칙
 
같은 규칙을 분광학에 써봅시다. 6.3에서 분자가 적외선을 흡수하려면 진동하는 동안 쌍극자 모멘트가 변해야 한다고 했었죠. 이걸 양자역학으로 쓰면 **전이 쌍극자 모멘트(transition dipole moment)**라는 적분의 값이 0이 아니어야 한다는 조건이 됩니다.
 
$$
\mu_{i \to f} = \int \psi_i \hat{\mu} \psi_f \,d\tau
$$
 
$\psi_i$는 처음 상태, $\psi_f$는 나중 상태, $\hat{\mu}$는 쌍극자 모멘트 연산자입니다. 쌍극자 모멘트는 전하에 위치를 곱한 것이라 성분이 $x$, $y$, $z$와 같은 대칭 종을 가지죠. 그러니 지표표 오른쪽 열에서 $x$, $y$, $z$가 있는 행을 보면 됩니다.
 
진동 운동의 바닥 상태는 항상 완전 대칭입니다. 그러니까 $A_1$이죠. 그리고 진동 모드 하나가 한 단계 들뜨면 그 상태는 그 진동 모드와 같은 대칭 종을 갖습니다. 그러면 피적분 함수의 대칭 종은 $A_1 \otimes \Gamma_{\mu} \otimes \Gamma_{\text{진동}} = \Gamma_{\mu} \otimes \Gamma_{\text{진동}}$이 되죠. 즉, 진동 모드의 대칭 종이 $x$, $y$, $z$ 중 하나와 같아야 적외선을 흡수한다는 것입니다. 이런 모드를 **IR 활성(IR active)**이라고 부릅니다.

13.3에서 구한 물의 진동 모드 $2A_1 + B_2$에 적용해볼까요? $C_{2v}$ 지표표에서 $z$는 $A_1$, $y$는 $B_2$에 있으니 세 모드 모두 IR 활성입니다. 실제로 물의 적외선 스펙트럼에는 세 진동이 모두 나타나죠.  

이산화탄소 분자의 경우에는 선형이고 가운데에 반전 중심이 있어서 점군이 $D_{\infty h}$입니다. 조작이 무한히 많아서 지표표도 크지만, 여기서는 반전 조작 $i$ 하나만 봐도 충분합니다. $x$, $y$, $z$는 반전에 대해 모두 부호가 바뀌니 전부 $u$죠. 그러니 $g$인 진동 모드는 $g \otimes u = u$가 되어서 IR 비활성이 됩니다. 그래서 이산화탄소 분자의 진동 모드는 비대칭 신축과 굽힘 2개, 총 3개만 IR 활성입니다.

[[TIP]]
6.3의 TIP에서 Raman 분광법은 쌍극자 대신 분극률의 변화를 본다고 했었죠. 분극률은 $x^2$, $xy$ 같은 이차 함수와 같은 대칭 종을 가집니다. 그래서 진동 모드의 대칭 종이 이차 함수 중 하나와 같아야 Raman 활성이게 됩니다. 반전 중심이 있는 분자에서 $x$, $y$, $z$는 모두 $u$이고, $x^2$, $xy$ 같은 이차 함수는 부호가 두 번 바뀌니 모두 $g$입니다. 그러니 IR 활성인 모드는 $u$여야 하고 Raman 활성인 모드는 $g$여야 하죠. 따라서, 반전 중심이 있는 분자에서는 IR 활성과 Raman 활성이 서로 배타적입니다. 이걸 상호 배타 규칙(rule of mutual exclusion)이라고 부릅니다. 이산화탄소의 대칭 신축은 IR에는 안 보이지만 Raman에는 보이는 거죠.
[[/TIP]]

6.3절에서 얘기했던 양자 조화 진동자의 선택 규칙도 같은 방식으로 어느 정도 설명할 수 있습니다. 6.2절에서 본 것처럼 조화 진동자의 파동 함수는 $v$가 짝수면 우함수, 홀수면 기함수였죠. 그리고 쌍극자 모멘트는 변위 $x$에 비례하니 기함수입니다. 그러면 $\langle 0|x|v \rangle$의 피적분 함수는 $v$가 짝수일 때 우함수×기함수×우함수=기함수가 되어서 0입니다. 직접 계산해볼까요?
```python
from numpy.polynomial.hermite import hermval
from math import factorial, pi, sqrt

xg = np.linspace(-10, 10, 20000)
dx = xg[1] - xg[0]


def psi(v):
    """조화 진동자의 파동 함수"""
    c = np.zeros(v + 1)
    c[v] = 1
    return hermval(xg, c) * np.exp(-(xg**2) / 2) / sqrt(2**v * factorial(v) * sqrt(pi))


for v in range(1, 6):
    integral = round(np.sum(psi(0) * xg * psi(v)) * dx, 10) + 0.0
    parity = "홀수" if v % 2 else "짝수"
    print(f"<0|x|{v}> = {integral:+.4f}   (v = {v}, {parity})")
```
```
<0|x|1> = +0.7071   (v = 1, 홀수)
<0|x|2> = +0.0000   (v = 2, 짝수)
<0|x|3> = +0.0000   (v = 3, 홀수)
<0|x|4> = +0.0000   (v = 4, 짝수)
<0|x|5> = +0.0000   (v = 5, 홀수)
```
$v$가 짝수인 경우는 예상대로 0입니다. 대칭성으로 설명되는 부분이죠. 그런데 $v$가 3과 5일 때도 0이 나왔습니다. 이건 대칭성만으로는 설명되지 않습니다. 이 부분은 6.2절에서 이름만 잠깐 소개했던 사다리 연산자에서 나옵니다. 대칭성은 "홀수 칸만 움직일 수 있다"까지 알려주고, "그중에서도 한 칸씩만"은 조화 진동자의 특별한 구조가 알려주는 셈입니다.
