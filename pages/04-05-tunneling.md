앞 절 마지막에서 이상한 것을 봤습니다. 전자의 에너지가 언덕 높이보다 낮은데도 파동함수가 언덕 안에서 0이 아니었죠.

고전물리학에서는 있을 수 없는 일입니다. 공을 언덕 위로 굴리려면 언덕 높이만큼의 에너지가 있어야 하고, 모자라면 중간에 멈춰 되돌아옵니다. 언덕 **안쪽**에 공이 들어가 있는 상황 자체가 성립하지 않죠.

그런데 전자는 들어가 있습니다. 이 절에서 그 이야기를 하겠습니다. 그리고 4장을 마무리하죠.


## 벽을 낮춰봅시다

지금까지 우리 상자의 벽은 무한히 높았습니다. 아무리 큰 에너지를 가져도 넘을 수 없었죠. 이제 유한한 높이로 바꿔봅시다.

$$
V(x) = \begin{cases}
0 & (\text{우물 안}) \\
V_0 & (\text{우물 밖})
\end{cases}
$$

**퍼텐셜 배열 한 줄만 고치면 됩니다.**

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.constants import hbar, m_e, e, h

def second_derivative_matrix(N, dx):
    return (-2*np.eye(N) + np.eye(N, k=1) + np.eye(N, k=-1)) / dx**2

def solve(N, L, potential):
    dx = L/(N+1)
    x = np.linspace(0, L, N+2)[1:-1]
    H = -hbar**2/(2*m_e)*second_derivative_matrix(N, dx) + np.diag(potential(x))
    E, psi = np.linalg.eigh(H)
    return x, E/e, psi

L, N, w = 4e-9, 1200, 1e-9          # 전체 구간 4 nm, 우물 폭 1 nm

def well(V0_eV):
    """가운데 폭 w인 우물, 바깥은 V0"""
    return lambda x: np.where(np.abs(x - L/2) < w/2, 0.0, V0_eV*e)

fig, axes = plt.subplots(1, 2, figsize=(11, 4.2), sharey=True)

for ax, (V0, title) in zip(axes, [(1e6, "infinite well"), (5.0, "finite well (5 eV)")]):
    x, E, psi = solve(N, L, well(V0))
    ax.plot(x*1e9, np.clip(well(V0)(x)/e, 0, 6), color="black", lw=1.8)
    for k in range(3):
        v = psi[:, k]
        if v[np.argmax(np.abs(v))] < 0:
            v = -v
        ax.hlines(E[k], 0, L*1e9, color="gray", lw=0.7, ls=":")
        ax.plot(x*1e9, E[k] + 0.6*v/np.abs(v).max(), lw=1.8)
    ax.set_xlim(1.0, 3.0); ax.set_ylim(-0.5, 4.5)
    ax.set_xlabel("x (nm)"); ax.set_title(title, fontsize=12)

axes[0].set_ylabel("E (eV)")
plt.show()
```

두 가지가 달라집니다.

**첫째, 파동함수가 벽 안으로 새어 나갑니다.** 무한 우물에서는 벽에서 정확히 0이었는데, 유한 우물에서는 벽 안쪽으로 슬며시 스며들어 지수적으로 잦아듭니다.

**둘째, 에너지가 낮아집니다.** 숫자로 확인해보죠.

```python
x, E, psi = solve(N, L, well(5.0))

for n in range(1, 4):
    infinite = n**2 * h**2/(8*m_e*w**2) / e
    print(f"n={n}:  무한 우물 {infinite:7.4f} eV   유한 우물 {E[n-1]:7.4f} eV")
```
```
n=1:  무한 우물  0.3760 eV   유한 우물  0.2722 eV
n=2:  무한 우물  1.5041 eV   유한 우물  1.0788 eV
n=3:  무한 우물  3.3843 eV   유한 우물  2.3822 eV
```

전부 낮아졌습니다. 이유는 4.1절의 결과에 있습니다. $E \propto 1/L^2$이었죠. **전자가 벽 안으로 조금 새어 나가면 실효 상자가 넓어진 셈**이고, 그러면 에너지가 내려갑니다.

여기서 4.2절이 떠오르시나요? 시아닌 염료 계산에서 예측 파장이 전부 실측보다 짧게 나왔었죠. 상자를 너무 짧게 잡았기 때문이라고 했고요. **지금 보고 있는 것이 바로 그 현상입니다.** 실제 분자의 벽은 무한히 높지 않으니 전자가 조금씩 새어 나가고, 그래서 유효 상자가 우리가 잡은 것보다 넓었던 겁니다.


## 준위가 유한하게만 존재한다

무한 우물에서는 준위가 무한히 많았습니다. $n=1, 2, 3, \ldots$ 끝없이요. 유한 우물은 어떨까요?

```python
for V0 in [1, 3, 5, 10, 30]:
    x, E, psi = solve(N, L, well(V0))
    bound = E[E < V0]                    # 벽보다 낮은 준위 = 우물에 갇힌 상태
    print(f"V0={V0:3d} eV : 속박 준위 {len(bound)}개   {np.round(bound[:4], 3)}")
```
```
V0=  1 eV : 속박 준위 2개   [0.191 0.704]
V0=  3 eV : 속박 준위 3개   [0.249 0.98  2.11 ]
V0=  5 eV : 속박 준위 4개   [0.272 1.079 2.382 4.064]
V0= 10 eV : 속박 준위 6개   [0.298 1.188 2.655 4.669]
V0= 30 eV : 속박 준위 9개   [0.328 1.311 2.946 5.227]
```

**벽보다 에너지가 높은 상태는 우물에 갇혀 있지 않습니다.** 그런 전자는 그냥 지나가버리죠. 그래서 우물에 묶여 있는 **속박 상태(bound state)**의 개수가 유한합니다.

벽을 높일수록 속박 준위가 늘어나고, 무한대로 보내면 무한히 많아집니다. 우리가 4.1절에서 다룬 것이 그 극한이었던 셈이죠.

거꾸로 우물이 얕거나 좁으면 속박 상태가 아주 적어집니다. 1차원에서는 아무리 얕아도 최소 하나는 남지만, 3차원에서는 **바닥상태조차 없을 수도** 있습니다. 중성자와 양성자가 결합해 중수소를 만들 때 겨우 하나의 속박 상태만 갖는 것도 이런 사정 때문입니다.


## 벽 안에 얼마나 있을까

전자가 벽 안에 있을 확률을 실제로 세어봅시다.

```python
x, E, psi = solve(N, L, well(5.0))
outside = np.abs(x - L/2) > w/2          # 우물 바깥 = 고전적으로 금지된 영역

for k in range(3):
    v = psi[:, k]
    p = np.sum(v[outside]**2) / np.sum(v**2)
    print(f"n={k+1}: E={E[k]:.3f} eV,  벽 안에서 발견될 확률 = {p*100:.2f}%")
```
```
n=1: E=0.272 eV,  벽 안에서 발견될 확률 = 0.83%
n=2: E=1.079 eV,  벽 안에서 발견될 확률 = 3.55%
n=3: E=2.382 eV,  벽 안에서 발견될 확률 = 9.26%
```

$n=3$이면 거의 10%입니다. **고전적으로는 절대 있을 수 없는 자리에 전자가 10번 중 한 번 발견된다**는 뜻이죠.

그리고 에너지가 높을수록 확률이 커집니다. 벽 높이까지 남은 여유가 적을수록 더 깊이 스며드는 것이죠.

*그러면 에너지 보존은 어떻게 되나요?* 벽 안에서 전자의 퍼텐셜 에너지가 전체 에너지보다 크니, 운동에너지가 음수여야 할 것 같습니다. 말이 안 되죠.

**질문 자체가 성립하지 않습니다.** 2.4절에서 봤듯이 전자는 위치와 운동량을 동시에 정해진 값으로 갖지 않습니다. "벽 안에 있을 때의 운동에너지"라는 것을 따로 떼어 말할 수 없죠. 우리가 말할 수 있는 것은 전체 상태의 에너지 하나뿐이고, 그건 제대로 보존됩니다.


## 우물이 두 개라면

이제 재미있는 것을 해봅시다. 우물을 두 개 나란히 놓고 사이를 얇은 벽으로 막으면 어떻게 될까요?

```python
L2, N2, V0 = 6e-9, 1500, 5.0

def double_well(barrier_w):
    def V(x):
        out = np.full_like(x, V0*e)
        for center in [L2/2 - barrier_w/2 - w/2, L2/2 + barrier_w/2 + w/2]:
            out[np.abs(x - center) < w/2] = 0.0
        return out
    return V

fig, axes = plt.subplots(1, 3, figsize=(13, 4))

for ax, bw_nm in zip(axes, [0.2, 0.6, 1.5]):
    Vf = double_well(bw_nm*1e-9)
    x, E, psi = solve(N2, L2, Vf)
    ax.plot(x*1e9, np.clip(Vf(x)/e, 0, 1.15), color="black", lw=1.6)
    for k, col in zip([0, 1], ["crimson", "steelblue"]):
        v = psi[:, k]
        if v[np.argmax(np.abs(v))] < 0:
            v = -v
        ax.hlines(E[k], 0, L2*1e9, color="gray", lw=0.7, ls=":")
        ax.plot(x*1e9, E[k] + 0.25*v/np.abs(v).max(), lw=1.8, color=col)
    ax.set_xlim(1.2, 4.8); ax.set_ylim(-0.1, 1.2)
    ax.set_xlabel("x (nm)")
    ax.set_title(f"barrier {bw_nm} nm\nsplit = {(E[1]-E[0])*1000:.2f} meV", fontsize=11)

axes[0].set_ylabel("E (eV)")
plt.show()
```

**바닥상태가 둘로 갈라집니다.**

우물이 하나였다면 바닥상태는 하나였을 겁니다. 그런데 두 개를 놓으면 두 개가 나오죠. 하나는 양쪽 우물에서 **같은 부호**로 출렁이고(대칭), 다른 하나는 **반대 부호**로 출렁입니다(반대칭). 그리고 둘의 에너지가 살짝 다릅니다.

갈라지는 정도를 재보면 이렇습니다.

```python
print(f"{'장벽(nm)':>10} {'E1(eV)':>9} {'E2(eV)':>9} {'갈라짐(meV)':>13}")
for bw_nm in [0.2, 0.4, 0.6, 0.8, 1.2]:
    x, E, psi = solve(N2, L2, double_well(bw_nm*1e-9))
    print(f"{bw_nm:10.1f} {E[0]:9.4f} {E[1]:9.4f} {(E[1]-E[0])*1000:13.3f}")
```
```
   장벽(nm)    E1(eV)    E2(eV)    갈라짐(meV)
       0.2    0.2630    0.2800        16.996
       0.4    0.2712    0.2730         1.826
       0.6    0.2720    0.2722         0.197
       0.8    0.2721    0.2721         0.021
       1.2    0.2721    0.2721         0.000
```

**벽이 두꺼워지면 갈라짐이 급격히 줄어듭니다.** 0.2 nm에서 17 meV였던 것이 0.6 nm에서 0.2 meV로, 1.2 nm에서는 사실상 0이 됩니다.

로그 축으로 그려보면 이유가 보입니다.

```python
widths = np.linspace(0.15, 1.2, 20)
splits = [ (solve(N2, L2, double_well(bw*1e-9))[1][1]
          - solve(N2, L2, double_well(bw*1e-9))[1][0]) * 1000
          for bw in widths ]

fig, ax = plt.subplots(figsize=(6, 4.2))
ax.semilogy(widths, splits, "o-", color="crimson", lw=2)
ax.set_xlabel("barrier width (nm)"); ax.set_ylabel("splitting (meV)")
ax.grid(alpha=0.3, which="both")
plt.show()
```

거의 직선입니다. 즉 갈라짐이 벽 두께에 대해 **지수적으로** 줄어듭니다. 벽이 조금만 두꺼워져도 급격히 사라진다는 뜻이죠.

[[TIP]]
장벽이 아주 두꺼운 세 번째 그림을 보세요. 두 파동함수가 각각 한쪽 우물에만 있습니다. 대칭·반대칭이 아니라요.
이건 오류가 아닙니다. 갈라짐이 0에 가까워지면 두 상태가 **축퇴**되는데, 4.3절에서 봤듯이 축퇴된 상태들은 어떻게 섞어도 여전히 해입니다. 그래서 `eigh`가 어느 조합을 돌려줄지는 정해져 있지 않죠. 벽이 두꺼워 두 우물이 사실상 남남이 되면, "왼쪽 우물의 상태"와 "오른쪽 우물의 상태"로 잡는 것이 오히려 자연스럽습니다.
[[/TIP]]


## 갈라짐이 뜻하는 것

두 준위가 갈라진다는 것은 무엇을 의미할까요?

전자를 왼쪽 우물에만 넣어놓고 시작한다고 합시다. 그 상태는 대칭 상태와 반대칭 상태를 반반 섞은 것입니다. 그런데 두 상태의 에너지가 다르니 시간이 지나면서 위상이 어긋나고, 결국 **전자가 오른쪽 우물로 옮겨갑니다.** 그리고 다시 왼쪽으로 돌아오죠.

이 왕복 주기는 갈라짐 $\Delta E$로 정해집니다.

$$
T = \frac{h}{\Delta E}
$$

```python
for bw_nm in [0.2, 0.6, 1.2]:
    x, E, psi = solve(N2, L2, double_well(bw_nm*1e-9))
    dE = (E[1] - E[0]) * e
    print(f"장벽 {bw_nm} nm : 갈라짐 {dE/e*1000:8.3f} meV  ->  왕복 주기 {h/dE*1e12:12.4f} ps")
```
```
장벽 0.2 nm : 갈라짐   16.996 meV  ->  왕복 주기       0.2433 ps
장벽 0.6 nm : 갈라짐    0.197 meV  ->  왕복 주기      20.9834 ps
장벽 1.2 nm : 갈라짐    0.000 meV  ->  왕복 주기   16689.6405 ps
```

**벽이 0.2 nm면 0.24 피코초 만에 건너가는데, 1.2 nm면 16 나노초가 걸립니다.** 벽이 여섯 배 두꺼워졌을 뿐인데 시간은 7만 배 늘었죠.

이것이 터널링이 **거리에 극도로 민감한** 이유입니다. 그리고 그 민감함이 실용적으로 쓰입니다.


## 실제로 일어나는 일들

**암모니아 반전.** NH₃는 삼각뿔 모양인데, 질소가 수소 삼각형의 위에 있을 수도 아래에 있을 수도 있습니다. 두 배치 사이에 에너지 장벽이 있어 고전적으로는 넘나들 수 없죠. 그런데 질소가 터널링으로 오갑니다.

실제로 측정된 반전 진동수는 23.786 GHz입니다.

```python
nu = 23.786e9
print(f"NH3 반전: 진동수 {nu/1e9:.3f} GHz")
print(f"          준위 갈라짐 {h*nu/e*1000:.5f} meV")
print(f"          왕복 주기 {1/nu*1e12:.2f} ps")
```
```
NH3 반전: 진동수 23.786 GHz
          준위 갈라짐 0.09837 meV
          왕복 주기 42.04 ps
```

갈라짐이 0.1 meV 수준입니다. 우리가 방금 계산한 이중 우물의 0.6 nm 장벽과 비슷한 규모죠. 그리고 이 진동수는 **역사상 첫 메이저(maser)**의 기반이 되었습니다. 레이저의 마이크로파 판본이죠.

**주사터널링현미경(STM).** 뾰족한 금속 탐침을 시료 표면에 아주 가까이 가져가면, 사이가 진공인데도 전류가 흐릅니다. 전자가 터널링하는 것이죠. 그리고 방금 봤듯이 터널링은 거리에 지수적으로 민감합니다. 탐침을 0.1 nm만 움직여도 전류가 열 배씩 바뀌죠. **그 민감함 덕분에 원자 하나하나를 볼 수 있습니다.**

**화학 반응.** 수소 원자가 이동하는 반응에서는 터널링이 실제 반응 속도에 기여합니다. 특히 저온에서요. 수소를 중수소로 바꾸면 질량이 두 배가 되어 터널링이 크게 줄어드는데, 이것이 **동위원소 효과**의 한 원인입니다. 6장에서 진동을 다룰 때 다시 이야기하겠습니다.


## 4장을 마치며

이 장에서 우리는 상자 하나로 꽤 멀리까지 왔습니다.

3.1절의 진동하는 줄과 수학이 같다는 것에서 시작해(4.1), 염료 분자의 색을 예측하고(4.2), 3차원으로 넓혀 축퇴를 만났으며(4.3), 손으로 구한 답을 코드로 검증했습니다(4.4). 그리고 마지막으로 벽을 낮춰 고전물리학이 금지한 영역으로 들어갔죠.

무엇보다 **도구를 하나 손에 넣었습니다.** 미분 행렬에 퍼텐셜을 얹고 `eigh`를 부르는, 그 두 줄이죠.

$$
\mathbf{H} = -\frac{\hbar^2}{2m}D_2 + \mathrm{diag}(V)
\qquad\longrightarrow\qquad
\hat{H}\psi = E\psi
$$

퍼텐셜만 바꾸면 어떤 1차원 문제든 풀 수 있죠. 6장의 조화진동자도 이 코드로 확인하게 될 것이고, 15장에서 벤젠의 분자 궤도를 다룰 때도, 18장에서 실제 분자의 전자구조를 계산할 때도 마지막은 `eigh`입니다. **행렬을 만드는 방법이 점점 정교해질 뿐이죠.**

다음 장에서는 잠시 계산을 멈추고 도구를 정비합니다. 우리가 계속 써온 "연산자"라는 것이 정확히 무엇인지, 그리고 측정한다는 것이 무슨 뜻인지 정리할 차례입니다.
