# 4.1. 같은 방정식, 다른 의미

## 1차원 상자 만들기

1차원 상자는 그냥 구간입니다. 상자의 길이가 $L$이라고 하면 구간 [0, $L$]에 해당하는 거죠. 전자는 이 안에서는 자유롭게 움직이지만 상자 밖으로는 나갈 수 없습니다. 이런 조건을 넣을 때는 구간 밖에서의 퍼텐셜이 무한대라고 놓습니다.

$$
V(x) = \begin{cases}
0 & (0 < x < L) \\
\infty & (x < 0 , \enspace x > L)
\end{cases}
$$

퍼텐셜이 무한대라는 것은 전자가 아무리 큰 에너지를 가지고 있어도 $x=0$과 $x=L$에 있는 양쪽 벽을 넘을 수 없다는 뜻입니다. 그래서 이런 모양의 퍼텐셜을 **무한 우물(infinite well)**이라고도 부릅니다. 물론 현실에서 무한대의 퍼텐셜이라는 것은 존재하지 않지만 매우 높은 퍼텐셜 벽이 있을 경우의 근사 정도로는 쓸 만합니다.  

상자 안에서는 $V=0$이니 전자의 Schrödinger 방정식은 이렇게 됩니다.

$$
-\frac{\hbar^2}{2m} \frac{d^2 \psi}{dx^2} = E \psi \qquad \Longrightarrow \qquad \frac{d^2 \psi}{dx^2} = -\frac{2mE}{\hbar^2} \psi
$$

그리고 물론 상자 밖에서는 전자가 존재할 수 없으니까 파동함수가 0이어야 하고요. 파동함수가 연속이어야 한다는 조건을 기억하시면 상자의 경계에서 파동함수의 값이 0이어야 한다는 경계조건을 얻게 됩니다.

$$
\psi(0) = 0, \quad \psi(L) = 0
$$


## 나는 이 문제를 이미 풀어봤어요!

3.1절에서 진동하는 줄의 파동방정식을 풀 때 공간과 시간에 대한 변수를 분리하고 나면 각각의 방정식이 정확히 위에 있는 식과 같은 형태였습니다.

$$
\frac{d^2 X}{dx^2} = -k^2 X \qquad \longleftrightarrow \qquad \frac{d^2 \psi}{dx^2} = -\frac{2mE}{\hbar^2} \psi
$$

여기서 $k^2=\frac{2mE}{\hbar^2}$으로 두면 정확히 똑같은 식이 됩니다. 그러니 답도 그대로 가져오면 됩니다.

$$
\psi_n(x) = A_n \sin \left( \frac{n\pi x}{L} \right), \quad k_n = \frac{n\pi}{L}, \quad n=1, 2, 3, \ldots
$$

딱히 새로운 게 없네요. 하지만 전자의 경우에는 재미있는 일이 일어납니다.

### 1) n과 k의 의미가 다르다

진동하는 줄에서 $k$는 파장을 정하는 값이었고, 거기서 모드의 번호 $n$에 비례하는 값들로 진동수가 나왔었습니다.

$$
k_n = \frac{n\pi}{L} \quad \longrightarrow \quad \nu_n = \frac{nv}{2L}
$$

그런데 전자에서는 이 $k$가 에너지와 연결되어 있습니다. $k^2=\frac{2mE}{\hbar^2}$였으니 에너지는 다음과 같겠네요.

$$
E_n = \frac{\hbar^2 k_n^2}{2m} = \frac{\hbar^2}{2m} \left( \frac{n\pi}{L} \right)^2 = \frac{n^2 h^2}{8mL^2}
$$

에너지가 $n$의 제곱에 비례하네요! 2.2절에서 언급한 것처럼 여기서의 $n$은 양자수라고 부릅니다. 특히, $n$은 **주양자수(principal quantum number)**라는 이름이 붙어있습니다.  
$k$가 등차수열로 증가하는 것은 같은데, 줄에서는 진동수가 일정하게 증가하지만 전자에서는 제곱이 붙어 에너지가 위로 갈수록 벌어집니다.
```python
import numpy as np
import matplotlib.pyplot as plt

fig, (a1, a2) = plt.subplots(1, 2, figsize=(10, 5))

for n in range(1, 7):
    a1.hlines(n, 0, 1, lw=2.5, color="blue")
    a2.hlines(n**2, 0, 1, lw=2.5, color="red")
    a1.text(1.04, n, f"n = {n}", va="center", fontsize=9)
    a2.text(1.04, n**2, f"n = {n}", va="center", fontsize=9)

for ax, ylab, title in [
    (a1, "Frequency", "String: nu ~ n"),
    (a2, "Energy", "Electron: E ~ n^2"),
]:
    ax.set_ylim(0, 40)
    ax.set_xlim(0, 1.25)
    ax.set_xticks([])
    ax.set_ylabel(f"{ylab} (relative)")
    ax.set_title(title)

plt.tight_layout()
plt.show()
```

숫자를 한번 넣어봅시다. 예를 들어, 상자 길이를 1 nm나 2 nm로 하면 어떨까요?
```python
from scipy.constants import h, m_e, e


def energy_level(n, L_nm):
    L = L_nm * 1e-9
    return n**2 * h**2 / (8 * m_e * L**2) / e


for L_nm in [1, 2]:
    levels = [energy_level(n, L_nm) for n in range(1, 4)]
    print(
        f"L = {L_nm} nm: "
        + ", ".join(f"E_{n} = {E:6.4f} eV" for n, E in enumerate(levels, 1))
    )
```
```
L = 1 nm: E_1 = 0.3760 eV, E_2 = 1.5041 eV, E_3 = 3.3843 eV
L = 2 nm: E_1 = 0.0940 eV, E_2 = 0.3760 eV, E_3 = 0.8461 eV
```
상자의 길이가 작을수록 에너지가 커집니다. $L^2$이 분모에 있으니 절반으로 줄이면 에너지가 4배가 되죠. nm 단위의 상자에서는 에너지가 eV 단위로 나옵니다. 1.2절에서 봤던 가시광선 영역의 광자의 에너지가 약 2~3 eV 정도였으니, 이 정도 길이의 상자 속 전자는 빛과 상호작용하기에 딱 좋은 상태라는 뜻입니다.

### 2) $n=0$이 허용되지 않는다

줄에서 $n=0$은 무슨 뜻이었나요? $u(x)=0$이 되니 줄이 직선으로 가만히 있는 상태입니다. 심심하긴 하지만 아무 문제는 없습니다. 그런데 전자의 경우에는 사정이 달라집니다. $n=0$이라면 $\psi=0$이 되는데, 이 얘기는 전자를 발견할 확률이 모든 곳에서 0이라는 뜻입니다. 분명히 상자 안에 전자가 있다고 했는데 측정해보면 전자가 어디에도 없다고 나오는 거죠. 그래서 $n$은 1부터 시작합니다. 그리고 이 값에 해당하는 에너지는 이렇죠.

$$
E_1 = \frac{h^2}{8mL^2} > 0
$$

전자는 에너지가 0일 수 없는 겁니다. 전자가 가만히 있을 수 없다는 뜻이죠. 불확정성 원리를 생각해볼까요? 만약 전자가 모든 에너지를 잃고 한 점에서 멈춰있다면 위치에 대한 불확정성이 0이라는 뜻인데 그러면 운동량에 대한 불확정성이 무한대가 됩니다. 말이 안 되는 거죠. 이렇게 전자가 가질 수 있는 최소의 에너지를 **영점 에너지(zero-point energy)**라고 부릅니다.

[[TIP]]
영점 에너지는 그냥 어떤 추상적인 개념이 아닙니다. 실제로 헬륨의 경우 대기압에서 절대영도까지 온도를 내려도 절대로 얼지 않습니다. 헬륨 원자들의 영점 운동이 너무 커서 결정 구조를 유지할 수 없기 때문이죠. 이에 대해 더 궁금하신 분들은 '양자 요동(quantum fluctuation)'이나 '진공 에너지(vaccum energy)' 등의 주제를 찾아보세요.
[[/TIP]]

### 3) 진폭이 정해져 있다

진동하는 줄에서 진동의 진폭 $A$는 얼마나 세게 튕겼는지에 따라 정해졌습니다. 모양만 맞으면 세게 튕기든 약하게 튕기든 아무 문제가 없죠. 고전 파동방정식은 진폭에 대해 아무런 정보도 주지 않았습니다. 하지만 전자의 경우에는 파동함수가 정규화되어야 하기 때문에 진폭도 자동으로 정해집니다.

$$
\int_0^L |\psi_n|^2 dx = 1
$$

이 조건이 계수 $A$를 결정하게 됩니다. 실제로 계산해보면 $A=\sqrt{2/L}$이 나오는데, 0.1.5에서 우리가 사인 기저에 붙였던 바로 그 값입니다. 전자의 파동함수에는 '세기'라는 개념이 없는거죠.

### 4) 실제로 나타내는 것은 무엇인가

줄에서의 $u(x)$는 실제로 줄이 휘어있는 모양을 나타냈습니다. 눈으로도 볼 수 있고 직접 측정도 할 수 있는 값이죠. 그런데 전자의 파동함수 $\psi(x)$는 실제로 볼 수 있는 함수가 아닙니다. 일반적으로 복소수 값을 가지기 때문인 것도 있지만 애초에 물리적으로 의미를 가지는 값이 아니거든요. 우리가 측정할 수 있는 것은 $|\psi|^2$, 즉 전자를 발견할 확률밀도뿐입니다. 그러니 파동함수 자체만 봐서는 의미가 없고 확률밀도까지 함께 봐야 합니다.
```python
L = 1.0
x = np.linspace(0, L, 500)

fig, axes = plt.subplots(4, 2, figsize=(10, 7), sharex=True)

for i, n in enumerate([1, 2, 3, 4]):
    psi = np.sqrt(2 / L) * np.sin(n * np.pi * x / L)
    nodes = np.arange(1, n) * L / n

    axes[i, 0].plot(x, psi, color="blue", lw=2)
    axes[i, 0].axhline(0, color="black", lw=1)
    axes[i, 0].axvline(0, color="black", lw=2)
    axes[i, 0].axvline(L, color="black", lw=2)
    axes[i, 0].set_ylim(-1.6, 1.6)
    axes[i, 0].set_ylabel(f"n = {n}", rotation=0, labelpad=22, va="center")
    
    axes[i, 1].fill_between(x, psi**2, color="red", alpha=0.5)
    axes[i, 1].axhline(0, color="black", lw=1)
    axes[i, 1].axvline(0, color="black", lw=2)
    axes[i, 1].axvline(L, color="black", lw=2)
    axes[i, 1].plot(x, psi**2, color="red", lw=2)
    axes[i, 1].plot(nodes, np.zeros_like(nodes), "o", color="black", ms=6, zorder=5)
    axes[i, 1].yaxis.set_label_position("right")
    axes[i, 1].set_ylabel(f"$E = \\frac{{{n**2}h^2}}{{8mL^2}}$", labelpad=30, rotation=0, va="center", fontsize=12)

    for ax in axes[i]:
        ax.set_yticks([])

axes[0, 0].set_title(f"$\\psi(x)$")
axes[0, 1].set_title(f"$|\\psi(x)|^2$")
axes[-1, 0].set_xlabel("x")
axes[-1, 1].set_xlabel("x")

plt.tight_layout()
plt.show()
```
![파동함수과 확률밀도](/assets/image-42.png)

왼쪽의 파란 곡선은 3.1절에서 봤던 진동하는 줄의 모양과 똑같습니다. 그런데 오른쪽 그림에서는 아래로 내려갔던 봉우리들이 모두 제곱이 되어 위로 올라왔습니다. 그림에 표시된 검은 점이 바로 마디입니다. 이 점에서는 $|\psi|^2=0$이니 전자를 발견할 확률이 0이 됩니다.  

그런데 이상한 점이 하나 있습니다. $n=2$의 경우를 보면, 가운데에 마디가 하나 있고 마디 양쪽에서 전자를 발견할 확률이 0이 아닙니다. 전자는 마디를 지나갈 수 없는데 어떻게 양쪽에서 다 발견될 수 있을까요?  
사실 이 질문에는 답이 없습니다. 질문 자체가 잘못되었기 때문이죠. 전자는 이 안에서 '움직이고 있는' 것이 아닙니다. 전자가 어느 순간에는 왼쪽에 있다가 다른 순간에는 오른쪽에 있는 식으로 움직이는 게 아니라는 거죠. 확률밀도가 우리에게 보여주는 것은 전자의 경로가 아니라 분포입니다.
