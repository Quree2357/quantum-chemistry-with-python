## 1차원 파동방정식

어떤 줄이 아주 팽팽하게 당겨져 있다고 합시다. 뭐, 기타 줄 같은 걸 생각하시면 되겠네요. 그리고 이제 얘를 튕깁니다. 튕긴다는 게 뭐죠? 줄에 수직한 방향으로 줄을 잡아당긴다는 거죠. 그러면 줄이 약간 늘어나게 될 겁니다. 늘어난 줄은 다시 원래 상태로 돌아가려고 하는데, 이때 줄에 가해지는 힘은 Hooke의 법칙이라고 불리는 관계를 따르게 됩니다. 흔히 용수철 같은 것으로 설명되는 "늘어난 길이와 힘은 비례한다"는 그 법칙입니다. 이 법칙과 Newton의 제2법칙을 결합하면 다음과 같은 식을 얻을 수 있는데요, 자세한 유도과정은 생략하도록 하겠습니다. 지금 우리에게 중요한 건 결과뿐이거든요.

$$
\frac{\partial^2 u}{\partial x^2} = \frac{1}{v^2} \frac{\partial^2 u}{\partial t^2}
$$

미분처럼 보이지만 살짝 다른 $\frac{\partial^2 u}{\partial x^2}$ 기호는 편미분입니다. 그러니까 함수 $u(x,t)$를 $x$에 대해서만 미분하고 나머지는 상수로 보겠다는 뜻이죠. 0.2.4절에서 편미분방정식(PDE)에 대한 얘기를 했던 것, 기억나시나요?  
함수 $u(x,t)$는 줄이 수직방향으로 얼마나 늘어났는가를 뜻하는 함수입니다. 그리고 $v$는 파동이 전파되는 속도입니다. 그러니까 왼쪽 항은 $x$, 즉 공간에 대한 2차 미분이니 줄이 얼마나 휘어 있는지를 나타내는 항이고, 오른쪽 항은 $t$, 즉 시간에 대한 2차 미분이니 줄이 늘어날 때 얼마의 가속도로 움직이는지를 나타내는 항입니다. 따라서 이 식은 "줄이 많이 휘어 있을수록 더 큰 가속도를 가지고 움직인다"라는 의미네요. 당연해 보입니다.  

여기서 잠깐 이 식의 형태에 대해 고찰해보고 넘어가죠. 만약에 우리가 함수 $u(x,t)$의 자리에 $f(x-vt)$를 넣는다고 생각해봅시다. 합성함수의 미분법은 아직 기억하고 계시리라 믿습니다... 

$$
\frac{\partial^2}{\partial x^2} f(x-vt) = f(x-vt)
$$
$$
\frac{\partial^2}{\partial t^2} f(x-vt) = v^2 f(x-vt)
$$

오, 이 함수는 방정식을 만족합니다! 그러니까 함수 $f$가 어떻게 생겼든 간에 $(x-vt)$의 함수로 나타난다면 무엇이든 해가 된다는 뜻입니다. 이게 무슨 의미일까요?  
$(x-vt)$가 일정한 값을 가진다는 것은 시간 $t$가 흘렀을 때 위치가 $vt$만큼 움직였다는 뜻입니다. 즉, 모양을 그대로 유지하면서 오른쪽으로 속도 $v$로 움직이고 있다는 거죠. 파동이 진행하고 있습니다! 반대로 함수 $f(x+vt)$도 방정식의 해가 되는데 이건 왼쪽으로 움직이는 파동이네요. 한번 그림으로 확인해봅시다.

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 4, 500)
k, w = np.pi, 2 * np.pi

fig, axes = plt.subplots(5, 1, figsize=(5, 12))

for t, ax in zip([0, 0.13, 0.25, 0.38, 0.5], axes):
    right = np.sin(k * x - w * t)  # 오른쪽으로 진행하는 파동
    left = np.sin(k * x + w * t)  # 왼쪽으로 진행하는 파동
    ax.plot(x, right, color="blue", lw=1.5, alpha=0.5, label="right-moving")
    ax.plot(x, left, color="green", lw=1.5, alpha=0.5, label="left-moving")
    ax.plot(x, right + left, color="red", lw=2, label="sum")
    ax.axhline(0, color="black", lw=0.6)
    ax.set_ylim(-2.3, 2.3)
    ax.set_yticks([])
    ax.set_xlabel("x")
    ax.set_title(f"t = {t}")
    ax.legend(bbox_to_anchor=(1.3, 0.5), fontsize=7, loc="right")

plt.tight_layout()
plt.show()
```
![진행 파동](/assets/image-32.png)

시간에 따라 파란색과 녹색의 파동이 각각 오른쪽과 왼쪽으로 진행하고 있습니다. 빨간색은 이 둘을 더한 것인데요, 시간이 지나도 움직이지 않고 제자리에서 위아래로만 출렁이고 있습니다. 그리고 아예 모든 시간에서 진폭이 0인 지점들도 있네요.  

빨간색과 같은 파동을 **정상파(standing wave)**라고 부릅니다. 제자리에서만 위아래로 진동하는 파동이죠. 줄의 양 끝이 묶여 있는 경우에는 파동이 진행하다가 끝에서 반사되는데 이 반사파와 원래 파동이 겹치면서 만들어집니다. 진폭이 항상 0인 지점은 **마디(node)**라고 부릅니다.

[[TIP]]
파동방정식이 선형 미분방정식이어서 이렇게 여러 개의 해를 더한 것도 해가 되는 것입니다. 0.2.4절에서 제차 선형 미분방정식은 해를 더해도 여전히 해가 된다고 했었죠. 중첩원리가 여기서도 작동하는 것입니다.
[[/TIP]]


## 변수분리법으로 풀기

이제 실제로 이 방정식의 해를 구해봅시다. 기타 줄처럼 양쪽이 고정된, 길이 $L$의 줄이 있다고 해보죠. 그러면 양 끝점에서는 줄이 움직이지 않는 경계조건이 되겠네요.

$$
u(0, t) = 0 \qquad u(L, t) = 0
$$

PDE는 일반적으로 풀기가 매우 어렵습니다. 그런데 다행히 이 문제는 아주 쉽게 풀 수 있는 종류입니다. 바로 **변수분리(separation of variables)**법입니다. 아이디어는 단순합니다. 방정식의 해가 각각의 변수에 대한 함수들의 곱으로 이루어졌을 거라고 찍어보는 거죠. 그러니까 이런 모양인 겁니다.

$$
u(x, t) = X(x)T(t)
$$

물리적으로는 "줄의 모양은 정해져 있고, 그 모양 자체가 시간에 따라 커졌다 작아졌다 한다"는 느낌입니다. 앞에서 본 정상파가 딱 이런 경우입니다.  

*근데 이렇게 찍어도 되나요? 찍어서 맞췄다고 그게 끝이라고 어떻게 보장하나요?*  
사실, 여기서 우리가 사용하는 변수분리법이 먹히는 경우는 굉장히 드뭅니다. 하지만 이게 먹히기만 한다면 그렇게 얻은 해들이 완전기저를 이룬다는 것은 수학적으로 보장되어 있습니다. 그리고 완전기저를 이루는 해를 찾기만 하면 그 해들의 선형 결합으로 가능한 모든 해를 표현할 수 있게 됩니다. 이렇게 해들로 이루어진 벡터 공간을 **해공간(solution space)**이라고도 부릅니다.  
 

일단 해봅시다. 이 형태를 원래 방정식에 넣으면 이렇게 정리할 수 있습니다.

$$
\frac{1}{X} \frac{d^2 X}{dx^2} = \frac{1}{v^2 T} \frac{d^2 T}{dt^2}
$$

여기서 결정적인 것은 왼쪽은 $x$만의 함수이고 오른쪽은 $t$만의 함수라는 것입니다. 그런데 둘이 항상 같아야 하니 유일한 경우는 둘 다 상수일 때뿐입니다. 이 상수를 $-k^2$이라고 놓아보죠.(음수로 두는 이유는 곧 알게 됩니다.)

$$
\frac{d^2 X}{dx^2} = -k^2 X \qquad \frac{d^2 T}{dt^2} = -k^2 v^2 T
$$

이제 PDE 하나가 ODE 두 개로 쪼개졌습니다. 그리고 두 식 모두 0.2.4에서 봤던 상수계수 2계 제차 선형 ODE네요. 특성방정식으로 풀 수 있습니다.  
$X$에 대한 식의 특성방정식은 $r^2 + k^2 = 0$이므로 근이 $r=\pm ik$로 나타납니다. 켤레복소근의 경우는 0.2.4에서 봤었죠. 다음과 같은 해를 얻게 되겠네요.

$$
X(x) = A\sin(kx) + B\cos(kx)
$$

여기서 상수를 음수로 둔 이유가 드러납니다. 진동하는 해를 얻기 위해서죠. 만약 이 상수가 양수였다면 실근이 나와 해가 지수함수꼴로 나왔을 겁니다. 그러면 양 끝에서 0이 된다는 경계조건을 만족할 수 없습니다.  

$T$에 대한 식의 특성방정식은 $r^2 + v^2k^2 = 0$이므로 근이 $r=\pm ivk$로 나타납니다. 같은 방식으로 보면 시간에 따라서 위아래로 진동하는 파동이 되겠네요.

$$
T(t) = C \sin(kvt) + D \cos(kvt)
$$

위에서 봤던 정상파의 경우와 정확히 일치합니다. 한 가지 눈여겨볼 점은 $X(x)$와 $T(t)$가 둘 다 같은 상수 $k$로 묶여있다는 점입니다. 둘이 따로따로 놀 수 없다는 거죠.


## 파동방정식과 경계조건

이제 경계조건에 대해 생각해봅시다. 양 끝 점에서 0이 되어야 하니까 $X(0) = 0$과 $X(L) = 0$의 두 가지 조건을 만족하면 됩니다. 일단 0을 대입해보면 $X(0)=B$가 되네요. 따라서 쉽게 $B$가 0이라는 것을 알 수 있습니다.  
두 번째 조건을 넣어보죠.

$$
X(L) = A\sin(kL) = 0
$$

만약 $A=0$이라면 줄이 그냥 가만히 있는 것이니까 별로 재미가 없습니다. (이런 경우를 자명한 해(trivial solution)라고 합니다.)  
$A \neq 0$의 경우를 생각해보죠. 그러면 사인 함수가 0이 되어야 합니다. 사인 함수가 0이 되는 점이 어디였죠? 바로 $\pi$의 정수배일 때였죠.

$$
kL = n \pi \quad \Longrightarrow \quad k = \frac{n \pi}{L} \qquad n=1,2,3,\ldots
$$

어라, 이 장면 어딘가 익숙합니다. 0.2.4에서 정확히 같은 계산을 했었죠. 그때는 슈팅법으로 $k$를 바꿔가면서 하나하나 경계조건을 확인했었습니다.  

파장으로 바꿔 쓰면 더 직관적으로 알 수 있습니다. $k=\frac{2\pi}{\lambda}$이므로 $\lambda_n = \frac{2L}{n}$이 됩니다. 즉, 줄 전체 길이의 2배, 1배, 2/3배, 등등과 같은 파장만 허용되는 것입니다. 양 쪽 끝 사이에 봉우리가 1개, 2개, 3개, 등등으로 들어가 있는 이미지가 되겠네요. $n$에 따른 각 파동의 함수를 **모드(mode)**라고 부릅니다. 각 모드가 어떻게 생겼는지 그려봅시다.
```python
L = 1.0
v = 1.0
x = np.linspace(0, L, 500)

fig, axes = plt.subplots(4, 1, figsize=(7, 6))

for n, ax in zip(range(1, 5), axes):
    X = np.sin(n * np.pi * x / L)
	
    for t, alpha in [(0, 1.0), (0.05, 0.67), (0.1, 0.5), (0.15, 0.33), (0.2, 0.25)]:
        T = np.cos(n * np.pi * v * t / L)
        ax.plot(x, X * T, color="blue", lw=2 if t == 0 else 1, alpha=alpha)
    nodes = np.arange(0, n + 1) * L / n
    ax.plot(nodes, np.zeros_like(nodes), "o", color="red", ms=6, zorder=5)
    ax.axhline(0, color="black", lw=0.6)
    ax.set_ylim(-1.3, 1.3)
    ax.set_yticks([])
    ax.set_ylabel(f"n = {n}", rotation=0, labelpad=25, va='center')

axes[-1].set_xlabel("x")
plt.tight_layout()
plt.show()
```
![파동방정식의 해](/assets/image-33.png)

시간에 따른 파동의 변화 모습을 그렸습니다. 위아래로 출렁거리는 모습이 잘 보이네요. 빨간 점이 바로 마디입니다. $n$번째 모드에는 마디가 $n+1$개 있군요. $n$이 커질수록 마디가 많아져 파장이 짧아지고 파동의 에너지도 높아지네요.  
또, 위에서 말했던 것처럼 함수 $T(t)$와 함수 $X(x)$가 같은 상수 $k$로 묶여있어 $n$이 커질수록 더 빠르게 진동하는 것을 볼 수 있습니다. $n=1$일 때는 조금밖에 안 움직였는데 $n=4$일 때는 벌써 반대 방향까지 갔네요.

일반물리학에서 봤던 $\nu = \frac{v}{\lambda}$ 관계식을 이용하면 각 모드들의 진동수는 $\nu_n=\frac{v}{\lambda_n} = \frac{nv}{2L}$로 계산할 수 있네요. 기본진동수의 정수배로만 나옵니다.  
여기서 $n=1$일 때의 진동수를 **기본 진동수(fundamental frequency)**라고 부르고, 이 기본 진동수를 포함한 모든 모드를 **고조파(harmonics)**라고 부릅니다. 영어 단어에서 예상하셨겠지만 화음을 뜻하는 하모니(harmony)와 어원이 같습니다.  


## 모드들의 선형 결합

아까도 말했지만 제차 선형 미분방정식의 해끼리는 서로 더해도 해가 됩니다. 이렇게 여러 모드가 섞인 것도 파동방정식의 해가 될 수 있는데요, 이것이 바로 악기마다 같은 음을 연주해도 소리가 다르게 느껴지는 이유이기도 합니다.  

$$
u(x, t) = \sum_n A_n \sin \left( \frac{n\pi}{L} x \right) \left( C_n \sin \left( \frac{n\pi v}{L} t \right) + D_n \cos \left( \frac{n\pi v}{L} t \right) \right)
$$

```python
coeff = {1: 1.0, 2: -0.5, 3: 0.3, 5: -0.2}  # 각 모드를 얼마나 섞을 것인가

fig, ax = plt.subplots(figsize=(7, 4))
total = np.zeros_like(x)

for n, c in coeff.items():
    mode = c * np.sin(n * np.pi * x / L)
    total += mode
    ax.plot(x, mode, lw=1.1, ls="--", alpha=0.7, label=f"n={n} ({c})")

ax.plot(x, total, color="red", lw=2.4, label="sum")
ax.axhline(0, color="black", lw=0.6)
ax.set_xlabel("x")
ax.set_yticks([])
ax.legend(ncol=2)

plt.tight_layout()
plt.show()
```
![파동방정식의 해들의 선형 결합](/assets/image-34.png)

빨간색 곡선이 바로 각 모드들을 합한 값인데요, 이상하게 생겼지만 이 곡선도 파동방정식을 만족합니다. 각 모드를 얼마나 섞느냐에 따라 줄의 모양이 달라지고 이것이 서로 다른 악기들의 음색의 차이를 만듭니다.  

여기서 0.1.5에서 배운 것이 생각나셨다면 여러분은 정말 대단하십니다. 그때 우리는 임의의 함수를 사인 함수들의 합으로 펼쳤었죠. 지금 한 일이 바로 그것입니다. $\sin \left( \frac{n\pi x}{L} \right)$들이 정규직교기저를 이루고, 계수 $A_n$은 내적으로 구합니다. 줄을 어떤 모양으로 튕겼는지가 정해지면 각 모드가 얼마나 섞일지도 자동으로 정해지는 것이죠. 이런 것을 Fourier 사인 급수(Fourier sine series)이라고도 부르는데 이런 게 있구나 정도만 아시면 됩니다.
