# 4. 상자 속 입자

방정식과 조건을 모두 손에 넣었으니 이제 직접 풀어볼 차례입니다. 가장 단순한 문제부터 시작하자고 했었죠. 바로 1차원 상자 속에 갇힌 전자입니다.  

그런데 사실 이 문제는 여러분이 이미 절반 정도는 풀어놓은 셈입니다! 3.1절에서 진동하는 줄에 대한 파동 방정식을 풀었던 방법과 해의 모양을 기억하시나요? 그때와 수학이 완전히 같거든요. 그래서 여기서는 똑같은 계산을 한 번 더 반복하기보다는, 방정식의 해가 뜻하는 의미가 어떻게 달라지는지에 집중해보도록 하겠습니다.  

이 장의 마지막 부분에서는 여러분이 손으로 풀었던 것을 직접 코드로 검증해보고 다른 상황에서는 어떻게 답이 달라지는지 확인하게 됩니다.
