## 사슬을 따라 움직이는 전자

이중결합과 단일결합이 번갈아 이어진 구조를 **공액(conjugation)**이라고 부릅니다. 이런 구조에서는 $\pi$ 전자가 한 결합에 묶여 있지 않고 사슬 전체에 퍼져 있습니다. 이걸 전자가 **비편재화(delocalized)**되어 있다고도 하죠.

그러면 이 전자에게 세상은 어떻게 보일까요? 사슬을 따라서는 자유롭게 움직일 수 있지만, 사슬이 끝나는 곳에서는 더 갈 데가 없습니다. 앞에서 봤던 1차원 상자랑 비슷한 상황 같네요.

물론 실제 사슬에서 퍼텐셜은 일정하지 않습니다. 울퉁불퉁하지만 그 깊이가 사슬 밖으로 나가는 데 필요한 에너지에 비하면 작습니다. 그래서 울퉁불퉁한 바닥을 평평하다고 치고 계산해보자는 것이 **자유전자 모형(free electron model)**입니다. 1949년 Hans Kuhn이 제안했죠.


## 시아닌 염료

공액 구조를 가지고 있는 대표적인 분자는 시아닌(cyanine) 염료입니다. 두 개의 질소 원자를 폴리메틴 사슬이 잇고 있는 구조죠. 아래 그림은 Cy3 분자의 구조입니다.

![Cy3 분자 구조](/assets/image-41.png)

시아닌 분자가 자유전자 모형에 특히 잘 맞는 이유가 있습니다. 양쪽이 대칭이라 전하가 고르게 퍼져 있거든요. 양전하가 두 질소 사이를 오가는 공명구조를 그릴 수 있고, 그 결과 사슬의 C–C 결합 길이가 거의 일정합니다. 결정 구조에서 재보면 139~140 pm 정도로, 단일결합(154 pm)과 이중결합(134 pm)의 중간쯤이죠. 바닥이 거의 평평하다는 가정이 실제로 성립하는 겁니다.

| 이름 | 사슬 탄소 수 | 최대 흡수 파장 | 대략적인 색깔 |
|---|---|---|---|
| Cy3 | 5개 | 544 nm | 분홍색 |
| Cy5 | 7개 | 638 nm | 파란색 |
| Cy7 | 9개 | 742 nm | 옅은 녹색 |

여기서 사슬을 구성하는 탄소의 수는 양 쪽 질소 사이에 있는 탄소 원자 모두를 센 것입니다. 이름에 붙어있는 숫자는 질소 바로 옆에 있는 탄소는 세지 않고 붙인 거고요.

탄소의 개수가 2개씩 늘어날 때마다 최대 흡수 파장이 약 100 nm씩 밀립니다. Cy7이 흡수하는 빛은 거의 근적외선 영역이라 눈에 잘 보이지 않습니다. 그래서 색으로는 밋밋하지만, 근적외선이 생체 조직을 잘 통과한다는 점 때문에 오히려 바이오 이미징 등의 의학 분야에서 많이 쓰입니다. 확인문제 1번에서 Cy9의 흡수 파장을 계산해보면 왜 파장을 더 길게 만들려고 하는지 짐작하실 수 있을 겁니다.

(측정값은 PhotochemCAD의 데이터베이스에서 가져왔습니다: https://www.photochemcad.com/databases/common-compounds/cyanine-dyes)


## 상자 길이와 전자 수 세기

실제로 계산하려면 두 가지가 필요합니다. 상자 길이와 전자 개수죠.

### 전자 개수

$\pi$ 전자는 사슬 위에 어떻게 놓여 있을까요? Kuhn의 계산법에 따르면 이렇습니다.

- 사슬의 각 탄소가 한 개씩 내놓는다
- 두 질소가 합쳐서 세 개를 내놓는다

질소가 제공하는 전자가 3개인 이유는 한쪽은 중성이라 고립전자쌍 한 개(전자는 두 개)를 내놓고, 다른 쪽은 양전하를 띠고 있어 전자 한 개를 내놓기 때문입니다. 양전하가 두 질소 사이를 오가니 어느 쪽이 어느 쪽인지는 정해져 있지 않고요.

$$
N = (\text{사슬 탄소 수}) + 3
$$

예를 들어, Cy3는 질소 사이의 탄소가 5개니 $N=8$입니다.

### 상자 길이

사슬 원자 사이의 결합을 세고 139 pm을 곱하면 되겠죠. 그런데 하나 더 고려할 것이 있습니다. 전자가 질소에서 딱 멈추지 않습니다. 그 너머로도 조금 퍼져 있죠.

그래서 관례적으로 양 끝에 반 결합씩, 합쳐서 한 결합만큼을 더 줍니다.

$$
L = (\text{사슬 원자 수} + 1) \times 139\ \text{pm}
$$

Cy3는 원자가 7개(탄소 5 + 질소 2)니 $L = 8 \times 139 = 1112$ pm입니다.


## 상자 속 입자로 계산해보기

전자는 아래 준위부터 두 개씩 채워집니다. 일반화학에서 **쌓음 원리(Aufbau principle)**와 **Pauli 배타 원리(exclusion principle)**에 대해 배운 기억이 나시죠? $N$개면 $N/2$번째 준위까지 차죠. 전자가 채워져 있는 가장 높은 준위가 HOMO, 그 바로 위에 있는 빈 준위가 LUMO입니다. 빛을 흡수하면 전자 하나가 HOMO에서 LUMO로 올라갑니다.

1차원 상자 속 입자 모델에 따르면 두 에너지 준위 간의 에너지 차이는 다음과 같습니다.

$$
\Delta E = E_{N/2+1} - E_{N/2} = \frac{h^2}{8mL^2}\left[\left(\frac{N}{2}+1\right)^2 - \left(\frac{N}{2}\right)^2\right] = \frac{(N+1)h^2}{8mL^2}
$$

그리고 이 에너지에 해당하는 파장을 최대 흡수 파장이라고 계산하면 되죠.

$$
\lambda = \frac{hc}{\Delta E} = \frac{8mcL^2}{(N+1)h}
$$

준위가 채워지는 모습을 그려봅시다.

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.constants import h, m_e, c, e

l = 139e-12
name = {1: "Cy3", 2: "Cy5", 3: "Cy7"}

fig, axes = plt.subplots(1, 3, figsize=(11, 4.2), sharey=True)

for ax, k in zip(axes, [1, 2, 3]):
    p = 2 * k + 3  # 사슬 탄소 수
    N = p + 3  # pi 전자 수
    L = (p + 3) * l  # 사슬 원자 수(p+2) + 1
    E0 = h**2 / (8 * m_e * L**2) / e  # n=1 에너지 (eV)
    homo = N // 2

    for n in range(1, homo + 3):
        E = n**2 * E0
        ax.hlines(E, 0, 1, lw=2, color="navy")
        if n <= homo:  # 채워진 준위
            ax.plot([0.42, 0.58], [E, E], "o", color="crimson", ms=6)
        ax.text(1.05, E, f"n={n}", va="center", fontsize=8)

    ax.annotate(
        "",
        xy=(0.25, (homo + 1) ** 2 * E0),
        xytext=(0.25, homo**2 * E0),
        arrowprops=dict(arrowstyle="->", color="darkorange", lw=2.5),
    )
    ax.set_xlim(0, 1.3)
    ax.set_xticks([])
    ax.set_title(f"{name[k]}  ({N} pi electrons)", fontsize=11)

axes[0].set_ylabel("energy (eV)")
plt.show()
```
![시아닌 분자의 에너지 준위](/assets/image-42.png)

빨간 점이 전자입니다. 준위마다 두 개씩 채워지고, 주황 화살표가 HOMO에서 LUMO로 뛰는 전이죠. 사슬이 길어질수록 전자가 늘어 HOMO가 위로 올라가지만, 동시에 준위 간격 자체가 좁아집니다. 상자가 길어지니 $L^2$이 분모에서 커지거든요. 두 효과가 합쳐져서 어떤 결과가 나올지는 직접 계산해봐야 알 것 같네요.

```python
def cyanine(k):
    p = 2 * k + 3  # 사슬 탄소 수
    N = p + 3  # pi 전자 수
    L = (p + 3) * l  # 상자 길이 = (원자 수 + 1) x 139 pm
    dE = (N + 1) * h**2 / (8 * m_e * L**2)
    return p, N, L, h * c / dE * 1e9  # 파장 (nm)


obs = {1: 544, 2: 638, 3: 742}

print(f"{'':>2} {'탄소':>4} {'pi':>4} {'L(pm)':>7} {'예측':>6} {'실측':>6} {'오차':>7}")
for k in [1, 2, 3]:
    p, N, L, lam = cyanine(k)
    o = obs[k]
    print(
        f"{name[k]:>3} {p:4d} {N:4d} {L*1e12:7.0f} {lam:8.2f} {o:7.1f} {(lam-o)/o*100:+7.1f}%"
    )
```
```
     탄소   pi   L(pm)     예측     실측      오차
Cy3    5    8    1112   453.01   544.0   -16.7%
Cy5    7   10    1390   579.14   638.0    -9.2%
Cy7    9   12    1668   705.65   742.0    -4.9%
```

숫자가 완벽하게 똑같지는 않지만 꽤 비슷한 결과를 나타내고 있습니다. Cy7의 경우에는 오차가 5% 미만이네요! 전자를 1차원 상자에 가둬놓고 결합 길이 하나만 넣어 계산한 결과가 이 정도라는 게 놀랍습니다. 분자의 실제 모양도, 원자의 종류도, 전자끼리의 반발도 전혀 넣지 않았거든요.

그림으로 비교해보죠.

```python
ks = [1, 2, 3]
pred = [cyanine(k)[3] for k in ks]
meas = [obs[k] for k in ks]

fig, (a1, a2) = plt.subplots(1, 2, figsize=(11, 4.2))
xpos = np.arange(3)

a1.bar(xpos - 0.18, pred, 0.36, color="blue", label="free-electron model")
a1.bar(xpos + 0.18, meas, 0.36, color="red", label="measured")
a1.set_xticks(xpos)
a1.set_xticklabels([name[k] for k in ks])
a1.set_ylabel("absorption max (nm)")
a1.legend(fontsize=9)
a1.grid(alpha=0.3, axis="y")

a2.plot(ks, pred, "o-", color="blue", lw=2, ms=8, label="model")
a2.plot(ks, meas, "s-", color="red", lw=2, ms=8, label="measured")
a2.set_xticks(ks)
a2.set_xticklabels([name[k] for k in ks])
a2.set_ylabel("absorption max (nm)")
a2.legend(fontsize=9)
a2.grid(alpha=0.3)

plt.show()
```
![계산과 실제의 비교](/assets/image-43.png)

사슬이 길어질수록 흡수 파장이 길어진다는 것을 정확히 잡아냅니다. 공액계가 길어질수록 흡수 파장이 커진다는 유기화학의 규칙이 여기서 설명되는 셈이죠.

$\lambda = \frac{8mcL^2}{(N+1)h}$을 보면 이유가 보입니다. 사슬을 늘리면 $L^2$은 빠르게 커지는데 $N$은 천천히 늘어납니다. 그래서 결국 $\lambda$가 커지죠.


## 상자 속 입자 모델의 한계점

계산과 실제 측정값의 오차를 다시 한번 봅시다.

```
Cy3 : -16.7%
Cy5 :  -9.2%
Cy7 :  -4.9%
```

두 가지가 눈에 띕니다.

첫째, 전부 음수입니다. 예측 파장이 실측보다 짧다는 건 예측 에너지 간격이 너무 크다는 뜻이고, 결국 상자를 너무 짧게 잡았다는 뜻입니다. 실제로 그렇습니다. 시아닌의 양 끝에는 인돌레닌 고리가 붙어 있는데, 이 고리의 $\pi$ 전자계도 사슬과 이어져 있거든요. 전자가 질소에서 멈추지 않고 고리 쪽으로 더 퍼져 있는 것이죠. 우리가 "반 결합씩" 준 여유로는 사실 부족했던 겁니다.

둘째, 사슬이 길수록 오차가 줄어듭니다. 양 끝에서 새어 나가는 양은 사슬 길이와 무관하게 일정한데, 사슬이 길어지면 전체에서 차지하는 비중이 줄어들죠. 물론 긴 사슬에서는 결합길이의 교대나 비틀림 같은 다른 효과도 다시 커질 수 있지만 지금은 무시하도록 합시다.

[[TIP]]
공액 폴리엔(예: 베타카로틴)에도 같은 모형을 써볼 수 있는데, 시아닌만큼 잘 맞지 않습니다. 폴리엔은 시아닌과 달리 대칭이 아니라서 단일결합과 이중결합의 길이가 147 pm과 134 pm으로 뚜렷하게 번갈아 나타나거든요. 그러면 바닥이 평평하지 않고 굴곡이 생깁니다. 자유전자 모형의 핵심 가정이 깨지는 겁니다.
[[/TIP]]


## 그래서 이 모델은 무엇을 위한 것인가

상자 속 입자 모델은 정밀한 예측 도구가 아닙니다. 5~17% 오차로는 실험을 대신할 수 없죠.

그런데 이 모형에는 다른 값이 있습니다. 왜 그런 일이 일어나는지 설명해주거든요.

- 왜 공액계가 길수록 색이 붉어지는가 → $L^2$이 $N$보다 빨리 커지니까
- 왜 시아닌은 잘 맞고 폴리엔은 안 맞는가 → 바닥이 평평한지 아닌지
- 왜 사슬이 길수록 예측이 좋아지는가 → 끝 효과의 비중이 줄어드니까

숫자를 정확히 맞히는 것과 왜 그런지 이해하는 것은 다른 일입니다. 앞으로 배울 방법들은 숫자를 훨씬 잘 맞히겠지만, 그만큼 "왜"가 코드 안에 숨어버리죠. 그래서 이런 '거친' 모형이 여전히 쓸모가 있습니다.

어떻게 하면 더 계산을 정확하게 할 수 있는지는 나중에 다룹니다. 15장에서 Hückel 이론으로 사슬의 각 원자를 제대로 다루게 되고, 24장에서는 더 정확한 방법으로 실제 분자를 계산합니다. 그때 이 결과를 다시 꺼내 비교해보겠습니다.
