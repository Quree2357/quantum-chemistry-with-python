지금까지 세 가지 이야기를 했습니다. 뜨거운 물체가 내는 빛, 금속에서 튀어나오는 전자, 원자가 내뿜는 선 스펙트럼. 서로 아무 관계도 없어 보이는 현상들이죠. 그런데 세 사건에는 공통점이 있었습니다. 이 절에서는 그것을 정리하고, 왜 이것만으로는 아직 부족했는지를 짚겠습니다.


## 자꾸 끼어드는 플랑크 상수

먼저 각 사건에서 무엇을 가정했는지 다시 봅시다.

| | 가정 | 식 |
|---|---|---|
| 흑체 복사 | 진동자의 에너지가 덩어리 단위 | $E = nh\nu$ |
| 광전 효과 | 빛 자체가 덩어리 | $E = h\nu$ |
| 선 스펙트럼 | 정해진 원자 궤도 | $L = n\hbar$ |

셋 다 "무언가가 연속적이지 않고 띄엄띄엄하다"는 주장입니다. 그리고 셋 다 같은 상수 $h$를 씁니다.

이게 우연이었다면 세 사건은 그냥 세 개의 별개 사건으로 끝났을 겁니다. 그런데 흑체 복사에서 얻은 $h$와 광전 효과에서 얻은 $h$가 같았고, 보어 모형에 그 $h$를 넣었더니 뤼드베리 상수가 정확히 나왔습니다. 서로 다른 세 실험이 하나의 숫자를 가리키고 있었던 것이죠.

자연에 무언가 근본적인 것이 숨어 있다는 신호였습니다.


## 양자와 거시 세계

여기서 자연스러운 의문이 생깁니다. 에너지가 그렇게 띄엄띄엄하다면 왜 우리는 일상에서 그걸 느끼지 못할까요? 자동차의 속도 같은 건 아무 값이나 될 수 있어 보이는데 말이죠.

답은 $h$가 너무 작기 때문입니다. 얼마나 작은지 감을 잡아봅시다.

```python
from scipy.constants import hbar

L_electron = hbar

m, r, v = 0.05, 0.03, 10
L_top = m * r * v

print(f"전자의 각운동량 = {L_electron:.3e} J·s")
print(f"팽이의 각운동량 = {L_top:.3e} J·s")
print(f"팽이를 보어 모형에 넣으면 n = {L_top / hbar:.2e}")
```
```
전자의 각운동량 = 1.055e-34 J·s
팽이의 각운동량 = 1.500e-02 J·s
팽이를 보어 모형에 넣으면 n = 1.42e+32
```

팽이의 양자수는 $10^{32}$ 정도입니다. 이 팽이가 $n$에서 $n+1$로 바뀌는 것은 전체의 $10^{-32}$만큼 변하는 것이니, 어떤 측정기로도 감지할 수 없습니다. 양자화되지 않은 게 아니라 그 간격이 너무 촘촘해서 연속인 것처럼 보이는 것이죠.

수소 원자에서도 같은 일이 일어납니다. $n$이 커지면 준위 간격이 어떻게 되는지 보세요.

```python
E = lambda n: -13.606 / n**2

for n in [1, 2, 10, 50, 100]:
    gap = E(n + 1) - E(n)
    print(f"n={n:4d} -> {n+1:4d}   간격 {gap:.3e} eV   상대 간격 {abs(gap/E(n)):.3e}")
```
```
n=   1 ->    2   간격 1.020e+01 eV   상대 간격 7.500e-01
n=   2 ->    3   간격 1.890e+00 eV   상대 간격 5.556e-01
n=  10 ->   11   간격 2.361e-02 eV   상대 간격 1.736e-01
n=  50 ->   51   간격 2.113e-04 eV   상대 간격 3.883e-02
n= 100 ->  101   간격 2.681e-05 eV   상대 간격 1.970e-02
```

바닥상태 근처에서는 에너지 준위 사이의 간격이 에너지 값의 75%나 벌어져 있어 누가 봐도 불연속입니다. 그런데 $n=100$쯤 가면 상대 간격이 2%로 줄어들죠. 계속 올라가면 사실상 연속이 됩니다.

그림으로 보면 더 분명합니다.

```python
import numpy as np
import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 3, figsize=(12, 4))

for ax, (lo, hi) in zip(axes, [(1, 6), (10, 15), (50, 55)]):
    ns = np.arange(lo, hi + 1)
    Es = -13.606 / ns**2
    for n, En in zip(ns, Es):
        ax.hlines(En, 0, 1, lw=2, color="navy")
        ax.text(1.04, En, f"{n}", va="center", fontsize=8)
    span = Es.max() - Es.min()
    ax.set_xlim(0, 1.2)
    ax.set_xticks([])
    ax.set_ylim(Es.min() - 0.1 * span, Es.max() + 0.1 * span)
    ax.set_ylabel("energy (eV)")
    ax.set_title(f"n = {lo} ~ {hi}")

plt.tight_layout()
plt.show()
```
![수소 원자의 에너지 준위](/assets/image-25.png)

같은 개수의 준위인데 $n$이 커질수록 촘촘하게 뭉칩니다. 양자수가 커질수록 고전물리학의 결과에 가까워진다는 이 성질을 보어는 **대응 원리(correspondence principle)**라고 불렀습니다.

이것은 새로운 이론이 갖춰야 할 조건이기도 합니다. 양자역학이 옳다면, 큰 계(거시 세계)에서는 고전역학과 같은 답을 내놓아야 하니까요. 고전물리학이 100년 넘게 잘 맞아온 것도 사실이거든요.


## 그런데 아직 이론이 아니었다

여기까지가 1913년의 상황입니다. 그리고 솔직히 말하면, 이건 아직 이론이라고 부르기 어려웠습니다.

세 가정을 다시 보세요. 셋 다 "이렇게 가정하면 실험과 맞는다"가 전부입니다.

- 플랑크: 진동자의 에너지가 왜 $h\nu$ 단위여야 하는가? &rightarrow; 모름
- 아인슈타인: 빛이 왜 덩어리인가? 그런데 간섭은 또 어떻게 하는가? &rightarrow; 모름
- 보어: 각운동량이 왜 $\hbar$의 정수배인가? 정상상태에서는 왜 빛을 안 내는가? &rightarrow; 모름

각 현상마다 필요한 가정을 그때그때 갖다 붙인 셈입니다. 이 시기의 이론들을 묶어 **구 양자론(old quantum theory)**이라고 부르는데, "구"라는 말이 붙은 이유가 여기 있습니다. 나중에 제대로 된 이론이 나오면서 밀려났기 때문이죠.

한계는 곧 드러났습니다. 보어 모형은 수소에서는 기가 막히게 맞았지만 전자가 두 개인 헬륨부터 어긋났습니다. 스펙트럼 선의 세기도 설명하지 못했고, 정밀 측정에서 선이 여러 개로 갈라지는 현상도 다루지 못했습니다. 무엇보다 화학자에게 가장 중요한 질문에 답하지 못했습니다. 원자들이 왜, 어떻게 결합해서 분자를 만드는가?

필요한 것은 가정을 하나 더 추가하는 것이 아니었습니다. 불연속성이 왜 나타나는지를 설명하는 통일된 원리였죠.
