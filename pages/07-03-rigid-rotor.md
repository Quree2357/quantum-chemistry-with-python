진동 운동이 적외선 분광학과 이어지는 것과 회전 운동이 마이크로파 분광학과 이어지는 것은 두 운동의 성질이 다르기 때문이라기 보다는 에너지의 규모가 다르기 때문입니다. 하지만 적외선 분광학에서는 결합의 힘 상수를 얻을 수 있는 반면에 마이크로파 분광학에서는 결합의 길이를 얻을 수 있습니다.


## 이원자 분자의 회전

앞 절에서는 질량이 $\mu$인 입자 한 개가 회전하는 모델을 봤었는데요, 실제 이원자 분자(diatomic molecule)는 입자가 두 개 있죠. 이런 모양의 모델을 **강체 회전자(rigid rotor)**라고 부릅니다. 결합 길이는 변하지 않는다고 가정합니다. 물론 환산질량은 조화 진동자 때와 같은 값으로 정의됩니다. 그러면 7.2절의 결과를 그대로 쓸 수 있습니다.

$$
E_J = \frac{J(J+1)\hbar^2}{2I}, \quad J = 0, 1, 2, \ldots
$$

회전 양자수는 관례상 $J$로 쓰는 경우가 많습니다. 분광학에서는 앞에 상수를 따로 떼어내어 **회전상수(rotational constant)**라고 부릅니다.

$$
E_J = BJ(J+1), \quad B = \frac{\hbar^2}{2I}
$$

조화 진동자에서와 마찬가지로 강체 회전자에서도 선택 규칙이 존재하는데 똑같이 $\Delta J=\pm 1$로 나타납니다. 그리고 전자기파를 흡수하기 위해 쌍극자 모멘트가 있어야 하고요.  

$J$에서 $J+1$로 올라가는 전이의 에너지를 구해봅시다.
 
$$
\Delta E = B(J+1)(J+2) - BJ(J+1) = 2B(J+1)
$$
 
조화 진동자의 경우에서는 이웃한 준위 간의 에너지 차이가 항상 일정했었는데 강체 회전자는 준위가 올라갈 수록 에너지 차이가 커지네요.  

HCl 분자로 예를 들어 계산해봅시다.
```python
import matplotlib.pyplot as plt
from scipy.constants import hbar, u, h, c

mu = (1.008 * 34.969) / (1.008 + 34.969) * u
r = 1.27e-10
B = hbar**2 / (2 * mu * r**2) / (100 * h * c)

fig, ax = plt.subplots(figsize=(6, 5))
for J in range(5):
    E = B * J * (J + 1)
    ax.hlines(E, 0, 1, lw=2, color="navy")
    ax.text(1.05, E, f"J = {J}", va="center", fontsize=9)
    ax.annotate(
        "",
        xy=(0.3 + 0.1 * J, B * (J + 1) * (J + 2)),
        xytext=(0.3 + 0.1 * J, E),
        arrowprops=dict(arrowstyle="->", color="crimson", lw=2),
    )

ax.set_xlim(0, 1.4)
ax.set_xticks([])
ax.set_ylabel("E (cm^-1)")
plt.show()

print(f"HCl의 회전 상수 = {B:.2f} cm^-1")

for J in range(4):
    Delta_E = 2 * B * (J + 1)
    print(f"J = {J} -> {J+1}: ΔE = {Delta_E:.2f} cm^-1")
```

```

```

확실히 진동 운동에서 나타났던 수천 $\text{cm}^{-1}$ 스케일에 비해서 많이 작네요. 적외선보다 훨씬 에너지가 낮은 원적외선과 마이크로파 영역입니다. 


## 마이크로파 분광학과 결합 길이

이제 거꾸로도 해봅시다. 실제로 분광 스펙트럼을 찍어서 얻은 회전상수로부터 결합 길이를 역산하는 것입니다.
```python
import numpy as np


def bond_length(B_cm, m1, m2):
    mu = m1 * m2 / (m1 + m2) * u
    I = hbar**2 / (2 * B_cm * 100 * h * c)
    return np.sqrt(I / mu) * 1e12


data = [
    ("HF", 20.96, 1.008, 18.998, 91.68),
    ("CO", 1.931, 12.000, 15.995, 112.83),
    ("N2", 1.998, 14.003, 14.003, 109.77),
]

print(f"{'분자':>2} {'B (cm^-1)':>10} {'계산 r':>9} {'실제 r':>9}")
for name, B_cm, m1, m2, r_lit in data:
    print(f"{name:>3} {B_cm:10.3f} {bond_length(B_cm, m1, m2):8.2f} pm {r_lit:7.2f} pm")
```
```
분자  B (cm^-1)      계산 r      실제 r
 HF     20.960    91.66 pm   91.68 pm
 CO      1.931   112.84 pm  112.83 pm
 N2      1.998   109.78 pm  109.77 pm
```

스펙트럼에서 선 간격 하나만 재면 분자의 결합 길이를 옹스트롬 이하 정밀도로 알 수 있습니다. 실제로 마이크로파 분광법은 기체 분자의 구조를 결정하는 가장 정확한 방법 중 하나입니다.  

앞에서 쌍극자 모멘트가 있어야 한다고 했으니 N₂는 마이크로파 스펙트럼을 관찰할 수 없어야 하죠. 그런데 회전 상수를 어떻게 알아낸 걸까요? 사실 N₂의 회전상수는 Raman 분광법으로 얻은 값입니다. 6.3절 팁에서 언급했던 그 방법이죠. 쌍극자가 아니라 분극률 변화를 보므로 동종핵 분자도 관측할 수 있습니다.


## 결합은 막대가 아니다

그런데 실제로 마이크로파 분광 스펙트럼을 찍어보면 선들이 등간격으로 나타나지 않습니다. 위에서 계산했던 것처럼 에너지 차이가 $2B$, $4B$, $6B$, 이런 식으로 일정하게 늘어나야 하는 데 말이죠.
 
이것은 분자의 결합이 막대처럼 고정된 길이를 갖지 않기 때문입니다. 분자가 빠르게 회전하면 원심력 때문에 결합이 늘어나죠. 결합이 길어지면 관성모멘트가 커지고, 따라서 회전상수가 작아집니다.
 
$$
E_J = BJ(J+1) - \tilde{D}J^2(J+1)^2
$$
 
$\tilde{D}$를 **원심 왜곡 상수(centrifugal distortion constant)**라고 부르는데, 보통 $B$의 $10^{-4}$ 정도로 작습니다. 그래서 낮은 $J$에서는 무시할 만하지만, $J$가 커지면 선 간격이 조금씩 좁아지는 것이 관측됩니다.
 
그리고 진동과 회전은 사실 함께 일어납니다. 기체 상태에서 적외선 분광 스펙트럼을 찍으면 진동 봉우리 하나가 여러 갈래로 갈라져 보이는데, 진동이 바뀌면서 회전도 동시에 바뀌기 때문이죠. 이것을 진동-회전 스펙트럼이라고 부릅니다. 자세한 것은 분광학 교재를 참고하세요.
