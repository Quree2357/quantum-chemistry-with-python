# 알기 쉬운 양자화학 with 파이썬

**양자화학(Quantum chemistry)**은 양자역학을 화학에 적용한 분야입니다. 모든 화학 반응은 전자를 통해 이루어진다고 해도 과언이 아닐 정도로 화학에서는 전자가 무엇보다도 중요합니다. 이 전자들의 상태와 운동을 정확하게 기술하려면 양자역학이라는 도구를 사용할 수밖에 없습니다.
양자역학이라는 단어는 많이 들어보셨을 겁니다. 대부분은 매우 어렵다는 이미지를 가지고 있지만 많은 과학 커뮤니케이터 분들께서 방송이나 유튜브 등의 대중매체에 출연하여 쉽게 설명해주셔서 진입 장벽이나 거부감은 많이 낮아진 것 같습니다. 양자화학은 양자역학을 도구로 사용하기는 하지만 이론과 철학적인 개념이 중요하지는 않습니다. 측정과 붕괴, 양자 얽힘, 슈뢰딩거의 고양이, 양자 컴퓨터와 같은 단어들이 생각나시겠지만 여기서는 실제로 계산해서 숫자를 얻어내는 것에 집중합니다.

양자화학(또는 양자역학)에서 가장 중요한, 그리고 유일한 문제는 그 유명한 **슈뢰딩거 방정식(Schrödinger equation)**을 푸는 것입니다. 이론적으로는 슈뢰딩거 방정식의 해를 구할 수 있다면 모든 것을 예측할 수 있습니다. 그러나, 문제는 이 방정식이 너무 복잡하다는 것입니다. 슈뢰딩거 방정식은 **미분방정식(differential equation)**의 형태를 가지고 있습니다. 본문에서도 설명하겠지만 미분방정식의 특징은 해(solution)를 구하는 것이 매우 어렵다는 것입니다. 해석적인 방법으로는 해를 구하는 것이 불가능한 경우도 있습니다. 그래서 과학자들은 슈뢰딩거 방정식을 풀기 위해(적어도 근사적인 해를 얻기 위해) 다양한 계산법을 발전시켜왔습니다. 이 과정에서 **계산화학(computational chemistry)**이라는 분야가 생겨났습니다. 컴퓨터를 이용해 슈뢰딩거 방정식의 수치적인 해를 구하는 방법으로, 여러 가지 근사법과 모델링의 개발을 통해 이제는 계산으로 화학적인 특성을 예측할 수 있게 되었습니다.

이 책은 양자화학에 대한 설명과 계산화학에 대한 개념을 정리하고 있습니다. 전체적인 흐름은 Donald A. McQuarrie의 『양자화학 제2판』(자유아카데미, 2010)을 참고하였으며, 최대한 알기 쉽게 풀어쓰려고 노력했고, Python을 활용해 직접 계산해보면서 개념을 다시 한 번 확인해 볼 수 있도록 하였습니다. 이는 추후에 본격적인 계산화학 도구들을 다룰 때 큰 도움이 될 것입니다. 각 Python 코드는 바로 실행 가능하도록 구글 Colab 노트북 링크를 제공하였습니다. 구글 Colab의 장점은 직접 여러 가지 패키지를 컴퓨터에 설치할 필요 없이 인터넷만 있으면 바로 실행할 수 있다는 점입니다. 큰 분자들의 양자 계산은 GPU를 이용하여 계산을 가속시키는 경우도 있지만 이 책에서 다루는 수준의 계산은 대부분 CPU만으로도 충분히 돌아갑니다.

기초적인 Python 프로그래밍에 대해서는 익숙하다고 가정합니다. 만약 Python에 대해서 잘 모르거나 복습을 하고 싶으시다면 [『점프 투 파이썬』](https://wikidocs.net/book/1)과 같은 곳에서 학습하실 수 있습니다. 그리고, 양자화학은 미적분학과 선형대수학에 대한 기초적인 선행 지식을 필요로 하고 있습니다. 머신러닝/딥러닝과 같은 인공지능 학습에 필요한 수학과 거의 동일하니 『개발자를 위한 필수 수학』(한빛미디어, 2024)과 같은 책이나 Khan academy의 [선형대수학 강의](https://www.khanacademy.org/math/linear-algebra)와 같은 다양한 자료들에서 참고하면 좋습니다.
